# 정적 제작기 0.2 검수 기록

2026-11-02. Python 3.12 / Pillow 12.3.0, 로컬 Linux 환경. 실제 앱·애니메이션 검수는 포함하지 않는다.

## 실행 증거

- 기존 unittest 5개 + tests/test_v02.py 9개 = 14개 통과.
- Playwright + 시스템 Chromium으로 tests/browser_v02.py 통과. 데스크톱 1440px·모바일 390px 폭, 페이지 JavaScript 오류 없음.
- 실제 개체의 비공개 프로필을 별도 임시 폴더에 코드·패키지와 함께 복사해 3개 새 프로세스에서 얼굴/전신 B2/C2 네 출력의 RGBA 해시 동일 확인. 참조 사진·정본·이전 시안 파일은 입력 패키지에 없음.
- 얼굴 출력 12색, 전신 14색(해당 개체 팔레트 기준), 투명도 0/255, 96×96 확인.
- maker.py는 0.1 원격 원문과 바이트 일치. 프로필 원본과 0.1 렌더 경로를 보존했다.
- 발 털 옵션이 내부 마스크만 바꾸고 최종 출력에 반영되지 않던 결함을 V05 검사에서 찾아 발 외곽에 반영하도록 수정했다.

## 편집 화면

실제 브라우저에서 4개 출력 로드, 눈/연결점 오버레이, 0.1 비교, 귀 길이 변경, 새 초안 저장·재로드, 이전 버전 복원, 코/주둥이 잘못된 조합의 오류와 저장 차단, 저장본 초기화를 확인했다. 원래 관찰 프로필 revision은 그대로 유지됐다. 로컬 API 검사에는 잘못된 세션 거절·stale 저장 409도 포함했다.

로컬 결과·개체 제작 상태·스크린샷은 실행 환경에 보존하고 공개 Git에는 넣지 않았다. 저장소는 코드·패키지·합성 검사 자료만 포함한다. 기술 통과를 개체 닮음·정본 승인이나 제품 전체 완료로 해석하지 않는다.
