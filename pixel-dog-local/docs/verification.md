# 인수인계 패키지 확인 기록

확인일: 2026-10-17.

- 원본 문서 10개의 블록 본문을 JSON으로 보존하고, 로컬 Markdown 본문과 대조했습니다. 프로젝트 내부 링크만 상대 경로로 변환했습니다.
- 문서와 시안의 로컬 링크 대상, JSON 구문, 8fps·125ms 설정을 확인했습니다.
- 참고 시안 4개의 원본 복사본은 원본 파일 SHA-256과 일치합니다. 독립 페이지의 JavaScript 구문을 검사했습니다.
- 이 환경에는 실행 가능한 Chromium이 없어 독립 HTML 복사본의 화면 렌더링·버튼 동작은 브라우저로 검증하지 못했습니다. 로컬에서는 references/previews/index.html을 열어 확인합니다.
- Android/iOS 앱은 아직 구현하지 않았으므로 앱 빌드·실기기·배터리 시험 결과는 없습니다.

압축 파일은 파일 목록과 CRC, 각 파일의 내용 일치 여부를 확인한 후 제공합니다. 전체 파일 해시는 provenance/checksums.sha256에 있습니다.
