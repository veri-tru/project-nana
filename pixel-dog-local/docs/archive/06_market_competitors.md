# 1. 시장의 범위

이 앱이 우선 진입할 범위는 ‘실제 반려견을 개인화한 모바일 동반 캐릭터’다. 전체 반려동물 산업에는 식품·병원·미용·보험 등이 포함되므로 그 지출을 이 앱의 매출 기회로 직접 환산하지 않는다.

경쟁은 동일한 기술 사용 여부보다 사용자가 무엇을 얻으려 하는지를 기준으로 나눈다.

| 경쟁 범위 | 사용자가 얻으려는 것 | 비교 대상 |
| --- | --- | --- |
| 직접 경쟁 | 내 반려동물을 닮은 움직이는 캐릭터 | 포켓펫, SpritePals, 사진 기반 PetPal |
| 표시 경험 경쟁 | 휴대폰을 쓰는 동안 작은 캐릭터와 함께하기 | Custom Pet, Pixel Pals, Widgetable |
| 관계·기억 경쟁 | 반려동물과의 추억·대화·개별적인 반응 | Still My Dog, 위드포, GoPowZ |
| 대체재 | 사진으로 기억하고 꾸미거나 선물하기 | 사진첩·배경화면, 맞춤 초상화·인형 |
| 관찰할 신생 서비스 | 사진으로 만든 AI 반려동물의 추가 방식 | PetLLM, Paw Beside |

고양이도 지원하는 경쟁 앱은 기능과 사업모델 비교에 포함하되, 본 프로젝트의 수집·개발·초기 고객 검증은 개로 한정한다.

농식품부의 방문조사와 KB의 추정모델·온라인 조사는 시점과 방법이 다르다. KB의 26.7%와 농식품부의 29.2%를 이어 붙여 시장 성장률로 계산하지 않는다. KB의 반려견가구 455만을 2026년 현재 실측 고객 수로 표시하지 않는다. 보호자 수·가구 수·개체 수를 매출 모델에서 혼합하지 않는다.

| --- | --- | --- |
| 잠재 고객 기반 | 국내 반려견 양육가구 | KB의 2024년 말 추정 455만 가구를 참고 가능 |
| 실제 접근 가능 시장 | 지원 기기 보유, 개인화 캐릭터 관심, 자료 제공 가능, 제안 가격 수용 | 해당 조건의 결합 비율을 확인해야 함 |
| 초기 확보 가능 고객 | 실제 모집 채널에서 유입되어 개인화를 완료하고 결제한 보호자 | 모집·사용·결제 실험으로 측정 |
| 매출 전망 | 유료 고객 수 × 실제 결제액, 환불·수수료·원가 반영 | 아직 확정 불가 |

현재 공개 자료로는 ‘실제 반려견의 습관을 재현하는 앱’의 국내 시장 매출·유료 전환율·유지율을 확정할 수 없다. 숫자가 필요한 사업계획은 전체 반려동물 산업 전망치를 차용하지 않고, 모집 가능한 고객 수와 제작 처리량부터 계산한다. 한 개체를 완성하는 데 드는 사람의 작업 시간이 크면 시장 크기보다 공급 능력이 초기 성장의 제한이 된다.

# 3. 목표 사용자 정의

첫 목표 사용자는 “현재 함께 사는 반려견의 사진과 영상을 이미 기록하며, 외형뿐 아니라 익숙한 반응과 버릇까지 화면에서 보고 싶고, 짧은 자료 제공과 확인에 참여할 성인 보호자”로 정의한다.

선정 이유는 본 앱의 핵심 가치가 반려견의 개별성을 표현하는 데 있고, 현재 양육 중인 보호자는 반복 장면을 새로 수집하고 재현 결과와 비교할 수 있기 때문이다. 직장인·1인가구·20~30대 여성으로 고객을 한정할 근거는 현재 확보하지 못했으므로 이러한 특성은 모집 후 비교 변수로 수집한다.

| 우선순위 | 사용자 집단 | 원하는 경험과 현재 대안 | 확인할 핵심 조건 |
| --- | --- | --- | --- |
| 1차 | 일상 기록을 하는 현재 반려견 보호자 | 사진·배경화면에서 한 단계 더 나아가 자기 개의 익숙한 반응을 보고 싶음 | 행동 개인화가 외형 개인화보다 가치 있는가 |
| 2차 | 꾸미기·맞춤 굿즈를 즐기는 보호자 | 빠르고 예쁜 캐릭터, 위젯, 공유용 결과물 | 단순 사진 변환과 비교해 추가 입력을 감수하는가 |
| 확장 | 가족과 반려견 기록을 공유하는 보호자 | 같은 개의 사진·기억·캐릭터를 함께 봄 | 가족 공유가 재방문과 지불에 기여하는가 |
| 별도 탐색 | 떠나보낸 반려견의 기억을 보존하려는 보호자 | 기존 사진·영상·편지·기념물 | 남은 자료로 가능한 재현 범위와 원하는 상호작용이 무엇인가 |
| 초기 후순위 | 실제 반려견이 없는 가상 펫 이용자 | 새 캐릭터 육성·수집·게임 | 실제 개체를 재현한다는 핵심 가치와의 적합성이 낮음 |

이 우선순위는 시장 규모 순위가 아니다. 추모 수요는 경쟁 서비스의 공개 리뷰에서도 확인되지만, 현재 앱의 반복 관찰 설계와는 자료 조건이 다르다. 현재 양육과 추모를 하나의 사용자 흐름에 합치기 전에 별도로 조사한다. ## 사용 상황과 해결할 과제

| 상황 | 사용자가 하려는 일 | 가치가 있었다고 판단할 징후 |
| --- | --- | --- |
| 업무·이동 중 잠깐 휴대폰을 볼 때 | 익숙한 반려견의 모습과 반응을 짧게 접하기 | 별도 과제 없이도 다시 보려고 함 |
| 평소 특이한 버릇을 촬영했을 때 | 그 행동을 캐릭터에도 반영하기 | 새 장면 추가 후 차이를 알아보고 유지함 |
| 가족에게 보여줄 때 | “이건 우리 개답다”는 장면을 공유하기 | 외형 외에 구체적인 행동을 설명함 |
| 캐릭터가 실제 개와 다르게 느껴질 때 | 잘못된 특징을 쉽게 수정하기 | 수정 후 만족이 높아지고 사용을 계속함 |

위 상황은 인터뷰로 검증할 가설이다. 반려견의 실시간 안전 확인이 목적이라면 홈캠·돌봄 서비스가 더 직접적인 대안이다. 본 앱을 홈캠 대신 사용할 제품으로 설명하지 않는다.

# 4. 직접 경쟁사 비교

기능은 공식 소개·앱스토어에 공개된 내용을 기준으로 한다. ‘미확인’은 조사한 공개 설명에서 확인하지 못했다는 뜻이며 기능이 없다고 단정하는 표시가 아니다. 앱을 설치해 생성 품질·응답 속도·지속 표시 시간을 시험한 결과는 포함하지 않는다.

특히 가상 상호작용으로 생긴 캐릭터의 성격과 실제 개에게 관찰된 행동을 재현하는 것은 서로 다른 개인화다. 경쟁 비교에서 두 방식을 같은 ‘AI 성격’ 항목으로 합치지 않는다.

| 비용이 성립하는가 | 실제 결제액이 제작·지원·변동비를 감당 | 기대 가격에 맞출수록 사람의 작업 비용이 커짐 |

인터뷰 12명이나 파일럿 소수의 선택률에 임의의 통계적 합격선을 붙이지 않는다. 사례별 완료 여부·사용 이유·작업 시간과 오류를 먼저 보고하고, 제품을 더 넓게 검증할 단계에서 정량 목표를 사전 설정한다.

시장 확보 경로는 반려견 사진·영상 기록 커뮤니티, 맞춤 굿즈·사진 서비스 이용자, 실제 사용 장면을 보여주는 짧은 콘텐츠를 우선 시험하는 가설로 둔다. 채널별 유입 수뿐 아니라 적합 보호자 비율, 자료 제출, 개인화 완료, 결제, 환불까지 추적한다. 홍보나 외부 연락은 아직 수행하지 않았다.

# 11. 기존 기획에 반영할 우선순위

| 항목 | 이번 시장 조사에 따른 적용 |
| --- | --- |
| 첫 고객 | 현재 반려견을 기록하는 보호자를 우선 검증 |
| 검증 순서 | M0 고객·시장 검증 후 G0~G3 기술·제품 로드맵을 조정 |
| 첫 비교 | 사진 위젯, 사진 기반 캐릭터, 행동 개인화 캐릭터의 가치 차이 |
| 첫 수집 | 장면 하나로 시작해 추가 촬영 부담을 실제로 측정 |
| 기능 범위 | 대표 행동과 수정·미리보기 우선. 방 꾸미기·미니게임·커뮤니티는 확장 필요성 확인 후 결정 |
| 상주 경험 | 짧게 보고 지나갈 수 있는 동행. 접속하지 않았다는 이유의 벌점·고통 연출을 기본안에 넣지 않음 |
| 결제 | 개인화 제작과 지속 서비스의 가치를 나누어 검증 |
| 플랫폼 | Android 먼저 만드는 기술 순서와 고객의 OS 선호를 구분. 시장 인터뷰는 두 OS 모두 포함 |
| 추모 경험 | 현재 양육 흐름과 분리해 자료·기대·표현을 별도 검토 |

이번 단계의 결론은 시장 진입의 타당성을 확정했다는 것이 아니다. 유사 서비스가 실제로 존재하는 상황에서, 누구에게 어떤 추가 가치를 입증해야 하는지 구체화한 것이다. 다음 산출물은 모집용 스크리너, 인터뷰 질문지, 세 가지 비교 콘셉트와 실제 자료 수집 과제다.

# 12. 근거의 적용 범위

| 근거 유형 | 이번 판단에 사용한 범위 | 그 자료만으로 판단하지 않은 것 |
| --- | --- | --- |
| 정부 통계·KB 보고서 | 국내 양육 기반, 조사 시점, 보호자 인식 | 본 앱의 관심도·구매율·시장 매출 |
| 공식 사이트·앱스토어 | 공개 기능, 플랫폼, 상품과 가격, 출시·대기 상태 | 실제 생성 품질·속도·활성 고객·매출 |
| 공개 리뷰 | 구체적인 긍정 경험과 마찰의 사례 | 전체 사용자 중 비율, 임상 효과, 현재 버전의 오류율 |
| 현재 기술 설계 | 필요한 자료와 구현 가능 범위에 따른 초기 타깃 적합성 | 시장에서 검증된 경쟁 우위 |
| 제안한 인터뷰·가격 실험 | 다음 단계의 검증 계획 | 이미 수행한 조사 결과 |

국내 통계는 조사 연도와 발표일을 구분했으며, 서비스 가격은 국가와 상품 종류를 함께 표시했다. 상품명이 같은 다른 앱을 동일 서비스로 합치지 않았다. 공개 설명에서 확인되지 않은 기능은 ‘미확인’으로 유지했다. 모든 경쟁사가 동일한 조건에서 시험된 것은 아니므로 기능 유무만으로 품질 순위를 부여하지 않는다.
