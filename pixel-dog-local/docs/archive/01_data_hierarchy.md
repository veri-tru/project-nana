# 데이터 위계

아래 위계는 수집과 저장을 위한 구조다. ‘성격 → 습관 → 동작’의 고정된 인과관계를 뜻하지 않는다. 개체 아래에 관찰 회차, 회차 아래에 상황 장면, 장면 아래에 행동 사건을 둔다. 개체별 프로파일과 사용자 평가는 이 원자료에 연결하는 별도 자료다.

| 단계 | 단위와 연결 | 저장할 내용 | 용도 |
| --- | --- | --- | --- |
| 1 개체 | 반려견 한 마리 | 개체 ID, 연령 또는 추정 범위, 함께 사는 사람, 외형 자료, 보호자 설명 | 누구의 자료인지 식별 |
| 2 관찰 회차 | 특정 날짜·시간의 관찰 | 촬영 일시·장소, 참여자, 직전 활동, 평소와 다른 상태, 원본 파일, 관찰 범위 | 상황 간 비교 조건 확인 |
| 3 상황 장면 | 하나의 시작 상황과 반응 구간 | 자극과 대상, 시작·종료 시점, 보호자 행동, 관찰 기회 여부 | 반응 지연과 반응률의 기준 |
| 4 행동 사건 | 구간 안에서 발생한 행동 | 행동 코드, 대상, 시작·종료 시각, 반복, 다음 행동, 가시성 | 동작과 순서를 재현 |
| 5 파생 프로파일 | 여러 회차·장면의 요약 | 상황별 반응률, 지연·지속의 분포, 자주 나타난 순서, 관찰 일수, 근거 구간 | 앱의 행동 선택 규칙 |
| 6 재현 평가 | 프로파일·앱 버전별 평가 | 자기 개다움, 익숙함, 귀여움, 식별 선택, 판단 이유 | 개인화의 효과 검증 |

사진·원음·영상은 해당 개체 및 촬영 회차에 연결한다. 보호자 설명은 보고 자료, 영상 코딩은 관찰 자료, 프로파일 값은 파생 자료로 구분한다. 평가에 쓸 영상과 응답에는 용도를 표시해 프로파일 조정에 사용한 자료와 구별한다.

# 우선순위와 근거 표기

| 우선순위 | 적용 시점 | 선정 기준 |
| --- | --- | --- |
| P0 먼저 수집 | 첫 개체 개인화에 사용 | 자료를 해석하는 데 필수이거나, 상황별 동작을 직접 구현하는 핵심 자료 |
| P1 다음 단계 | P0의 반복 관찰 자료가 확보된 뒤 | 생활 전반으로 확장하거나 핵심 자료의 해석을 보완하는 자료 |
| P2 필요할 때 | 구체적인 구현·검증 문제를 해결할 때 | 높은 수집 비용이 들거나 현재 재현 목적의 추가 가치가 불확실한 자료 |

근거 표기는 관찰·측정, 시간적 안정성, 보호자 경험, 설계 필수로 구분한다. ‘설계 필수’는 연구로 식별 효과가 증명됐다는 뜻이 아니라 출처 연결·측정·구현을 위해 필요한 항목이라는 뜻이다. 근거 유형과 수집 우선순위는 별개다.

## 먼저 구현할 행동 영역

| 영역 | 추가로 기록할 특징 | 첫 2D 구현에 연결할 값 | 근거 |

위 네 영역을 모든 개에게 동일한 비중으로 강제하지 않는다. 보호자가 중요하게 여기고 실제로 반복 관찰되는 영역부터 채운다. 거리·각도·속도는 영상의 기준척도와 시야가 확보될 때 수치화하며, 그렇지 않으면 ‘접촉 중·가까이·떨어짐’처럼 정의된 범주나 측정 불가로 기록한다.

| P1 | 개체 특유의 생활 습관 후보 | 눕기 전 순서, 선호 휴식 위치, 물건 운반 등 보호자 지목 행동 | 반복 영상과 보호자 평가로 검토하는 탐색 후보. 특정 동작의 식별 효과는 미확정 |
| P2 | 정밀 운동·표정 수치 | 관절 좌표, 보행 주기, 얼굴 움직임, 정확한 꼬리 각도·속도 | 일반 영상으로 핵심 동작이 구현되지 않을 때 추가하는 기술 자료 |
| P2 | 센서·자동 분석 | 활동계, 장기 촬영, 자동 행동 인식, 개체별 모델 | 생활 리듬 또는 수작업 비용 문제를 해결할 때 검토. 첫 개인화의 필수 조건은 아님 |

간단한 대표 움직임을 P0에서 영상으로 확보하는 것과, 그 움직임의 관절 좌표를 P2에서 정밀 추정하는 것은 다른 작업이다. 마찬가지로 한 장면의 기다림은 P0 공통 시간 기록에 포함되지만, 여러 상황에서의 기다림 성향 추정은 P1이다.

# 수집과 코딩 기준

## 대표 장면과 계획 관찰을 분리

대표 장면 자료는 보호자가 특징적이라고 고른 영상이다. 동작의 모양과 후보 습관을 찾는 데 사용한다. 계획 관찰 자료는 미리 정한 일상 상황이나 시간창에 해당하는 관찰 기회를 반응 유무와 관계없이 기록한다. 빈도와 반응률은 이 자료에서 계산한다. 보호자가 잘 나온 영상만 제출한 경우, 그 영상의 사건 수를 하루 행동 빈도로 해석하지 않는다.

제스처 연구에서는 수집된 영상 수가 개체별 레퍼토리 크기와 관련됐고, 활동 연구에서는 개체 내 일간 변동과 평일·주말 차이가 관찰됐다. 따라서 관찰량·관찰시간·날짜 수를 함께 보존한다. [R1](https://doi.org/10.1007/s10071-018-1181-3) [R4](https://pmc.ncbi.nlm.nih.gov/articles/PMC2907355/)

| 수집 조건 | 대표 장면/계획 관찰, 날짜·시간, 장소, 상호작용자, 직전 활동 |
| 시작 | 자극 종류·대상, 자극 시작 시각, 자극을 제시한 사람 |

| 상호작용 결과 | 보호자의 반응과 시각, 보상 제공, 다음 행동, 장면 종료 사유 |
| 관찰 상태 | 관찰한 전체 시간, 가림·화면 이탈, 반응 없음/판정 불가 |

## 파생값과 결측 처리

| 값 | 계산·기록 기준 |
| --- | --- |
| 상황별 반응률 | 같은 정의의 관찰 기회 중 판정 가능한 기회에서 해당 반응이 나온 비율. 분자·분모·판정 불가 수를 함께 저장 |
| 반응 지연 | 첫 반응 시각에서 자극 시작 시각을 뺀 값. 관찰 종료까지 무반응이면 0초나 종료 시각의 정확한 반응으로 입력하지 않고 미발생 상태와 관찰시간을 보존 |
| 행동 지속 | 관찰된 종료 시각에서 시작 시각을 뺀 값. 화면 밖으로 나가거나 촬영이 먼저 끝나면 종료 미확인으로 표시 |
| 사건 빈도 | 해당 상황에서 기록한 사건 수와 관찰시간 또는 관찰 기회를 함께 제시. 서로 다른 분모의 값을 섞지 않음 |
| 반복 패턴 | 같은 상황의 여러 날짜에서 확인된 순서·타이밍을 요약. 충분한 관찰 전에는 정확한 발생확률을 확정하지 않음 |
| 확실성 | 원본 영상 관찰/보호자 보고/파생 추정이라는 출처와 가시성·관찰량을 각각 저장. 검증 없이 신뢰도 백분율을 부여하지 않음 |

활동·비활동은 먼저 관찰 가능한 상태로 기록한다. 짧은 무동작 구간을 곧바로 수면으로 분류하거나, 수면 영상만으로 수면 단계를 추정하지 않는다. ‘불안하다’, ‘삐쳤다’ 같은 해석은 관찰 행동과 분리된 보호자 설명에 둔다.

## 반복성과 코딩 일치도

같은 상황을 서로 다른 날 관찰하고, 새로운 날의 자료에서 기존 패턴이 다시 나타나는지 확인한다. 개의 성격 일관성 메타분석에서는 연령·측정 간격·측정 도구의 일치가 결과와 관련됐다. 한 장기 연구에서는 지연보상 대기는 안정적이었지만 앞발 누르기 속도는 유의한 안정성이 확인되지 않았다. 상위 성향의 반복성과 특정 동작의 반복성을 별도로 확인한다. [R6](https://pmc.ncbi.nlm.nih.gov/articles/PMC3553070/) [R7](https://doi.org/10.1007/s10071-013-0701-4)

개발용 행동 사전에 시작·종료·동시 행동·판정 불가 기준을 작성한다. 일부 동일 영상을 두 코더가 독립적으로 기록해 행동 종류와 시간 기록의 불일치를 점검한다. 제스처 연구도 영상 일부에 관찰자 간 일치도를 평가했다. 필요한 표본 비율과 합격 기준은 본 파일럿의 오류 양상을 확인한 뒤 정하며, 해당 연구의 비율을 그대로 필수 기준으로 채택하지 않는다. [R1](https://doi.org/10.1007/s10071-018-1181-3)

# 첫 수집과 검증 순서

1. 개체 기본 정보와 외형 자료를 등록하고, 보호자가 대표적이라고 꼽는 상호작용 장면 3개를 선정한다. 3개는 초기 작업 범위를 줄이는 설계 선택이며 검증된 최소 수량은 아니다.

2. 선정 장면의 원본 영상을 확보한 뒤, 같은 상황을 서로 다른 날 관찰한다. 자극 시작 전과 이후 반응이 보이는 구간을 기록하고, 자연스러운 무반응도 포함한다. 자료 확보를 위해 불편한 상황이나 장시간 보상 차단을 만들지 않는다.

3. 장면별 행동 사건을 코딩하고 관찰 기회·지연·순서·지속·종료를 요약한다. 보호자에게 대표성과 누락된 행동을 확인하되, 원본 관찰값을 보호자 해석으로 덮어쓰지 않는다.

4. 확보된 근거로 2D 대표 동작과 상황별 전환을 구현한다. 관찰자료에서 추정한 값과 구현 편의를 위해 정한 임시값을 구분하고, 프로파일 버전과 근거 영상 구간을 연결한다.

5. 첫 개인화 결과가 나오면 자기 개다움과 식별을 평가한다. 이후 생활 리듬, 원음, 설문을 추가해 개선 여부를 확인한다.

생활 리듬은 평일과 휴일을 포함하도록 관찰 범위를 확장한다. Dow 등의 7일 구간 비교 결과는 활동 총량의 변동에 대한 근거이며, 모든 개의 행동 재현이 7일 안에 완성된다는 근거는 아니다. [R4](https://pmc.ncbi.nlm.nih.gov/articles/PMC2907355/)

## 첫 개인화 결과부터 수집할 평가 자료

| 평가 항목 | 기록 내용 | 해석 |
| --- | --- | --- |
| 자기 개다움 | 동일한 문항·응답 척도로 평가하고 판단 이유 기록 | 보호자 지각의 결과이며 제작 입력과 구분 |
| 익숙함·귀여움·생동감 | 각각 별도 문항으로 측정 | 자기 개다움과 합쳐 한 점수로 처리하지 않음 |
| 행동 식별 | 외형을 같게 한 네 개의 행동 프로파일에서 본인 개 선택, 순서 무작위화 | 강제 4지선다의 우연수준은 25%. 새로 제안하는 검증 설계 |
| 단서별 기여 | 행동 개인화 여부, 소리 유무, 순서·지연 변경 조건 | 어떤 자료가 재현에 도움이 됐는지 비교 |
| 평가 연결 | 평가자, 날짜, 앱·프로파일 버전, 평가 장면, 사용한 원자료 | 같은 자료로 조정하고 평가한 결과와 새 자료의 결과를 구별 |

‘어느 것도 아니다’를 허용하는 과제는 강제 4지선다와 분리해 분석한다. 동일 보호자·개체의 반복 응답을 독립 표본 수로 세지 않는다. 평가지표와 선택 과제는 본 앱의 개발 제안이며 타당화된 반려견 식별 척도는 아니다.
