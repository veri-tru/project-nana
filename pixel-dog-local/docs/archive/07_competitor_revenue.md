포켓펫은 멤버십·유료 재화·추가 슬롯·광고를 결합하고, SpritePals와 PetPal은 개인화 생성 자체에도 과금한다. 현재 확인된 상품 구조는 다양하지만, 직접 경쟁사 네 곳의 현시점 매출액·매출 비중·이익을 검증할 공개 자료는 확보되지 않았다. 판매 가격과 다운로드를 실제 매출로 환산하지 않는다.

우리 앱은 뛰어난 미감과 움직임을 첫 구매 이유로 삼고, 실제 반려견의 행동을 반영하는 기능을 추가 가치로 검증한다. 수익모델의 우선 가설은 개인화 결과물의 일회성 구매와 선택형 확장 구매다. 반복 구독은 지속적으로 새로 제공할 가치가 확인될 때 도입한다. 미감 우위는 개발자의 제품 방향이며, 고객 비교평가로 확인할 사항이다.

이는 하나의 생성권 가격만으로 경쟁 가격을 정하기 어려운 이유다. 초기 가격을 낮게 유지해도 뒤의 아이템·멤버십·광고에서 수익을 얻을 수 있다. 우리 앱이 일회성 완성품 판매를 택한다면, 무료 생성과의 가격 차이를 외형·동작의 완성도, 수정 범위, 이용 범위로 설명해야 한다.

2026년 8~9월 공개 리뷰에는 닮은 외형과 편지에 대한 호감, 광고·돌봄 수치에 대한 부담이 함께 나타난다. 개발자도 수치 감소와 광고 빈도를 조정한다고 답변했다. 과거 리뷰를 현재 버전의 동일한 결함이나 전체 고객의 반응으로 해석하지 않는다. [리뷰와 개발자 답변](https://play.google.com/store/apps/details?gl=KR&hl=ko&id=com.eveai.poketpet)

# 미감을 강점으로 삼는 우리 앱의 적용안

미감은 획득과 첫 결제의 핵심 가설로, 실제 습관 반영은 만족·차별화·추가 구매의 가설로 분리한다. 우선 검증할 보호자는 현재 반려견을 기르면서 맞춤 굿즈·프로필 이미지·배경화면처럼 자기 반려견을 아름답게 표현하는 데 관심이나 구매 경험이 있는 성인이다. ‘보기 좋다’와 ‘우리 개 같다’를 별도 항목으로 평가한다.

| 순서 | 제공할 상품 가설 | 과금 가설 | 확인할 지표 |
| --- | --- | --- | --- |
| 1 | 같은 개의 정교한 외형과 걷기·쉬기·터치 반응 | 반려견 한 마리의 기본 개인화 일회성 구매 | 결제 선택, 외형 승인, 수정 시간, 실제 표시 사용 |
| 2 | 실제 버릇을 반영한 대표 동작·상황 | 추가 행동 또는 패키지 구매 | 추가 영상 제출, 일반 동작 대비 선택, 제작비를 감당하는 결제 |
| 3 | 같은 개의 새 화풍·계절 장면·선택형 장식 | 개별 작품·팩 구매 | 기존 고객의 자발적 재구매와 새 자산 제작비 |
| 4 | 계속 제공할 신규 콘텐츠·동기화·공유 서비스 | 지속 수요 확인 후 선택 구독 | 반복 이용, 해지 이유, 고객별 서비스 비용 |

기존 가격 검증안의 일회성 9,900원·19,900원·29,900원은 그대로 실험 후보이며 적정가격이나 예상 구매율이 아니다. SpritePals의 일회성 Pro $7.99와 PetPal 데스크톱 팩 $10은 비교 기준이 되지만, 기능·플랫폼·제작 범위가 다르므로 단순 환율 변환으로 한국 가격을 정하지 않는다.

첫 구매에는 외형·동작 미리보기, 포함 행동, 수정 가능 범위, 추가 비용을 분명하게 보여준다. 구매한 기본 결과물을 계속 보고 싶은 요구와 새로운 콘텐츠를 받고 싶은 요구를 분리해 결제 범위를 설계한다. 광고를 채택할지는 미감·사용 경험·수익성 검증으로 결정하되, 현재의 우선 가설은 작품과 개인화 가치에 대한 직접 결제다.

미감 우위 검증에는 실제 사용할 작은 표시 크기와 움직이는 상태를 포함한다. 원본 사진, 출력 크기, 장면 길이를 맞추고 제시 순서를 바꿔 비교한다. 우리 결과물만 가장 좋은 사례로 고르거나 경쟁 결과물을 의도적으로 불리하게 제시하지 않는다. 구매 선택의 이유를 화풍, 외형 유사도, 움직임, 행동 개별성, 가격으로 나눠 기록한다.

# 매출보다 먼저 확인할 단위 경제성

일회성 개인화의 건당 공헌이익은 결제 후 실제 수령액에서 생성·분석비, 사람의 제작·검수·수정비, 고객 지원과 관련 변동비를 뺀 값으로 관리한다. 여기에 고객 획득비를 차감한 뒤 고정 개발비·운영비를 감당할 수 있는지 본다. 초기에는 사람의 수정 시간이 AI 분석비보다 중요한 비용 변수가 될 가능성을 검증해야 한다.

| 필요한 기록 | 구체적인 측정 |
| --- | --- |
| 무료 체험 비용 | 비결제 이용자의 생성 횟수·실패·재시도까지 포함 |
| 개인화 제작비 | 개체별 사람 작업 시간, 생성·분석 사용량, 수정 횟수 |
| 결제 전환 | 같은 유입 집단에서 미리보기·자료 제출·제작 완료·결제 단계별 수 |
| 환불과 지원 | 이유, 처리 시간, 닮지 않음과 기술 오류의 구분 |
| 반복 가치 | 실제 표시 이용, 새 동작·작품 구매, 구매 간격 |
| 구독 후보 | 갱신·해지와 지속 제공 비용. 연간 선결제는 월 현금유입과 구분 |
| 채널 수익성 | 채널별 고객 획득비와 결제 후 공헌이익 |

다운로드가 많은 모델의 과금 방식을 그대로 복제하기보다, 우리 결과물의 구매 전환과 수작업 시간을 먼저 확인한다. 한 번 생성한 애니메이션을 기기에서 재생하는 설계는 반복 AI 호출 비용을 줄일 수 있으나, 스토어 유지보수·OS 대응·지원 비용까지 없어지는 것은 아니다.
