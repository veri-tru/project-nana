공개 자료로 확인한 기능과 우리 앱에 적용할 설계안을 아래에서 구분한다. 현재 앱의 최초 실행·결제 화면, 조작 횟수, 애니메이션의 실제 속도와 배터리 사용은 실기기 확인 항목으로 남아 있다.

# 미감과 움직임을 평가하는 기준

| 평가 영역 | 구체적으로 볼 것 | 시제품에서 바꿔볼 것 |
| --- | --- | --- |
| 작은 크기의 형태 | 얼굴·몸통·다리가 뭉개지지 않는지, 어느 방향을 보는지 | 몸 비율, 외곽선, 가장 작은 표시 크기 |
| 개체 식별 단서 | 실제 개의 무늬·귀·꼬리·체형이 남는지 | 디테일의 유지·단순화 정도 |
| 배경과 조화 | 밝거나 어두운 배경, 복잡한 사진 배경에서 보이는지 | 색 대비, 바닥 접점, 보조 배경 |
| 동작 연결 | 정지→걷기→멈춤, 반응→휴식 전환에서 튀는지 | 전환 프레임, 가감속, 자세 연결 |
| 반복의 자연스러움 | 같은 루프가 지나치게 자주 눈에 들어오는지 | 쉬는 시간, 작은 고개 움직임, 행동 선택 간격 |
| 공간 점유 | 시각적으로 예뻐도 실제 조작을 가리거나 방해하는지 | 위치·크기·숨기기, 터치 영역 |

이는 우리 시제품의 제작·평가 항목이며 Pixel Pals의 측정 결과가 아니다. Pixel Pals의 프레임 수·속도·루프 간격은 공개 설명에서 확정하지 않는다. 정지 이미지 평가와 움직이는 상태 평가를 나누고, 외형의 선호와 자기 반려견다운 정도를 별도로 기록한다.

# iPhone 경험의 적용 범위

Apple은 위젯을 지속적인 실시간 갱신 화면으로 설명하지 않으며, 위젯·Live Activities의 데이터 갱신 애니메이션은 최대 2초로 제한한다. Pixel Pals의 홍보 문구나 과거 동작 사례를 모든 iPhone에서 무제한 상시 애니메이션이 가능하다는 근거로 사용하지 않는다. [Apple 위젯 지침](https://developer.apple.com/design/human-interface-guidelines/widgets) · [갱신 애니메이션](https://developer.apple.com/documentation/widgetkit/animating-data-updates-in-widgets-and-live-activities)

| 화면 | 우리 앱의 기본 범위 | 검증할 부분 |
| --- | --- | --- |
| 앱 내부 | 풍부한 연속 동작과 직접 상호작용 | 개체별 동작·전환, 반응, 발열 |
| Android 플로팅 | 기존 G0 범위의 표시·탭·이동·종료 | 권한, 앱 가림, 배터리, 화면 꺼짐·복귀 |
| 홈 화면 위젯 | 같은 반려견의 상태 표현과 지원되는 짧은 입력 | 갱신·반응 제약, 크기별 표현 |
| iOS 잠금 화면·StandBy | 운영체제가 지원하는 위젯 중심의 표현 | 지원 기기·OS, 정보량·가독성 |
| Dynamic Island·Live Activities | 후속 기술 검증 후보 | 표시 수명, 갱신, 정책 적합성. 상시 표시를 기본 약속으로 삼지 않음 |

Pixel Pals가 iOS의 여러 표시 기능을 활용한다는 점은 참고하되, 기존 Android 기술 검증 순서와 양 플랫폼 지원 방향은 유지한다. 새로운 iOS 표시 기능을 추가하려고 핵심 개인화 시제품의 범위를 넓히지 않는다.

# 수익모델에서 비교할 것

기성 캐릭터의 종류와 기능을 늘려 구독 가치를 만드는 방식, 개별 반려견의 완성된 외형·움직임에 결제받는 방식은 제공 가치가 다르다. Pixel Pals의 월·연·평생 구매 선택지는 비교하되, 그 구성을 그대로 채택하기 전에 우리 고객이 무엇을 계속 받고 싶은지 확인한다.

| 비교 과제 | 질문 |
| --- | --- |
| 첫 구매 | 내가 제공한 사진으로 만든 결과물과 움직임을 본 뒤 결제할 이유가 있는가 |
| 범위 이해 | 기본 구매에 어떤 동작·표시 기능·수정이 포함되는지 이해하는가 |
| 추가 구매 | 같은 개의 실제 버릇, 새 장면, 다른 화풍에 추가로 결제할 이유가 있는가 |
| 반복 구독 | 매달 계속 제공받고 싶은 기능·콘텐츠가 실제로 있는가 |
| 원가 | 미감과 개체 유사도를 맞추는 제작·수정 시간이 구매금액으로 감당되는가 |

현재 수익모델 가설은 개인화 기본 구매와 선택형 확장 구매로 유지한다. 구독은 반복 이용할 가치가 확인되면 비교한다. Pixel Pals의 과거 매출 발언과 최신 공개 가격은 [경쟁사 매출 구조 분석](./07_competitor_revenue.md)에 정리되어 있다.

# 첫 시제품과 비교 과제

먼저 한 마리의 외형, 걷기·쉬기·터치 반응, 동작 간 전환을 높은 완성도로 제작한다. 외형 시안은 실제 작은 표시 크기와 밝은·어두운 배경에서 본다. 이후 실제 반려견 자료를 반영한 대표 버릇 하나를 추가해, 같은 외형에 일반 동작만 있는 버전과 비교한다.

| 결과물 | 포함 내용 | 확인할 판단 |
| --- | --- | --- |
| 캐릭터 미리보기 | 실제 사진과 캐릭터 비교, 움직임 재생, 수정 요청 | 보기 좋음과 자기 개 유사도가 모두 확보되는가 |
| 곁에 두기 설정 | 플랫폼별 지원 위치, 크기, 표시·숨기기 | 사용자가 원하는 위치에 스스로 배치하는가 |
| 개인화 행동 비교 | 같은 외형에서 일반 행동과 실제 버릇 반영 행동 비교 | 행동 개인화의 차이를 알아보고 자료 제공·추가 결제를 선택하는가 |
| 구매 범위 시안 | 기본 상품과 추가 동작, 수정 범위, 결제 방식 | 구매 이유와 포함 범위를 설명할 수 있는가 |

같은 원본 사진·표시 크기·장면 길이로 비교하고 제시 순서를 바꾼다. Pixel Pals의 기성 캐릭터와 우리 개인화 캐릭터를 비교할 때에는 미감·사용 경험 평가와 실제 개체 유사도 평가를 분리한다. 본인 개의 자료를 쓰는 쪽이 유리한 조건을 미감 우위로 오인하지 않는다.
