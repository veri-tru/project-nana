# 얼굴·시선 움직임 정책 반영안

작성: 2026-11-01. 상태: **제작 정책 정본 v1.0 / 2026-11-01 정본화 / 자산·재생 승인 별도**.

사용자의 ‘2번까지’ 지시에 따라 정책 정본화와 P1 세 장면 연속 프레임 후보 제작을 진행했다. 이 문서의 부위별 정의·접촉·충돌·점눈 표현·복귀 규칙을 현재 제작 기준으로 사용한다. 문헌의 관찰 범위와 제작 규칙을 구분하며, 후순위 후보·미정 값은 확정값으로 승격하지 않는다. 세부 상황 규칙은 [상황 정책 v1.0](contextual-motion-policy.md), 변경 결정은 [결정 기록](decisions.md)을 따른다.

같은 날 후속 요청으로 [상황별 시선·표정·몸 동작 연결 정책](contextual-motion-policy.md)을 추가했다. 이 문서는 부위별 동작·충돌·자산 규칙을 맡고, 상황별 연결 정책은 사건·대상·활동에 맞는 동작 묶음의 선택과 종료·복귀를 맡는다. 부위의 독립 제어가 상황과 무관한 무작위 재생을 뜻하지 않는다.

사용자 요청인 ‘안면근육 및 혀·입 동작을 현재 움직임 정책에 반영할 수 있도록 정리’와 후속 ‘시선과 몸 동작의 분리 근거 조사’를 연결했다. 문헌에서 확인한 움직임 정의와 프로젝트용 제작 규칙을 구분한다. 문서화는 완료했지만 새 프레임 제작, 앱 구현, 실제 개체의 습관 확인, 최종 시각 승인을 뜻하지 않는다.

기존 [자산 규격](asset-spec.md), [개체 개인화 설계](personalization-spec.md), [현재 사양](current-spec.md)을 보완한다. 8fps·기본 125ms, 시간 기반 이동, 방향별 무늬 보존, 기준점·접지, 개체 근거 분리 원칙은 유지한다. G0의 걷기·쉬기·잠든 자세 범위를 확대하지 않으며, 아래는 후속 자산 제작·G1 개인화에서 사용할 연결안이다.

## 1. 동작을 선택하는 기준

1. 감정 이름 대신 관찰 가능한 동작을 지정한다. 예: `입꼬리 뒤로 당김 + 턱 내림 + 혀 보임`.
2. 문헌의 동작 정의, 특정 개체의 관찰·보호자 보고, 제작용 변형값을 별도 보관한다. 문헌 정의만으로 해당 개체의 빈도·상황을 채우지 않는다.
3. DogFACS AU/AD는 동작을 구분하는 참고 코드다. 영상의 근육 수축을 직접 측정한 값이나 감정 분류기가 아니다. 제작 클립을 공인 DogFACS 코딩 결과로 표시하지 않는다.
4. `관찰되지 않음`, `가려져 확인 불가`, `자산에서 표현 불가`, `동작 없음`을 구분한다. 보이지 않는 쪽 눈·입술을 자동 추정해 채우지 않는다.
5. 정적 시안의 입 벌림과 혀 노출은 호흡 리듬의 근거가 아니다. 몸 털기 그림 한 장도 실제 흔들림·시선 안정성을 증명하지 않는다.

## 2. 제어 부위를 분리한다

다음 항목은 논리적으로 별도 기록한다. 실제 제작은 레이어, 완성 프레임, 조합별 클립 중 어떤 방식도 가능하며 새 리깅 엔진을 필수로 요구하지 않는다.

| 제어 항목 | 담당 내용 | 다른 항목과의 경계 |
| --- | --- | --- |
| 화면 위치·이동 | 위치, 이동 경로, 속도, 멈춤 | 바라보는 대상이 바뀌었다고 이동 경로를 자동 변경하지 않음 |
| 몸통·사지 | 몸통 방향, 자세, 보행 위상, 발 접촉 | 머리 돌림 때문에 보행 프레임을 처음부터 재시작하지 않음 |
| 머리 | 몸통에 대한 수평 회전·들기/숙이기·기울임 | 수평 고개 돌림과 갸웃하기를 별개로 기록 |
| 눈의 방향 | 머리에 대한 상대적인 바라봄 방향 | 머리 방향과 같다고 간주하지 않음. 보이지 않으면 미확인 |
| 눈꺼풀·눈썹 부위 | 깜박임, 감기, 안쪽 피부 올림 | 시선 이동, 수면, 놀람과 자동 결합하지 않음 |
| 입술·입꼬리 | 윗입술 올림, 아랫입술 내림, 앞·뒤 당김, 벌어짐 | 턱뼈 움직임과 분리 |
| 턱 | 편안한 벌림, 능동적인 큰 벌림, 닫힘 | 입술 벌어짐이나 혀 노출과 동일시하지 않음 |
| 혀 | 노출, 전진·회수, 휨, 접촉 대상·경로 | 입술 쓸기·코 핥기·물체 핥기를 분리 |
| 귀 | 기저부 이동·회전, 처진 귀 끝의 후속 흔들림 | 머리 회전에 딸려 움직이는 것과 능동 귀 움직임을 구별 |

화면상의 시선 표현은 `몸통 방향 + 머리의 상대 방향 + 눈의 상대 방향`을 함께 고려한다. 이는 제작용 좌표 계층이며 생체의 완전한 독립 제어를 주장하는 식이 아니다. 회전은 각 방향의 실제 자산·가림·연결점에 맞춰 합성한다. 개의 눈·목 회전 한계나 눈→머리 지연 시간을 사람 연구에서 가져오지 않는다. [시선 근거와 한계](gaze-motion-research-20261101.md)

## 3. 얼굴 동작 사전

원어 근육명은 참고 해부학이며 런타임 제어변수나 단일 근육 활성의 확정값이 아니다. 앞/뒤는 화면 좌우가 아니라 코끝/귀 방향이다.

| 제작 동작 | DogFACS 참고 | 해부학적 대응 | 필요한 시각 변화·구분 |
| --- | --- | --- | --- |
| 눈썹 안쪽 올리기 | AU101 | LAOM: levator anguli oculi medialis | 눈 위 안쪽 피부를 위·안쪽으로 이동. 안구 이동·눈 크기 확대와 다름 |
| 깜박임 / 눈 감기 | AU145 / AU143 | orbicularis oculi 중심 | 눈꺼풀이 접촉해 완전히 덮이는 구간과 다시 여는 구간을 기록 |
| 윗입술 올리기 | AU110 | levator nasolabialis, caninus, levator labii maxillaris 관련 근육군 | 윗입술이 올라가며 턱 벌림 없이도 나타날 수 있음 |
| 코 주름과 윗입술 올리기 | AU109+110 | 위 근육군 | 주둥이 윗면 주름과 위쪽 이동을 함께 확인. 주름이 가려지면 임의로 추가하지 않음 |
| 입꼬리 뒤로 당기기 | AU12 | zygomaticus | 입꼬리를 귀 쪽으로 이동. 사람의 위로 휘어진 미소로 대체하지 않음 |
| 아랫입술 내리기 | AU116 | platysma | 아랫입술 자체의 하강. 아래턱 전체 하강과 분리 |
| 입술 오므리기 | AU118 | orbicularis oris 중심 | 입꼬리를 코끝 쪽으로 이동. AU12와 같은 채널에서 반대 끝점으로 취급 |
| 입술 벌어짐 | AU25 | 여러 입술 주변 근육의 작용·이완 | 입술 사이의 분리. 치아 사이 간격·턱 개방과 별도 |
| 편안한 턱 내림 | AU26 | 턱 여닫기 관련 근육의 조절 | 긴장 없이 내려간 턱과 치아 간 간격을 표현 |
| 능동적인 큰 턱 벌림 | AU27 | digastricus 등 턱 열기 관련 구조 | 크게 벌리는 동작. 입꼬리 좌우 늘림이나 일반 AU26과 구별 |
| 혀 보이기 | AD19 | 외재·내재설근의 협력 | 혀가 적어도 아랫입술 안쪽까지 전진해 보임. 길게 내밀 필요 없음 |
| 윗입술 쓸기 | AD37 | 동일 | 윗입술 바깥면을 입 중앙에서 한쪽 입꼬리로 쓸기. 접촉 경로 필수 |
| 코 핥기 | AD137 | 동일 | 혀가 위로 나와 코 표면을 닦고 회수. 입술 접촉만으로 대체 금지 |
| 헐떡임 | AD126 | 턱·혀·호흡의 복합 행동 | AU26 + AD19에 짧고 빠른 호흡이 동반된 동적 표현 |
| 입술 부풀리기 / 빨아들이기 | AD33 / AD35 | 공기 흐름·입술 상태를 포함한 복합 동작 | 배출 공기로 부풂 / 윗입술이 입안으로 들어감. 후순위 후보 |

해부학 참고: 이설근(genioglossus)은 혀 전진 및 섬유별 혀끝 회수, 경돌설근(styloglossus)은 후퇴·거상, 설골설근(hyoglossus)은 후퇴·하강에 관여한다. 내재설근은 국소 형태를 협력해 조절한다. 특정 핥기 한 종류에 근육 하나를 지정하지 않는다. 악이복근은 턱 열기, 측두근·교근·익돌근군은 닫기와 관련된다. [F1–F4]

## 4. 중첩·충돌·복귀 규칙

다음은 문헌에서 측정한 생체 규칙이 아니라 **프로젝트 제작 제안**이다.

| 조합 | 처리안 | 검수 기준 |
| --- | --- | --- |
| 걷기 + 바라보기/고개 돌리기 | 보행·이동을 유지하며 지원된 얼굴·머리 변형을 중첩 | 발 접지·주둥이 방향·목 연결 유지. 시선 변경만으로 경로 회전 금지 |
| 쉬기 + 깜박임/혀 노출 | 몸 자세를 유지하는 짧은 동작 후보 | 몸통이 매번 들썩이거나 지지 중인 머리가 떠오르지 않음 |
| AU12 + AU118 | 같은 입꼬리 채널의 상반된 목표이므로 동시 최대 적용 금지 | 한쪽 방향을 선택하거나 중립을 거쳐 전환. 입꼬리 이중 생성 금지 |
| AU26 + AU27 | 턱 상태는 한 가지로 평가하고 필요 시 전환 | 턱이 두 개로 갈라지거나 서로 다른 간격이 중첩되지 않음 |
| 코 핥기 + 입술 쓸기 | 한 혀 경로만 소유. 연속이면 회수/접촉 전환을 명시 | 같은 혀가 동시에 코와 먼 입꼬리에 붙지 않음 |
| 헐떡임 + 핥기 | 별도 결합 자산이 없으면 헐떡임 루프를 잠시 양보하고 핥기 뒤 복귀 | 혀·입·호흡 위상의 갑작스러운 중첩 방지. 생물학적 동시 발생 불가능 주장 아님 |
| 물체 물기 + 큰 턱 벌림/핥기 | 물체와 접촉을 유지하는 검수된 조합이 없으면 요청을 보류 | 물체가 떠 있거나 주둥이·혀를 관통하지 않음 |
| 몸 털기 + 대상 고정 시선 | 초기 자산에서는 몸 털기가 머리 채널을 소유하고 시선 요청은 보류 | 털기 중 얼굴만 화면에 고정되는 오류 방지. 전정안반사 모델로 주장하지 않음 |
| 잠든 자세 + 시선 요청 | 수면 상태를 유지하거나 별도 기상 전환 뒤 시선 허용 | 눈을 감은 채 눈동자 표시, 즉시 전신 방향 전환 금지 |

공통 흐름은 `현재 지원 자세 → 진입 → 필요한 유지/접촉 → 해제 → 해당 몸 자세의 중립 얼굴`이다. 모든 동작에 무조건 유지 단계를 넣지는 않는다. 갑작스러운 요청 교체는 기존 채널을 안전하게 해제한 뒤 적용하고, 지원되지 않는 조합은 다른 감정·행동으로 자동 변환하지 않는다.

여기서 중립 얼굴은 일률적인 닫힌 입이 아니라 **종료 시점의** 자세·활동·호흡·물체 접촉에 맞는 기본 얼굴이다. 상황에 연결된 시선과 얼굴은 같은 반응 ID·대상·단계를 공유한다. 진행 중 몸 상태가 바뀌면 진입 당시 상태로 강제 복원하지 않는다. 대상 소멸·오래된 요청·중복 사건 처리는 [상황별 연결 정책](contextual-motion-policy.md)을 따른다.

## 5. 시선과 몸의 결합 정책

### 별도 대상과 상태

- `gaze_target`: 현재 보도록 연출하는 대상. 보호자·손·물체·이동 방향 등과 대상 위치/참조 좌표를 기록한다.
- `locomotion_target`: 이동 목적지. `gaze_target`의 변경으로 덮어쓰지 않는다.
- `body_pose`, `body_heading`, `gait_phase`: 몸 자세·방향·보행 위상.
- `head_relative_pose`, `eye_relative_direction`: 몸에 대한 머리와 머리에 대한 눈의 상대 방향. 좌우 눈의 가시성도 기록한다.
- `target_source`: 영상 관찰 / 보호자 보고 / 문헌 일반 정의 / 제작 기본값 중 해당 근거를 구별한다.

이는 제안 필드이며 현재 앱 API나 확정 JSON 스키마가 아니다. 실제 자산의 회전 범위·표현 한계·지연값은 미측정이면 비워 둔다.

### 제작할 수 있는 조합

| 조합 후보 | 고정하거나 유지할 것 | 별도로 변화할 것 | 근거 상태 |
| --- | --- | --- | --- |
| 머리 유지 + 눈으로 대상 전환 | 몸·머리 | 눈 방향 | 머리를 지지한 눈추적 연구가 가능성을 지지. 일상 빈도·각도는 미확정 |
| 몸 자세 유지 + 고개 돌림 | 몸통·발 지지 | 머리와 필요한 눈 방향 | LOOK와 HEAD_TURN을 분리한 기존 DB 및 공개 보고 참고 |
| 걷는 중 잠깐 뒤 보기 | 진행 경로·보행 | 머리/눈 대상의 일시 전환 | 보호자 공개 보고. 완전한 시선·운동학 실측 아님 |
| 사람 ↔ 물체 번갈아 보기 | 지원되는 몸 자세 | 두 대상 사이의 머리/눈 방향 | 실험 근거 있음. 일부 논문은 코·머리 방향을 측정한 것이므로 눈동자 운동으로 확대하지 않음 |
| 대상을 바라본 뒤 접근 | 바라보기 단계에서 이동 보류 가능 | 이후 별도 접근 결정으로 몸·발 전환 | 바라봄과 선택을 별도 측정한 실험을 참고한 제작 구조 |

항상 눈→머리→몸 순서로 움직이게 만들지 않는다. 눈 먼저·머리 동시·고개만·몸까지 전환 중 지원된 조합을 선택한다. 이 순서·시차는 실제 영상에서 확인하거나 제작값으로 표시한다. 뒤를 보려는 목표가 현재 자산 범위를 넘으면 지원된 고개 돌림/몸 회전 클립으로 넘기거나 보류한다. 180도 눈동자 회전, 목 관통, 전체 이미지 좌우 반전으로 해결하지 않는다.

## 6. 8fps와 시간 기록

- 기본 프레임 유지 시간 125ms는 기존 확정값이다. 움직임 선택·이동·상태 체류와 그림 교체 시계를 분리한다.
- 실제 관찰의 반응 지연·지속 시간은 원영상 타임스탬프로 기록하고, 제작 시 조절한 `render_duration_ms`와 구별한다. SNS 편집 영상의 재생 속도를 생체 속도로 쓰지 않는다.
- [F2]의 AU145/AU143 구분은 눈이 **완전히 덮인 구간**의 0.5초 미만/이상이다. 전체 닫기-열기 클립 길이와 혼동하지 않는다. 일정 125ms 프레임에서는 완전 폐쇄 4프레임이 500ms라는 산술적 대응만 가능하며, 이를 실제 개의 자연스러운 깜박임 권장값으로 쓰지 않는다.
- 빠른 눈 이동·혀 이동이 한 프레임에 생략될 수 있으므로 8fps에서 동작이 보였다고 실제 속도를 재현했다고 보고하지 않는다. 방향 전환·접촉·회수의 가독성을 검수한다.
- 핥기 빈도, 뒤돌아보기 간격, 호흡수, 눈→머리 지연의 공통 숫자는 이번 문헌으로 고정하지 않는다. 확인된 개체값이 없으면 미정 또는 제작 기본값임을 명시한다.

## 7. 현재 P1 시안에 적용하는 우선순위

자세 참고는 [P1 내부 기준 수정안](../outputs/dog-crayon-p1-policy-20261101/README.md), 최신 선·채움 참고는 [약한 외곽선 A](../outputs/dog-crayon-outline-levels-20261101/README.md)다. 1254×1254 참고 원본과 별도로 [세 장면의 400×400 연속 프레임 후보](../outputs/dog-crayon-p1-sequences-20261101/README.md)를 만들었다. 이 크기는 후보 프레임의 포장 캔버스이며 최종 자산 해상도를 확정하지 않는다. 작은 원형 점눈에 대한 사용자 선호는 유지한다. 이는 실제 표시 해상도·애니메이션 승인과 별개다.

1. 첫 검토 후보는 **깜박임, 편안한 턱 벌림, 짧은 혀 보임, 코 핥기, 몸 자세를 유지한 고개 돌림**이다. 실제 개체에서 한다는 근거는 별도로 확인한다.
2. 코 핥기와 입술 쓸기는 접촉 위치가 식별되는 자산을 각각 제작한다. 수염·주둥이 윤곽 때문에 구별되지 않으면 과장으로 감추지 말고 미지원/재검토로 표시한다.
3. 점눈에는 흰자·홍채가 분리돼 있지 않다. 점눈 전체를 얼굴 위로 미끄러뜨려 눈동자 회전을 흉내 내거나, 시선을 강조하려고 큰 흰자·사람 눈썹을 추가하지 않는다. 우선 머리 방향으로 표현하고, 눈 방향은 내부 데이터상 분리하되 시각적으로 미표현임을 명시한다. 눈만 움직이는 변형은 별도 스타일 후보와 검수가 필요하다.
4. AU101은 털·피부 변형으로 표현할 수 있는지 후순위로 검토한다. 구별되지 않는다고 눈 크기나 흰 이마 무늬를 바꾸지 않는다.
5. 보행·기지개·몸 털기마다 고정된 ‘웃는 입’을 자동 부착하지 않는다. 기존 그림의 열린 입도 관찰된 감정·호흡으로 등록하지 않는다.
6. 혀는 입안에서 나오고 되돌아가야 한다. 털 위에서 생기거나 턱 아래를 관통하지 않도록 주둥이·입술·치아·혀의 가림 순서를 확인한다.
7. 고개·입을 바꾸더라도 기존의 회색/흰색 무늬, 귀 형태, 수염, 얼굴 폭, 비대칭 특징과 몸 접지를 유지한다. 낮은 꼬리 배치는 기존 비교 세트의 제작 선택이지 새 행동 법칙이 아니다.

## 8. 기존 행동 DB와 연결

DB 2.0.0의 기존 코드와 정의를 읽고 대응했다. **이번에는 DB/SQLite/Excel·원기록을 수정하지 않았다.**

| 기존 코드 | 이번 반영안의 연결 | 유지할 구분 |
| --- | --- | --- |
| BLINK / EYE_CLOSED / EYE_PART_CLOSED | 눈꺼풀 채널 | 깜박임·지속 폐쇄·부분 폐쇄를 합치지 않음 |
| INNER_BROW_RAISE | AU101 참고 | 눈의 상대 방향과 별개 |
| MOUTH_OPEN / MOUTH_CLOSED | 입술·턱 채널을 추가로 기술 | MOUTH_OPEN 한 코드로 AU25·26·27을 자동 확정하지 않음 |
| TONGUE_OUT | 혀 노출 채널 | 기존 DB는 ‘입 밖으로 보임’. AD19의 ‘아랫입술 안쪽까지’보다 범위가 좁으므로 완전 동의어로 치환하지 않음 |
| PANT / PLAY_PANT / MOUTH_OPEN_PLAY | 호흡·놀이 맥락을 별도 연결 | 정적 입 벌림·일반 헐떡임·놀이 특유 숨소리를 합치지 않음 |
| LICK | 혀의 접촉 대상·경로 세부화 | 원출처가 합산한 입 주변 핥기를 AD37/AD137로 소급 분해하지 않음 |
| LOOK / HEAD_TURN / HEAD_TILT | 바라봄 대상·머리 회전·기울임 분리 | LOOK를 정밀 눈추적값으로 승격하지 않음 |
| GAZE_ALTERNATE / LOOK_AWAY | 대상 전환 순서·관찰 방식 기록 | 머리 기반 보고인지 눈 방향 확인인지 남김. 외면을 불쾌감으로 자동 해석하지 않음 |

새 행동 원기록 ID나 근거 ID는 임의로 만들지 않는다. 세부 동작은 우선 클립 메타데이터 제안으로 보관하고, DB를 확장할 때 출처·정의·기존 코드 범위와 변환 검증을 별도 수행한다.

## 9. 자산별 추가 기록안과 통과 조건

기존 자산 메타데이터에 다음 내용을 연결하는 안이다. 실제 파일·좌표가 없는 값은 null/미정으로 두고 승인 상태를 채우지 않는다.

| 항목 | 내용 |
| --- | --- |
| 동작·근거 | action label, DogFACS 참고 코드, 기존 concept_id, 문헌/개체 근거와 관찰 방식 |
| 채널·범위 | 영향을 받는 부위, 부위별 소유 클립, 지원 방향·눈 가시성·머리 지지 자세 |
| 단계·시간 | 진입·접촉·회수·복귀, 제작 시간, 실제 관찰 시간 및 측정 여부 |
| 혀 접촉 | none / upper_lip / nose / object / unknown, 좌우·경로·실제 가림 상태 |
| 시선·이동 | gaze_target과 locomotion_target, 몸·머리·눈 상대 방향, 표현 불가 사유 |
| 충돌·중단 | 동시 사용 가능 조합, 채널 충돌 시 보류/해제/전환, 복귀 상태 |
| 검수 | 파일·버전·표시 크기·방향·실제 재생 근거, 미시험/통과/실패 |

- [ ] 정적 입 벌림·혀 노출과 헐떡임을 구별할 수 있다.
- [ ] 코 핥기와 윗입술 쓸기의 접촉 위치가 보이고, 혀가 입에서 출발해 회수된다.
- [ ] 입술·턱·혀가 서로 관통하거나 같은 부위가 중복 생성되지 않는다.
- [ ] 입꼬리 전후 이동이 사람식 미소·삐침으로 바뀌지 않는다.
- [ ] 깜박임 전체 길이와 완전 폐쇄 시간을 따로 확인했다.
- [ ] 같은 몸 자세에서 고개만 돌릴 때 발·몸 기준점·무늬가 유지된다.
- [ ] 걷는 중 고개 전환이 보행 위상을 초기화하거나 접지발을 미끄러뜨리지 않는다.
- [ ] 바라봄 대상 변경만으로 이동 목적지가 바뀌지 않는다.
- [ ] 점눈 스타일에서 표현하지 못한 눈 방향을 구현 완료로 보고하지 않는다.
- [ ] 동작 중단·복귀가 현재 몸 자세와 맞고 지원 범위 밖 요청이 안전하게 보류된다.
- [ ] 실제 표시 크기·8fps 재생·방향별 확인과 보호자 닮음 평가를 각각 기록했다.

현재 모든 자산별 검수 항목은 미실시다.
