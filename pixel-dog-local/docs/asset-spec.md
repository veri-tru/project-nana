# 픽셀 자산 규격 초안

## 2026-11-02 보완: 화풍 참조와 출력 검수

[화풍 참조 분리 정책](style-reference-policy.md)에 따라 실제 스타일 이미지의 파일·해시·참조 역할·사용 영역을 생성 기록에 포함한다. 사진의 잔털과 명암을 그대로 옮긴 그림을 픽셀 윤곽만으로 화풍 통과 처리하지 않는다. 개체 식별과 윤곽·색면·털 단순화의 검수 결과를 따로 남긴다. 고해상도 시안과 실제 96×96 실행 자산을 구분한다.

## 2026-11-02 개체 프로필과 생성·자산 버전 연결

개체 자산은 dog_id, 생성 당시 profile_revision, 표현 설정·제품 화풍 버전과 기준 자산을 필수로 연결한다. 새 동작에서 외형을 다시 임의 추정하지 않는다. 개체와 무관한 화풍 연구는 style_study로 구분하고 개체 자산으로 자동 승격하지 않는다. [생성 입력·수정 전파·사용 묶음 규칙](profile-generation-spec.md)을 따른다.

프로필 수정은 자산의 depends_on_fields와 대조해 재생성·재검수 범위를 정한다. 새로운 프로필과 유효성이 확인된 자산만 같은 release에 포함하고 한 번에 사용 대상으로 전환한다. 생성 실패·오래된 결과는 사용 중인 묶음을 자동 변경하지 않는다. 아래 크레용풍 P1 규정은 해당 이전 후보의 범위이며 모든 개체의 눈·눈꺼풀을 공통 모양으로 고정하는 기준이 아니다.

상태: 제안. G0과 첫 개체 시안 결과를 반영해 버전 1을 고정합니다.

공통 사양의 확정 여부는 [현재 사양](current-spec.md)을 먼저 확인합니다. 몸통·부품·동작의 실제 호환 판정과 개인화 연결 구조는 [개체 개인화 설계](personalization-spec.md)에 있습니다.

## 이미지와 프레임

- 제작 원본은 레이어와 프레임을 수정할 수 있는 편집 파일로 보관합니다.
- 실행 자산은 투명 PNG 시트 또는 동일 크기 PNG 프레임과 JSON 메타데이터를 기본 후보로 둡니다.
- 최종 해상도는 미정입니다. 64×64와 96×96을 교체할 수 있도록 원본 크기를 메타데이터로 관리합니다.
- 같은 캐릭터·동작의 캔버스 크기, 기준점, 접지선을 유지합니다. 잘린 프레임을 쓰면 원래 위치를 복구할 정보를 보존합니다.
- 얼굴의 큰 무늬, 귀·꼬리 모양, 다리 비율을 프레임 사이에 유지합니다. 비대칭 무늬는 좌우 반전으로 바꾸지 않습니다.
- 픽셀 경계를 유지하는 스케일링을 사용하고 실제 표시 크기에서 확인합니다. 미감과 개체 식별 효과는 별도로 평가합니다.

## 시간과 이동

기본 8fps = 125ms/프레임입니다. 같은 그림을 오래 유지할 수 있도록 프레임별 유지 시간을 둡니다. 입력 처리·상태 체류·화면 이동은 이 간격에 묶지 않습니다. 이동 속도는 초당 거리, 지속 시간은 ms로 표현합니다.

관찰된 반응 지연과 제작자가 조정한 애니메이션 길이는 별도의 값입니다. 화면상의 이동거리와 발이 땅에 닿아 있는 구간이 맞는지 확인합니다.

## 얼굴·혀·시선 동작의 추가 반영안

2026-11-01 사용자 요청으로 [얼굴·시선 움직임 정책 반영안](facial-motion-policy.md)을 정리했습니다. 입술·턱·혀와 눈·머리·몸통·이동을 별도 항목으로 기록하고, 접촉 경로·동작 충돌·복귀·8fps 검수 기준을 제안합니다. 관찰 가능한 동작 정의와 제작용 제어 규칙을 구분하며, 근육명이나 DogFACS 코드를 감정·개체 습관의 확정값으로 사용하지 않습니다.

현재 P1의 작은 점눈, 무늬·귀·비율과 접지 기준을 유지하는 적용 순서도 포함했습니다. 정책은 제작 정본 v1.0이며 [세 장면 연속 프레임 후보](../outputs/dog-crayon-p1-sequences-20261101/README.md) 36장을 제작했습니다. 눈동자만의 방향 표현·앱 실행 자산·3단계 재생 및 실기기 검수는 미실시입니다. [시선과 몸 분리의 문헌·공개 사례](gaze-motion-research-20261101.md)를 함께 참고합니다.

후속 [상황별 연결 정책](contextual-motion-policy.md)은 같은 사건·대상에 속한 시선·표정을 반응 단위로 연결합니다. 자산 검수에는 상황 진입·접촉·중단·현재 상태 복귀, 대상 소멸, 보행 위상 유지까지 포함합니다. 개별 얼굴 동작 파일의 존재만으로 해당 상황 조합을 지원한다고 표시하지 않습니다.

## 크레용풍 P1의 선과 채움 방향

2026-11-01 사용자 지시를 반영한 시안 제작 방향입니다. 픽셀 격자와 별개로 개체 특징·좌우 무늬·신체 구조의 일관성 기준은 유지합니다. 사용자가 외곽선은 [A의 약한 안](../outputs/dog-crayon-outline-levels-20261101/A-weak.png)을 선택했습니다. 전체 닮음·동작과 최종 실행 자산은 검토 중입니다.

- P1의 후속 그림은 A처럼 가늘고 약한 필압의 외곽선을 기준으로 합니다. 일부 자연스러운 끊김을 허용하며 얼굴·발·다리의 구분은 유지합니다. 현재 털 채움과 눈·코·혀는 선 강도를 바꾸기 위해 함께 변경하지 않습니다.

- 털의 회색·흰색 분포는 유지하고 회색 면을 채운 밀도는 조금만 낮춥니다. 넓은 회색 영역을 거의 빈 종이로 바꾸지 않습니다. 채움의 변화와 색상 변경은 별개입니다.
- 작고 둥근 점눈·코·혀에는 약한 필압 차이, 작은 가장자리 흔들림 등 손으로 그린 불완전함을 적용할 수 있습니다. 코 중앙에 구멍처럼 보이는 큰 밝은 틈을 만들지 않습니다.
- 빈틈을 좌우 짝·같은 간격·중앙 장식 패턴으로 반복하지 않습니다. 눈의 빈틈이 대칭적인 반짝임으로 보이지 않게 하고, 얼굴의 표식은 충분히 채워 명확히 읽히게 합니다.
- 작화의 비대칭은 선·채움의 표현이며 실제 개의 다리 길이·귀 구조·무늬를 비대칭으로 바꾸라는 뜻이 아닙니다. 한 캐릭터의 작화 특징을 프레임마다 무작위로 바꿔 깜빡이게 하지 않습니다.

현재 그림 기준은 v3에서 외곽선을 약하게 바꾼 [A 선택안](../outputs/dog-crayon-outline-levels-20261101/README.md)입니다. 걷기 한 장의 선 강도 선택이며 나머지 동작 적용·전체 닮음·애니메이션 승인은 아직 없습니다.
