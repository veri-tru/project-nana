# 털 요청·v03 연결 독립 기술 검토

검토일: 2026-11-07. 검토자: `/root/coat_review`. 구현자와 다른 에이전트가 실제 코드와 실행 결과를 확인했다.

**판정: PASS — JSON 요청 검증·기존 v03 길이 설정 연결·초안 파일 출력 범위. 미해결 BLOCKER/MAJOR 없음.**

이번 판정은 새 이미지의 외형·개체 닮음·화풍 승인 또는 native64 털 변형 지원을 뜻하지 않는다. 이미지를 저장하거나 사용자 관찰 DB를 수정하지 않는 연결 코드의 기술 검토다. 실제 참조 사진의 관찰은 별도 [참조 검토 기록](coat-reference-observations.md)을 따른다.

## 확인한 구현 범위

- `coat references`: 외부 사진의 출처·관찰·한계가 담긴 카탈로그를 조회한다. 참조 ID를 렌더 프리셋으로 변환하지 않는다.
- `coat describe`: 표현 요청을 기술하고 지원/미지원 항목을 구분한다. `static-v03`의 정수리·양쪽 귀·볼·가슴·발에 대한 `short/medium/long`만 적용 가능하다.
- `coat apply`: 원본 파일 해시·개체 ID·v03 스키마를 확인하고 `coat`만 변경한 초안과 적용 기록을 새 폴더에 기록한다. 지원/미지원이 섞인 요청을 부분 적용하지 않는다.
- 격리된 worker는 v03의 얼굴/앉은 전신 B2를 메모리에서 렌더해 입력 조합과 anchor 불변을 확인한다. 이미지 파일을 저장하지 않는다.
- `source_profile`, `migration`, `geometry`, `colors`, 개체 ID와 기존 관찰 근거는 보존한다. 결과의 검토 상태는 `unreviewed`이며 DB 인증 여부를 별도로 표시한다.
- mm·풍성함·결·피모 층·미용 형태, 양쪽 귀의 독립 설정, 3D 머리·native64 적용은 명시적으로 미지원 처리한다. 기존 0/1/2 제작 변위를 실측 mm로 해석하지 않는다.

## 검토 과정에서 보완한 사항

1. 의존성 해시는 worker 실행 전에 확보하고 출력 공개 전에 다시 대조하도록 구현자가 수정했다.
2. 참조 ID 검증과 기록용 해시가 동일한 카탈로그 바이트를 사용하도록 `catalog, catalog_raw`를 한 번 읽어 전달한다. 검증 뒤 다른 카탈로그 버전의 해시를 기록할 수 있던 간격을 제거했다.
3. worker 입출력에 UTF-8을 명시하고 검증 기록에 실제 Python/Pillow 버전을 포함했다.

최신 파일에서 위 수정 반영을 확인했다. 파일 저장은 대상과 같은 상위 폴더의 임시 디렉터리에서 준비한 뒤 이름을 변경하며, 기존 출력·검토 기록이 있는 디렉터리에 대한 덮어쓰기를 거절한다. 입력이 도중에 바뀌면 임시 출력도 정리한다.

## 직접 실행한 검사

독립 검토자가 실행한 명령:

```powershell
python -m unittest tools.dog_engine.tests.test_coat -q
```

결과: **11개 검사 통과**. 현재 파일을 기준으로 실제 v03 길이 변경의 픽셀 영향, anchor 유지, 입력 보존, 반복 출력 일치, 잘못된 타입/중복 키/비정상 수치/참조 ID 거절, 다른 개체·오래된 해시·package 거절, 덮어쓰기 차단, 실행 중 입력 변경 시 출력 미공개, CLI 종료 코드를 확인했다.

이 검사와 별도로 임시 합성 v03 상태를 만들어 `apply_file`을 호출했다. `coat` 외 모든 필드와 원본 파일이 보존되고 출력이 `draft-state.json`, `application.json` 두 파일뿐인지 확인했다. 기존 출력, 잘못된 원본 해시, 지원/미지원 혼합 요청을 거절했으며 실패 대상 폴더는 생성되지 않았다. 임시 자료는 검사 종료 후 정리했다.

`describe`의 정상 CLI 종료 0과 미지원 종료 2, schema/길이의 불리언 값·없는 참조 ID·빈 부위·NaN 거절, `head-3d`/`native64`의 빈 적용 patch도 직접 확인했다. 전체 저장소 회귀 검사는 구현 담당자가 별도로 수행하며 이 기록은 그 결과를 대신하지 않는다.

## 남은 범위

현재 연결은 기존 미승인 96px 정적 제작기의 제한된 길이 선택이다. 모든 품종의 미용·모량 자동 변형, 실제 mm 재현, 참조 사진과의 시각적 일치, 선택된 두 개체 C의 재현, 새 이미지 전달, native64 자산과 앱 적용은 이번 기술 PASS 범위에 포함되지 않는다. 해당 기능을 추가하거나 이미지를 저장·전달할 때는 기존 구조 및 독립 외형/기술 검토 절차를 따른다.
