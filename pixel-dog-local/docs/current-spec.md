## 해상도를 결정하는 절차

같은 개체와 특징, 같은 포즈·프레임 수·재생 시간으로 두 해상도를 비교한다. 원본 픽셀 수와 화면에 보이는 크기를 분리하여, 같은 기기와 같은 표시 너비에서 평가한다. 실제 적용 배율과 픽셀 경계 유지 여부도 기록한다.

보호자가 고른 특징의 식별, 앞발·입·꼬리의 동작 구분, 프레임 간 무늬 유지, 수정 소요와 재생 상태를 확인한 후 선택한다. 현재는 실제 자산과 평가 결과가 없으므로 최종값을 채우지 않는다. 한 마리에서의 선택 결과를 모든 체형에 검증된 해상도로 일반화하지 않는다.

## 기획 자료 간 적용 순서

최신 사용자 지시와 확정 결정이 우선이다. 이 문서는 현재 값을 모아 보여주고, 개인화·자산 문서는 해당 항목의 세부 규칙을 설명한다. config/project.json은 구현 전 기획 설정의 대응본이며 운영 중인 앱 설정이 아니다.

초기 보존 문서의 영상·반복 촬영 중심 수집안은 고도화 참고다. 첫 입력은 사진·응답 중심으로 검토한다. 96×96 참고 시안은 최종 해상도나 실제 개체 자산의 승인을 뜻하지 않는다. 기존 조사 DB의 출처 스냅샷과 archive 문서는 당시 기록으로 보존한다.
