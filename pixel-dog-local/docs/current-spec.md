# 현재 사양과 결정 상태

## 최신 구현 상태: 정적 제작기 0.2 — 2026-11-02

[0.2 제작기](../tools/static_maker/README.md)는 96px 정면 얼굴·앉은 전신의 연결점 기반 출력과 내부 로컬 편집 화면을 제공한다. 원본 관찰 프로필과 제작 상태 revision을 분리하고 0.1 경로를 보존한다. 눈 형태/기울기/가림·코/주둥이·턱과 정수리/귀/볼/가슴/발 털을 조절한다. B2/C2는 동일 기하에 외곽·겹침선 색 역할을 달리한다.

자동 검사 14개, 실제 Chromium 편집·저장·재로드·복원·오류 처리와 3개 새 프로세스 재현을 확인했다. [검수 기록](../tools/static_maker/VERIFY-v02.md). 닮음·정본 미감·실기기 표시 검수는 남아 있으며 최종 해상도/단일 화풍은 미정이다. 제작자 편집 화면은 제품의 사용자 3단계 앱 구현과 구분한다. 사진 자동 추출·동작·모바일 통합·다른 개체 지원 검증은 미구현이다. 아래 0.1 및 이전 설계 설명은 해당 시점의 이력이다.

## 2026-11-02 한 개체 정적 제작기 0.1 구현

[실행 코드와 안내](../tools/static_maker/README.md)를 추가했다. Python/Pillow와 SQLite로 프로필의 불변 revision·낙관적 수정 충돌 검사·재시작 복구·되돌리기를 구현하고, 프로필 기반 96×96 정면 얼굴/앉은 전신의 B2/C2 출력, 의미별 마스크·메타데이터·HTML 미리보기를 제공한다. 실제 이미지 모델 호출과 원본 사진 읽기 없이 출력한다.

합성 입력의 자동 검사 5개가 통과했다. 별도 임시 폴더에서 코드·스타일·프로필만 복사해 새 프로세스 3회의 4개 출력 RGBA 해시가 동일함을 확인했다. 실제 한 개체의 로컬 제작 프로필에서도 3회 동일 출력이 확인됐다. B2/C2는 동일 기하/마스크에 윤곽색만 다르고, 알파는 0/255·불투명 색 수는 24색 이하다. 출력 덮어쓰기를 거절한다.

개체 사진의 외형을 사람이 제작값으로 입력한 기술 프로토타입이다. 정면 처진 귀 계열만 지원하며 복잡한 무늬·다른 방향·64px·동작·사진 자동 추출·모바일·사용 묶음 전환 UI는 미구현이다. 털 길이 설정은 정수리 실루엣만 바꾼다. 정본 화풍과 닮음은 부분 충족/검수 대기, 보호자 승인은 없다. 단계 2의 전체 통과로 표시하지 않는다.

개인 프로필·DB·개체 결과는 로컬 /workspace/nana-maker/private 와 /workspace/nana-maker/output/final 에 보존하고 공개 Git에 넣지 않았다. 이 경로는 실행 환경 전용이다. 저장소에는 코드·가상 예제·테스트·실행 안내만 포함했다.


## 2026-11-02 현재 구현 우선순위

[로드맵](roadmap.md)을 지속 프로필 → 정적 제작기 → 다른 개체 재사용 → 동작 → 사진 입력/사용자 3단계 → Android 통합으로 갱신했다. 기존 Android G0 표시·입력·종료 검증은 병행한다. 제작 방식은 버전이 고정된 부품·마스크·팔레트·동작 패키지로 재현 가능한 출력을 검증하는 제안이며 미구현이다.

정본 이미지는 제작 패키지 개발·검수 기준으로 보존하고 제작기 실행의 매 요청 필수 입력으로 두지 않는 것을 목표로 한다. 실제 이미지 생성 도구 경로의 참조 이미지 필수 규칙은 유지한다. B2/C2 비교 정본, 사용자 3단계·개체별 외형/행동, 8fps·해상도 미정 상태는 유지한다. 기간·표본은 계획값이다.

## 2026-11-02 사용자 흐름과 지속 개체 프로필

사용자 흐름은 사진 등록 → 털 선택·모습 보기 → 행동 설정·결과 확인의 3단계다. 외형 추출·프로필 구성·자산 검수는 내부 처리이며, 부위별 선택·식별 특징 선정은 기본 필수 입력이 아니다. 결과 수락은 보여준 표현 범위에만 적용한다.

모든 개체 생성은 dog_id와 변경되지 않는 프로필 스냅샷, 표현·화풍 버전, 기준 자산을 필수 참조한다. 외형·행동·근거와 제작 설정을 분리하고, 수정 범위·후속 자산 영향·사용 묶음의 일관성을 관리한다. [상세 설계와 검증 시나리오](profile-generation-spec.md). 설계 반영 완료이며 앱·영속 저장·생성 엔진은 미구현이다.

기준일: 2026-10-18. 사양을 확인할 때 먼저 읽는 문서다. 확정값, 현재 설계 방향, 보완 초안과 미결정 항목을 구분한다. 사용자 지시와 [결정 기록](decisions.md)을 근거로 하며, 10월 18일 검토 의견의 세부 연결 규칙은 [개체 개인화 설계](personalization-spec.md)에 정리했다.

## 해상도를 결정하는 절차

같은 개체와 특징, 같은 포즈·프레임 수·재생 시간으로 두 해상도를 비교한다. 원본 픽셀 수와 화면에 보이는 크기를 분리하여, 같은 기기와 같은 표시 너비에서 평가한다. 실제 적용 배율과 픽셀 경계 유지 여부도 기록한다.

보호자가 고른 특징의 식별, 앞발·입·꼬리의 동작 구분, 프레임 간 무늬 유지, 수정 소요와 재생 상태를 확인한 후 선택한다. 현재는 실제 자산과 평가 결과가 없으므로 최종값을 채우지 않는다. 한 마리에서의 선택 결과를 모든 체형에 검증된 해상도로 일반화하지 않는다.

## 기획 자료 간 적용 순서

최신 사용자 지시와 확정 결정이 우선이다. 이 문서는 현재 값을 모아 보여주고, 개인화·자산 문서는 해당 항목의 세부 규칙을 설명한다. config/project.json은 구현 전 기획 설정의 대응본이며 운영 중인 앱 설정이 아니다.

초기 보존 문서의 영상·반복 촬영 중심 수집안은 고도화 참고다. 첫 입력은 사진·응답 중심으로 검토한다. 96×96 참고 시안은 최종 해상도나 실제 개체 자산의 승인을 뜻하지 않는다. 기존 조사 DB의 출처 스냅샷과 archive 문서는 당시 기록으로 보존한다.
