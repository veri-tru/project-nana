# 실행 환경·상태·문서 드리프트 정리

기준일: 2026-11-12. 사용자 요청은 “일단 드리프트들 부터 제거”다. 현재 사용자 선택과 검토 범위는 유지하고 실제 구현·기록·실행 환경 사이의 차이를 정리한다.

## 원인과 변경

| 발견한 차이 | 처리 |

## 검증

- 전용 환경 설치 완료, `pip check`와 `doctor` PASS.
- 이전에 실패한 골든 참조 PNG 바이트 동일성 검사 PASS.
- 선택 이미지/선택 기록/검토 무효화·범위 확대·간접 의존성 변경·환경 사전 차단을 확인하는 새 회귀 7개 PASS.
- `./engine.ps1 verify` 전체 **166개 PASS**: 기존 머리 21개, 정적 제작기 52개, 활성 엔진 93개(새 상태 회귀 7개 포함). 기존 골든 참조 PNG와 native64 atlas 바이트 비교도 포함한다.
- C 정본 1건과 최신 가슴 음영 구조/native64 9건의 기존 전달 기록 검사 **10/10 READY**. 새 시각 리뷰나 사용자 승인으로 대체하지 않는다.
- 전역 Python으로 `verify`를 실행하면 NumPy와 간접 의존성 차이를 보고하고 렌더 전에 exit 1로 차단하는 실제 실행을 확인했다.
- 프로젝트 바깥 폴더에서 `engine.ps1 coat describe --request ...`를 호출해 작업 폴더·인수 전달·종료 코드가 유지되는지 확인했다.
- 수정한 안내 문서 12개의 내부 파일 링크 누락 0건, `git diff --check` 통과.
- `git diff --name-only HEAD -- outputs tools/head_engine tools/review references/styles`의 출력은 없다. 보호된 기준 이미지·보존 코드·검토 도구·스타일 참조에 추적 변경이 없다.

기존 정적 제작기의 Pillow `getdata` 사용 중단 예정 경고는 남아 있다. 현재 버전의 오류나 이번 재현성 실패는 아니며, 보존 경로의 API 이관은 별도 변경과 검증이 필요하다. 드리프트 정리 완료 시점에는 로컬 변경만 있었고, 이후 사용자 “머지까지” 요청에 따라 기존 후속 구현과 이번 수정을 `codex/engine-drift-cleanup-20261112` 브랜치에서 함께 커밋·PR 병합한다. 사용자 사진·비공개 결과·로컬 환경은 버전 관리에서 제외한다. 새 bridge와 선택/거절 메타데이터에도 해시 보존용 줄바꿈 규칙을 적용한다.

## 유지한 경계

두 개체 C는 고해상도 5시점 표현 정본이다. 골든 P1/P2/P3의 화풍 거절과 진단 전용 상태, 등록 말티푸 털의 회색 진단 범위, 최신 털 결과의 사용자 PENDING을 유지한다. 볼·귀 풍성함·결·미용 형태, B2/C native64 화풍·닮음·실기기 승인, 머리·전신 연결·동작·앱은 이번 수정으로 완료되지 않는다. 기존 기준 이미지·모델·생성 코드·검토 기록·사용자 사진은 변경하지 않는다.
