# 프로젝트 개요

전체 현황과 자료 연결은 [기획 종합 정리](planning-summary.md)를 먼저 확인합니다.

사양의 확정 여부는 [현재 사양](current-spec.md), 속성별 근거와 부품·동작 연결은 [개체 개인화 설계](personalization-spec.md)를 확인합니다. 최근 보완안은 개체 외형 설정 → 부품·동작 호환 → 한 마리 닮음 검증 순서입니다.

## 제품 목표

보호자가 휴대폰에서 자신의 강아지와 닮은 외형과 익숙한 행동을 접하게 합니다. 행동 개인화를 핵심 차별점으로 유지하고, 미리 준비한 동작을 사진과 보호자 응답에 맞추는 방식을 검토합니다. 미감·움직임의 완성도와 함께 행동의 순서·타이밍이 자기 강아지다움에 주는 효과를 검증합니다.

실시간으로 실제 반려견의 현재 상태를 보여 주거나 마음을 읽는 서비스로 설명하지 않습니다. 프로젝트의 ‘디지털 트윈’은 작업명입니다.

## 사용자와 사업 가설

초기 대상은 현재 반려견을 기르며 개인화 결과물에 관심이 있는 보호자입니다. 사진과 짧은 응답으로 시작하고 영상 제출 부담을 줄이는 방향입니다. 연령·성별에 따른 실제 구매율은 미확인입니다. 미감에 대한 자신감은 제품 방향이며 고객 검증 결과와 구분합니다. 개인화 결과물의 일회성 구매와 선택형 확장 구매를 우선 가설로 두며 가격·구독 여부는 미정입니다.

2026-10-17 사용자가 선택한 검증 가설은 **20대 여성을 첫 고객 후보로, 30대 여성을 유료 개인화 구매 후보로 검증**하는 것입니다. 실제 구매율과 연령·성별에 따른 니즈 차이는 미확인입니다. [사용자 니즈 조사와 검증안](customer-needs-2026-10-17.md)을 기준으로 두 집단에 동일한 과제를 적용합니다.

시장 및 매출 관련 근거는 [시장 조사](archive/06_market_competitors.md)와 [경쟁사 수익 구조](archive/07_competitor_revenue.md)를 확인합니다. 경쟁사의 추정 다운로드·평가 수를 우리 앱의 매출 예측으로 직접 바꾸지 않습니다.

## 제품 구성

1. 기존 사진과 짧은 보호자 응답으로 외형·행동 후보를 선택합니다.
2. 직접 보이는 특징과 보호자 보고, 제작 기본값을 구분합니다.
3. 보호자가 후보와 동작 미리보기를 보고 수락·수정·제외합니다.
4. 확인된 프로필을 제작한 외형·동작 자산과 연결합니다.
5. 기기에서 재생하고 필요할 때 사진·응답·짧은 영상을 추가합니다. 첫 입력의 영상은 필수로 두지 않는 안입니다.

AI는 후보 추출과 기록 구조화에 사용합니다. 픽셀 그림과 동작 자산은 별도 제작하며 평소 재생에 API를 호출하지 않습니다.

## 개발 단계

| 단계 | 범위 | 상태 |
| --- | --- | --- |
| M0 | 목표 사용자·경쟁사·가치·가격·수집 부담 검토 | 공개자료 조사 완료, 고객 검증 미실시 |
| G0 | Android 표시·입력·종료 검증 | 착수 전 |
| G1 | 한 마리의 외형·행동 개인화. 기본 8종·대표 행동 최대 3개는 초안이며 몸 털기·기지개를 별도로 포함 | 설계 초안, 자료 준비 |
| G2 | 5~10마리·총 30~50장면의 탐색 파일럿 | 제안 규모, 검정력 기반 표본 아님 |
| G3 | iOS 앱과 양 플랫폼 위젯 등 | 후속 |

## G0 기술 기본안

Kotlin 네이티브로 작은 Android 오버레이와 앱 내 표시를 검증합니다. 걷기·쉬기·잠든 자세를 임시값으로 재생하고 탭과 드래그를 구분합니다. 표시 켜기·끄기, 권한 철회, 화면 꺼짐, 프로세스 종료를 다룹니다. 화면 바깥 터치를 방해하지 않는지 실제 기기에서 확인합니다.

OS·서비스·배포 조건은 개발할 SDK와 목표 OS에 맞춰 공식 문서를 확인합니다. 기존 조사 근거는 [개발 지침](archive/00_project_guidance.md)과 [상세 설계](archive/05_detailed_design.md)에 있습니다.

## 미결정 사항

서비스명, 최종 해상도·팔레트·화풍, 최소 지원 OS, 테스트 기기, 공통 UI 프레임워크, 제작 도구, AI API의 실제 연결 설정, 가격과 출시 범위는 미정입니다. G0을 시작하는 데 모든 항목을 확정할 필요는 없습니다.
