# 개의 시선·머리·몸 방향 분리: 문헌과 공개 사례

검색일: 2026-11-01. 목적: [얼굴·시선 움직임 정책 반영안](facial-motion-policy.md)의 근거와 제작 참고 후보 정리.

## 결론

**눈의 방향, 머리 방향, 몸통 방향, 이동은 따로 기록·제어할 가치가 있다.** 개의 눈추적 연구는 머리 방향만으로 놓치는 짧은 바라봄을 보여 주고, 머리를 지지한 상태에서도 시선의 위치 변화를 측정한다. 다만 네 요소가 생체에서 완전히 독립적이라는 뜻은 아니다. 눈·목의 운동 범위, 자세, 대상과 과제에 따라 함께 작동한다. ‘항상 눈이 먼저, 머리가 다음, 몸이 마지막’이라는 고정 순서·지연 시간은 이번 근거로 확정하지 않는다.[G1, G2]

## 검색·확인 범위

Exa에서 8회 검색으로 결과 47건을 요청·수집 시도했다(중복·검색 결과 없음 포함한 검색 규모이며 독립 출처 수가 아니다). 검색 영역은 눈-머리 측정, 바라봄과 이동/대상 선택, SNS·보호자 보고다. 주요 논문과 공개 게시글은 본문/방법 또는 초록을 확인했고, SNS는 원게시물 연결과 보도 설명을 구분했다. 공개 영상의 프레임별 분석이나 행동 빈도 측정은 하지 않았다. 체계적 문헌고찰은 아니다.

## 채택하지 않은 자료와 해석

- 사람을 대상으로 한 눈·머리 협응 연구의 회전 각도·시간은 개의 기본값으로 가져오지 않았다.
- AI 생성 강아지 영상 제작 예시는 실제 동물 관찰 근거에서 제외했다.
- ‘side-eye = 질투/죄책감’, ‘뒤돌아봄 = 사랑’ 같은 SNS 감정 해석은 정책에 넣지 않았다.
- 게임 개발 인터뷰의 ‘개는 머리로, 고양이는 눈으로 본다’는 간략한 표현을 개의 안구운동 부재 근거로 사용하지 않았다.
- 검색 결과의 중복 논문, 원출처가 불분명한 영상 모음은 독립 근거로 세지 않았다.

## 정책으로 옮기는 규칙

1. **별도 기록:** 몸 방향, 이동 방향, 머리 방향, 눈 방향, 바라봄 대상을 구분한다. 머리만 보이면 눈 방향은 미확인으로 둔다.
2. **선택적 결합:** 몸 고정+고개 돌림, 머리 고정+눈 전환, 걷기+짧은 뒤보기, 사람↔대상 전환을 별도 조합 후보로 둔다.
3. **이동 비종속:** 바라봄 요청이 이동 목적지를 자동 변경하거나 걷기 주기를 초기화하지 않도록 한다.
4. **범위 제한:** 자산이 지원하지 않는 뒤보기는 고개/몸 전환 클립이나 보류로 처리한다. 눈을 얼굴 밖으로 이동시키지 않는다.
5. **형태 유지:** P1의 점눈을 보존한다. 눈동자 방향을 표현할 구조가 없으면 머리 방향으로 표현하고 눈 채널은 시각적 미지원으로 남긴다.
6. **시간 분리:** 관찰 타임스탬프와 제작 프레임 시간을 분리한다. 매 N걸음 뒤보기나 고정된 눈→머리 지연값을 문헌 근거 없이 확정하지 않는다.
7. **검증 상태:** 연구가 가능한 행동을 보여 줬다는 것, 제작 후보가 존재한다는 것, 이 개체가 실제로 한다는 것, 화면에서 자연스럽게 재생된다는 것을 각각 기록한다.

## 다음 실제 영상 검토의 기록 항목

`출처/게시자 → 원영상 여부 → 편집·재생속도 → 시간 구간 → 몸 자세·이동 → 머리 회전 → 눈 가시성·상대 방향 → 대상 확인 가능 여부 → 복귀 → 판정 한계` 순서로 적는다. 화면상 눈 위치 변화는 카메라 이동·머리 회전·원근 변화와 구별한다. 가려진 눈은 보간해 관찰값으로 만들지 않는다.
