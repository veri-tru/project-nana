# 상황별 시선·표정·몸 동작 연결 정책

작성: 2026-11-01. 상태: **제작 정책 정본 v1.0 / 2026-11-01 정본화 / 런타임·자산 승인 별도**.

사용자의 ‘2번까지’ 지시에 따라 9개 상황 ID·선택 조건·부위 조합·충돌·중단·현재 상태 복귀·필수 기록 항목을 제작 기준으로 확정한다. 정본화는 이 문서를 후속 제작의 기준으로 삼는다는 뜻이다. 개체 습관, 자연적인 행동 순서·지연, 자산 품질, 런타임 구현을 승인한 것은 아니다. 아래 선택 후보와 미정 수치는 계속 그 상태로 남긴다.

사용자 방향은 ‘상황에 맞는 시선과 표정의 동작이 연결되도록 정책 정비’다. [얼굴·시선 움직임 정책](facial-motion-policy.md)의 부위별 제어와 충돌 규칙 위에 상황별 선택·연결 계층을 추가한다. 부위는 따로 제어하되 **같은 상황·대상·반응 단계에 속하는 동작은 하나의 반응으로 묶어 선택한다.**

확정된 8fps·기본 125ms, 시간 기반 이동, P1 점눈·무늬 유지, G0 범위, 관찰/보호자 보고/제작 기본값 분리는 그대로 적용한다. 실제 반응 엔진이나 새로운 입력 기능은 미구현이다. [P1 연속 프레임 후보](../outputs/dog-crayon-p1-sequences-20261101/README.md)는 이 규칙을 시각화한 제작물이며 실행 준비 자산과 구분한다.

## 1. 연결 단위: 상황에서 시작해 현재 상태로 돌아온다

`입력된 사건과 현재 상황 → 대상 확인 → 반응 선택 → 시선·표정·몸 동작 조합 → 유지/갱신 → 종료 또는 중단 → 현재 상황에 맞는 기본 상태`

예를 들어 ‘장난감이 나타났다’는 사건을 받으면 그 장난감을 대상으로 바라보기와 지원되는 얼굴 반응을 함께 선택한다. 눈은 장난감을 보는데 얼굴은 무관한 반복 핥기를 하고, 몸은 다른 대상을 따라가는 식으로 각각 무작위 선택하지 않는다. 기본 깜박임 등은 호환되는 경우 배경 동작으로 유지할 수 있다.

상황 이름은 사건·활동·자세를 나타낸다. ‘행복·불안·질투·죄책감’을 실제 개의 상태로 추정해 상황을 채우지 않는다. 연구는 가능한 동작과 관계의 참고이며 아래 전체 장면 순서를 검증한 것은 아니다.

## 2. 상황을 판단할 때 사용할 정보

| 항목 | 기록할 내용 | 결측·주의 처리 |
| --- | --- | --- |
| 사건 | 사건 ID, 종류, 발생 시각, 발생/갱신/종료 구분 | 같은 사건을 매 프레임 새 자극으로 만들지 않음 |
| 입력 출처 | 앱 내 명시적 상호작용, 가상 장면 사건, 보호자 설정, 확인된 영상 관찰 등 | 화면 탭을 실제 보호자의 호출·애정·감정으로 바꾸지 않음 |
| 현재 활동 | 걷기·쉬기·잠든 자세·놀이·물체 물기·몸 털기 등 | 현재 엔진/장면에 없는 활동은 지원된 것으로 간주하지 않음 |
| 대상 | 대상 ID·종류, 위치와 좌표계, 위치 갱신 시각, 유효 여부 | 대상이 불명확하면 임의 좌표를 바라보게 하지 않음 |
| 몸 조건 | 몸 자세·방향, 이동 목적지·속도·보행 위상, 머리 지지, 접촉 물체 | 시선 요청만으로 몸 자세·경로를 덮어쓰지 않음 |
| 진행 중 반응 | 단계, 소유 부위, 시작 시각, 중단 가능한 지점 | 기존 반응과 동시에 같은 입·혀·머리를 제어하지 않음 |
| 개체 설정 | 해당 상황의 행동 여부·방향·선호 대상·빈도·지연 및 근거 | 모름은 제작값과 구별. 하지 않는다고 보고한 상황에서는 제외 |
| 자산 지원 | 개체·버전·방향·자세·표시 크기에서 검수된 조합 | 문헌에 있는 행동도 자산이 없으면 재생 후보에서 제외 |

카메라·마이크·현실의 보호자 위치 감지는 현재 기능으로 가정하지 않는다. 호출이나 소리 방향 사례는 해당 사건과 위치를 명시적으로 제공하는 장면·후속 기능이 있을 때만 사용할 설계 후보다.

## 3. 반응 선택 규칙

1. **가능한 반응부터 좁힌다.** 현재 자세·대상 유효성·개체 제외 설정·자산 호환·부위 점유·반복 제한을 검사한다. 하나라도 필수 조건을 만족하지 못하면 해당 반응을 시작하지 않는다.
2. **근거가 맞는 연결을 고른다.** 해당 상황에 대한 확인된 개체 설정을 우선한다. 관찰과 보고가 충돌하면 임의로 섞지 않고 기존 개인화 상태 규칙에 따라 보류한다.
3. **제작 기본값은 별도다.** 개체 근거가 없으면 검수된 공통 제작 반응을 쓸 수 있지만 ‘그 개의 습관’으로 표시하지 않는다. 검수된 기본 반응도 없으면 현재 지원 상태를 유지한다.
4. **시선과 표정을 묶는다.** 하나의 반응 ID 아래에 대상·시선 방식·눈꺼풀/귀/입술/턱/혀 동작·몸 처리·단계별 시점을 둔다. 반응 안의 일부 동작도 현재 입·호흡·물체 접촉 조건을 검사한다.
5. **허용된 변형 안에서만 변주한다.** 여러 후보를 섞더라도 같은 상황·대상·자세와 호환되는 전체 반응 또는 명시된 선택 동작만 고른다. 눈·입·혀를 각각 다른 상황 묶음에서 뽑지 않는다.
6. **필수 표현을 못 하면 반응을 재선택한다.** 코 핥기의 코 접촉처럼 정체성을 결정하는 표현을 생략한 채 같은 동작명으로 내보내지 않는다. 선택적인 눈썹 동작만 미지원이면 생략 사유를 기록할 수 있다.

## 4. 상황별 연결표

아래 행은 **제작 시나리오**다. 실제 개가 반드시 이 순서로 행동한다는 뜻이 아니다. ‘선택’ 동작은 해당 상황에 연결된 개체 설정 또는 별도로 검수한 제작 반응이 있을 때만 포함한다. 얼굴 기본값은 일률적인 닫힌 입이 아니라 현재 자세·호흡·물체 접촉을 반영한 검수 상태다.

| 상황 ID·진입 조건 | 시선·머리 대상과 흐름 | 연결할 얼굴 동작 | 몸 동작과 종료 |
| --- | --- | --- | --- |
| CTX_REST_CHECK: 깨어 쉬는 중 위치가 명확한 상호작용 발생 | 사건 대상 쪽으로 짧게 확인. 머리를 받친 자세라면 지원된 눈/고개 변형만 사용 | 기본 얼굴 유지. 선택: 깜박임·귀 기저부 방향 변화. 턱 벌림·혀 노출을 자동 부착하지 않음 | 휴식 자세 유지. 대상 소멸/확인 종료 시 그 자세의 기본 방향으로 복귀 |
| CTX_WALK_CHECK: 걷는 중 유효한 확인 대상 사건 | 이동 방향에서 대상 쪽으로 잠깐 전환한 뒤 현재 진행 방향으로 복귀 | 기존 입·호흡 상태를 유지하며 선택적인 깜박임을 허용. 뒤보기마다 ‘웃는 입’ 생성 금지 | 경로·보행 위상 유지. 각도/방향 자산 미지원이면 보류하거나 별도 멈춤 전환을 선택 |
| CTX_TARGET_PRESENT: 먹이·장난감 등 가상 대상이 명시적으로 등장 | 해당 대상을 바라봄. 사람↔대상 전환은 둘 다 유효하고 선택 규칙이 있을 때만 사용 | 선택: 귀 모음, 입술/턱의 검수된 변화. 코 핥기·혀 보임은 그 상황의 설정이 있는 경우만 포함 | 기본적으로 자세 유지. 접근은 별도 행동 결정이 발생한 뒤 연결. 먹이 획득·대상 제거·반응 만료로 종료 |
| CTX_TARGET_MOVES: 보고 있던 대상의 위치 갱신 | 같은 대상 ID를 유지하며 지원 범위 안에서 따라봄 | 현재 반응의 얼굴 상태 유지. 위치 갱신마다 핥기·눈썹 올림을 다시 시작하지 않음 | 기존 몸 활동 유지. 눈/머리 범위를 넘으면 검수된 몸 회전 전환 또는 추적 종료 |
| CTX_TARGET_UNAVAILABLE: 기대 대상에 접근할 수 없다는 장면 상태가 명시됨 | 유효한 대상/상호작용 주체를 확인하거나 주의 해제 | 기존 얼굴에서 선택: 코 핥기, 눈 깜박임, 귀 뒤 이동 중 설정된 조합. 상황만으로 ‘좌절 얼굴’을 강제하지 않음 | 접근 시도 반복을 자동 생성하지 않음. 접근 가능 전환·대상 제거·시간 만료 시 종료 |
| CTX_PLAY_EXCHANGE: 장면/입력으로 놀이 상태가 이미 성립 | 놀이 대상 또는 상대를 봄. 활동 전환에 맞춰 대상을 갱신 | 선택: 놀이 맥락의 이완된 입 벌림. 헐떡임은 별도 호흡 상태가 있을 때만. 물체를 물었다면 물기 자산이 턱·혀를 소유 | 몸 놀이 동작과 같은 반응 흐름을 공유. 놀이 종료 시 현재 자세·호흡에 맞게 복귀 |
| CTX_CONTACT_CHANGE: 가상 접촉의 시작·변화·종료가 명시됨 | 접촉 주체/위치가 주어졌을 때만 방향 확인 | 선택: 해당 개체/제작 반응의 눈꺼풀·귀·입 변화. 접촉 종료를 ‘불만’으로 명명하거나 옆눈질을 강제하지 않음 | 현재 지지 자세 유지. 같은 접촉의 미세 갱신은 하나의 반응으로 묶음 |
| CTX_SLEEP_REQUEST: 잠든 자세 중 상호작용 요청 | 기본은 잠든 자세 유지. 기상 반응이 선택되고 전환 자산이 있을 때만 눈 열기 후 대상 확인 | 기상 전 눈 감은 상태 유지. 기상 뒤 새로운 얼굴 기본 상태를 선택 | 시선부터 즉시 움직이지 않음. 기상하지 않으면 사건 만료; 기상하면 깨어 있는 상태에서 재평가 |
| CTX_ACTION_FINISHED: 기지개·몸 털기 등 머리를 점유한 동작 완료 | 해제 지점에서 현재 유효한 대상이 있으면 다시 평가 | 털기/기지개 클립의 종료 얼굴에서 현재 활동의 기본 얼굴로 전환. 과거 핥기 요청을 누적 재생하지 않음 | 완료된 자세·현재 보행 상태에서 이어짐. 오래된 요청은 폐기 |

문헌 연결: 대상 제시·제한 상황의 얼굴 후보는 [얼굴 정책의 F2·F5](facial-motion-policy.md), 대상 전환과 접근 분리는 [시선 조사의 G1–G5](gaze-motion-research-20261101.md)를 참고했다. 걷기 확인·휴식 확인·접촉 변화·수면 요청·완료 후 복귀의 구체 연출은 제작 제안이다. CTX_TARGET_UNAVAILABLE의 후보들도 감정 진단이나 특정 개체의 관찰값이 아니다.

## 5. 반응 단계와 부위의 연결

| 단계 | 연결해야 하는 동작 | 상태 변화 |
| --- | --- | --- |
| 선택 대기 | 대상·자세·부위 점유·자산을 검사 | 보류에는 만료 조건을 둠. 무기한 큐 적재 금지 |
| 진입 | 시선/머리 목표와 얼굴 변화를 같은 반응 ID로 시작 | 지원 클립에 따라 동시·선행·후행 관계 지정. 보편적인 눈 우선 순서는 없음 |
| 확인·유지 | 목표 대상을 유지하고 필요한 얼굴 상태를 유지 | 혀 접촉은 해당 프레임/단계에서만 발생. 기본 깜박임은 호환 시 유지 가능 |
| 상호작용/후속 행동 | 접근·놀이·물체 접촉 등 별도 결정이 있을 때만 연결 | 시선만 바뀌었다는 이유로 몸 이동을 발생시키지 않음 |
| 종료·중단 | 혀 회수·입/눈 상태 해제·시선 해제 또는 새 대상으로 전환 | 단계 도중 끊으면 관통·튀는 변화가 생기는 클립은 지정된 해제 지점 사용 |
| 복귀 | **지금의** 몸 자세·활동·호흡·접촉·대상을 재평가 | 진입 당시 상태를 무조건 복원하지 않음. 걷기가 끝났다면 걷기로 되돌리지 않음 |

얼굴의 동작 개수는 상황의 강도를 나타내는 점수가 아니다. 한 상황에 눈썹·입·귀·혀를 모두 움직여야 한다는 규칙을 두지 않는다. 관찰이나 제작 목적에 필요한 동작만 선택한다.

## 6. 중복 사건·충돌·중단

- 같은 사건 ID와 같은 대상의 위치 갱신은 기존 반응을 갱신한다. 매 갱신마다 진입·핥기를 반복하지 않는다.
- 대상 ID가 바뀌면 새 사건으로 평가한다. 기존 반응의 늦은 완료 신호가 새 반응의 얼굴·시선을 되돌리지 않도록 반응 ID/버전을 확인한다.
- 대상이 사라졌거나 위치가 오래돼 유효하지 않으면 추적을 종료한다. 사라진 좌표를 계속 응시하지 않으며 ‘슬픔’ 등 다른 표정을 자동 생성하지 않는다.
- 우선 적용 순서는 **표시 종료·취소 → 접촉/해부학적 충돌 해소 → 현재 동작의 필수 해제 → 명시적 상호작용 → 자율 반응**이다. 이는 엔진 설계 순서이며 개의 심리적 우선순위가 아니다.
- 몸 털기·물체 물기 등은 필요한 부위를 소유한다. 양립 가능한 눈꺼풀 동작만 겹칠 수 있고, 불가능한 새 요청은 만료 가능한 보류 또는 폐기로 처리한다.
- 같은 우선순위에서 짧은 간격으로 대상이 바뀔 때는 설정된 최소 유지·전환 조건으로 흔들림을 줄인다. 직접 취소·대상 소멸은 그 제한보다 우선한다.
- 반복 허용 횟수·재실행 대기·사건 만료 시간은 반응별로 지정한다. 숫자가 미정인 규칙은 실행 준비 상태로 승인하지 않는다. 미정 값을 0이나 무한대로 바꾸지 않는다.
- 배경 깜박임은 얼굴 반응과 무관한 감정 표현을 발생시키지 않는 별도 유지 동작으로 둘 수 있다. 수면·눈꺼풀 점유 중에는 충돌 규칙을 따른다.

## 8. 현재 P1에서 먼저 비교할 세 장면

세 장면 모두 사용자 선호가 확인된 작은 점눈과 기존 식별단서를 유지한다. 점눈에서 눈 방향이 보이지 않으면 머리 방향 표현을 사용하고, 눈만 움직이는 표현을 구현했다고 주장하지 않는다.

### A. 엎드려 쉬다가 옆의 대상 확인

1. 몸·앞발 지지를 유지한 휴식 상태에서 명시적인 대상 사건을 받는다.
2. 지원된 범위로 고개를 돌린다. 얼굴은 해당 휴식 상태를 유지하고, 검수된 선택 동작만 더한다.
3. 대상이 사라지거나 확인 시간이 끝나면 현재 휴식 자세의 기본 얼굴·방향으로 돌아온다.
4. 같은 대상이 미세하게 움직여도 고개 돌림 진입이나 혀 노출을 매번 다시 시작하지 않는다.

### B. 걷다가 뒤쪽 대상 확인

1. 이동 목적지·속도·보행 위상을 유지한다.
2. 지원된 고개/얼굴 조합으로 뒤쪽 대상을 확인한다. 기존 입·호흡 상태를 함께 유지한다.
3. 대상 확인이 끝나면 현재 진행 방향을 본다. 그동안 멈춤 사건이 있었다면 멈춘 자세에서 복귀한다.
4. 지원 범위 밖 뒤보기는 목을 비틀지 않고 보류하거나 검수된 정지·몸 회전 반응을 별도로 선택한다.

### C. 장난감을 보고 사람과 번갈아 확인

1. 유효한 장난감과 사람 역할의 가상 대상이 모두 있는 장면에서 시작한다.
2. 설정된 대상 전환을 재생한다. 얼굴은 놀이 상태가 실제 장면에서 성립했는지에 따라 유지 또는 지원된 놀이 입 벌림을 선택한다.
3. 대상 등장만으로 자동 헐떡임·코 핥기·접근을 추가하지 않는다. 해당 상황의 설정이 있으면 그 반응 묶음의 지정 단계에 추가한다.
4. 접근 결정이 생겼을 때만 몸 이동을 시작한다. 대상을 물면 물기 자산이 턱·혀를 소유한다.

세 장면의 개체별 발생 여부·빈도·표정 조합은 보호자/관찰 검수가 남아 있다. 먼저 같은 장면에서 ‘몸까지 일괄 회전’과 ‘몸 유지+고개 전환’의 차이, 표정 연결의 자연스러움을 확인할 수 있다. 기존 A/B에서 새 자산·새 연쇄의 효과를 혼합하지 않도록 별도 자산 검수로 진행한다.

## 9. 후속 구현에서 확인할 시나리오

아래는 실행한 테스트 결과가 아니라 구현·자산 검수의 기대 결과다.

| 입력 시나리오 | 기대 결과 |
| --- | --- |
| 걷는 중 같은 대상의 위치가 여러 번 갱신됨 | 걷기 위상 유지, 기존 반응 갱신, 핥기 반복 생성 없음 |
| 고개를 돌리는 중 대상 제거 | 유효하지 않은 대상 추적 종료, 안전한 해제 뒤 현재 자세로 복귀 |
| 옛 반응 A 종료 신호가 새 반응 B 뒤에 도착 | B의 시선·얼굴을 A의 값으로 덮어쓰지 않음 |
| 코 핥기 도중 다른 핥기 요청 | 한 혀 경로 소유, 해제 지점에서만 교체, 이중 혀 없음 |
| 물체를 문 상태에서 놀이 입 벌림 요청 | 물기 접촉 유지 또는 검수된 놓기 전환. 물체 부유 없음 |
| 잠든 자세에서 탭 사건 | 설정된 수면 유지/기상 경로 중 선택. 즉시 열린 눈+뒤돌아보기 없음 |
| 대상 방향을 모르거나 필수 시간값이 없음 | 해당 반응 시작 보류. 임의 방향·무한 유지 없음 |
| 개체가 해당 상황에서 하지 않는다고 설정됨 | 그 상황의 반응 제외. 다른 상황의 보고까지 삭제하지 않음 |
| 그림상 눈 방향을 지원하지 않는 점눈 자산 | 허용된 머리 표현 대안 또는 보류; 스타일 변경 없음 |
| 대상 확인 중 걷기→쉬기로 상태 변경 | 복귀 시 현재 쉬기 상태 사용; 과거 걷기 재시작 없음 |

실제 재생 시 선택한 규칙·근거 유형·대상·시각·생략/보류 이유를 기록하고, 자연스러움과 개체 닮음은 보호자가 별도로 평가한다.

## 11. v1.0 적용과 P1 제작값

- 정본의 범위: 9개 CTX 상황, 공유 사건·대상·반응 ID, 부위 소유와 충돌, 같은 대상 갱신 시 재시작 금지, 유효성·만료·취소, 현재 상태 재평가 복귀, 미정 값의 실행 금지.
- 자산 기준: 작은 점눈과 개체 무늬·비율을 유지하며, 최신 [약한 외곽선 A](../outputs/dog-crayon-outline-levels-20261101/README.md)를 후속 화풍 기준으로 쓴다. 눈동자 방향은 독립적으로 표현하지 않고 머리 방향으로 대상 확인을 전달한다.
- [제작 후보 v0.1](../outputs/dog-crayon-p1-sequences-20261101/README.md): A 쉬면서 옆 확인 12장/2.5초, B 걷는 중 후측방 확인 12장/1.5초, C 장난감↔사람 확인 12장/3초. 기본 간격 125ms이며 A·C의 정지 구간에는 같은 프레임을 더 오래 표시한다.
- 이번 세 장면은 열린 입·짧은 혀 보임을 진입 전부터 가진 제작 변형이다. 대상 등장 때문에 입이 열리거나 헐떡이는 규칙이 아니다. A에만 1프레임의 닫힌 눈을 넣는다. 코 핥기·입술 쓸기·AU101은 이번 산출물에 포함하지 않는다.
- 미리보기 사건은 버튼으로 한 번 시작하고 마지막 프레임에서 끝난다. 입력 지연 0ms, 반복 상한 1회, 자동 재실행 없음, 대상은 장면 종료까지 유효한 가상 대상이다. 일반 런타임의 재실행 대기·만료값을 이 값으로 고정하지 않는다.
- 모든 수치는 제작 기본값이다. 문헌 실측이나 이 개의 반응 지연·빈도가 아니다. 프레임 시퀀스는 합쳐진 그림이며 독립 부위 제어 엔진이 구현된 것은 아니다.
- 3단계: 8fps 재생 자연스러움, 목·귀·무늬·발 접지와 프레임 경계, 실제 표시 크기, 중단/대상 갱신과 복귀를 검수한다. 최종 해상도·개체 닮음·사용자 승인은 별도다.
