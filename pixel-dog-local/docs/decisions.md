## 2026년 10월 17일 행동 개인화와 중간점검 A/B 테스트

- 사용자 방향: 행동 개인화를 차별화 요소로 유지하고, 미리 준비한 행동 요소를 보호자 응답과 사진에 맞추는 방식을 검토합니다. 영상 제출 부담을 줄이는 것이 우선입니다.
- 사용자 결정: 중간점검 때 A/B 테스트를 진행합니다. 현재는 계획 기록이며 테스트는 미실시입니다.
- 실행 시점 제안: 동일 외형으로 기본 행동과 응답 기반 개인화 행동을 모두 재생할 수 있는 비교물이 준비된 중간점검입니다. 날짜는 미정이며 G0 구현 범위를 확대하지 않습니다.
- A안은 공통 기본 행동, B안은 보호자 응답에 따라 동작·속도·빈도·순서를 맞춘 행동입니다. 외형·화풍·표시 크기·재생 시간·동작 자산의 품질은 같게 유지합니다.
- 개인화 여부를 먼저 알리지 않고 제시 순서를 교차 배정합니다. 같은 보호자가 두 안을 보는 탐색 비교로 시작하며, 차이 없음·둘 다 닮지 않음도 선택할 수 있게 합니다.
- 핵심 평가는 어느 쪽이 더 자기 강아지다운지와 그렇게 느낀 구체적 이유입니다. 귀여움·자연스러움·계속 사용 의향은 별도로 기록하고, 응답 시간·수정 횟수도 확인합니다.
- 사진은 외형과 직접 보이는 자세에, 응답은 습관·반응에 사용합니다. 사진 한 장으로 성격이나 행동 빈도를 확정하지 않고, 보호자 보고와 직접 관찰 근거를 구분합니다. 첫 비교에 영상 제출은 필수로 요구하지 않는 안입니다.
- 20대·30대 여성에게 동일 과제를 적용합니다. 표본 수·정량 통과 기준은 실행 전에 정하고, 소수 탐색 결과를 통계적 우위나 실제 구매로 해석하지 않습니다.
- 결과는 행동 개인화를 없앨지 결정하는 근거보다, 어떤 행동 요소와 입력 방식이 개체의 특징을 잘 전달하는지 개선하는 데 우선 사용합니다.

## 혼동을 피할 사항

- 8fps는 프레임 표시 속도입니다. 모든 동작을 8장으로 만들라는 뜻은 아닙니다.
- 96×96 시안은 일반화한 강아지 그림으로 만든 비교 자료입니다. 실제 개체의 외형·습관이나 최종 화풍이 승인된 자산은 아닙니다.
- 이전 문서의 일반 2D 일러스트·레이어 설명은 제작 방식의 참고로 유지합니다. 픽셀화에 맞는 결과물 규격은 [자산 초안](asset-spec.md)에서 관리합니다.
- Jev 문서는 과거 대안 검토입니다. 현재 구현의 의존성 목록으로 해석하지 않습니다.
- 기존 문서의 공급자 가격·모델 스펙·OS 정책은 당시 조사 기록입니다. 이 패키지 제작 과정에서 재검증한 최신 API 계약이 아닙니다.
