# 출처와 내보내기 기록

- `pages/*.json`: 접근 가능한 원본 문서 10개의 제목·URL·시퀀스·수정 시각·블록 내용과 원본 블록 해시. 계정 식별자는 포함하지 않았습니다.
- `manifest.json`: 로컬 파일과 원본 문서의 연결, 시안 파일 출처와 해시.
- `checksums.sha256`: 패키지 내 파일 내용 확인용 SHA-256 목록. 목록 자체는 제외합니다.

`docs/archive/*.md`는 원본 블록의 Markdown을 순서대로 이어 붙인 뒤 표제·출처 안내를 더했습니다. 패키지에 포함된 ChatGPT 문서 링크만 같은 폴더의 상대 링크로 바꿨고, 논문·제품·GitHub 등의 외부 링크는 유지했습니다. 원문과 비교할 때는 JSON의 블록 내용을 사용합니다.

참고 HTML은 기존 로컬 파일을 보존본 `references/previews/originals`에 그대로 복사하고, 독립 페이지 복사본에는 UTF-8 문서 구조·기본 CSS 변수·목록으로 돌아가는 링크를 덧붙였습니다. 그림과 애니메이션의 원래 스크립트는 보존했습니다. 원본의 호스트 테마 색상 값은 파일에 포함돼 있지 않아 독립 페이지의 색상은 이식용 기본값입니다.

이 패키지는 문서·시안의 로컬 인수인계본입니다. 원격 문서와 자동 동기화되지 않으며, 이후 개발 결과는 로컬 Git과 활성 문서에서 관리합니다.
