# 픽셀 반려견에 적용할 시각적 습관 요소 문헌조사

기준일: 2026-10-17. 행동 개인화를 유지하면서 사진과 짧은 보호자 응답으로 시작하는 Nana의 검토 방향에 맞춘 탐색적 문헌조사입니다.

첫 비교 시제품에는 **고개 돌려 번갈아 보기, 앞발 들기, 접근과 가까이 머물기, 꼬리 흔들기, 휴식 자세, 냄새 맡으며 이동하기, 몸 털기, 기지개**를 후보로 둡니다. 몸 털기와 기지개는 2026-10-17 사용자 지시로 포함했으며 각각 별도 동작입니다. 개별 동작을 많이 만드는 것보다 발생 상황·빈도·지속·순서를 조정할 수 있게 만드는 것이 fitting에 적합합니다. 나머지 구현 우선순위와 난이도는 연구 결과를 바탕으로 한 설계 판단이며 실제 제작·판독 테스트 결과가 아닙니다.

## 조사 범위와 근거의 의미

Exa에서 휴식·이동, 보호자와의 상호작용, 놀이·특징 동작의 세 축을 조사했습니다. 후속 검색을 포함한 7회 검색에서 후보 결과 43건을 받았고 정확히 같은 URL을 제거하면 40개입니다. 동일 논문의 DOI·PMC·출판사 페이지는 별도 논문으로 세지 않았습니다. 기존 프로젝트 문헌의 관련 논문도 원출처를 다시 확인해 10편을 선별했습니다. 8편은 본문 방법·결과 또는 행동 정의 표를 확인했고, 놀이 자세 관련 2편은 공개 초록 수준으로 사용했습니다. 체계적 문헌고찰이나 개 행동 전체의 빈도 순위가 아닙니다.

- **관찰 정의 근거:** 그 동작을 다른 관찰자가 구분할 수 있도록 정의한 연구입니다. 개체 고유성을 증명하지 않습니다.
- **개체차·일관성 근거:** 같은 상황 또는 연구 기간 안에서 개체별 차이가 나타나는지 확인한 연구입니다. 평생 유지되는 성격이나 모든 상황에서의 동일성을 뜻하지 않습니다.
- **제품 효과:** 보호자가 픽셀 캐릭터를 보고 자기 강아지답다고 느끼는지는 별도의 A/B 테스트로 확인합니다. 아래 10편은 Nana의 식별 효과를 직접 검증한 논문이 아닙니다.

## 우선 검토할 여덟 요소

난이도는 작은 2D 픽셀 캐릭터와 8fps 기본 재생을 가정한 상대 평가입니다. 낮음은 기존 자세·걷기 자산 재사용 위주, 중간은 별도 자세·방향·부위 자산이나 접촉 처리, 높음은 물건 조작이나 복잡한 연속 전환이 필요한 경우입니다.

| 꼬리 흔들기 | 실내 상황 간 흔드는 경향의 일관성 [R2], 비글의 반복 관찰에서 개체별 운동 패턴 차이 [R3] | 시작 조건·빈도·지속·대략적인 폭과 리듬 | 반길 때 꼬리는 작게 자주 흔드나요, 크게 흔드나요? | 중간. 체형·꼬리 형태별 자산 필요. 8fps에서 빠른 실제 주파수를 정확히 복제했다고 주장하지 않음. 흔듦을 행복 점수로 바꾸지 않음 |

| 냄새 맡으며 이동·멈춰 탐색하기 | 냄새 맡기와 이동을 행동 단위로 구분 [R4]. 물건을 살피고 냄새 맡는 탐색은 상황 의존적 [R2] | 머리 낮춤 → 짧은 이동 → 멈춤 → 다시 이동, 탐색 비율·지속 | 돌아다닐 때 자주 멈춰 냄새를 맡는 편인가요? | 중간. 머리 낮춘 자세와 걷기 연결. 냄새 맡는 동작은 시각적 대리 표현이며 실제 후각을 재현하지 않음. 한 상황의 탐색량을 고정 성격으로 처리하지 않음 |
| 몸 털기 | 몸 일부 또는 전체를 좌우로 흔드는 행동을 정의 [R9] | 시작 상황·횟수·지속과 다음 행동 | 몸을 털 때는 주로 언제이고, 얼마나 자주 하나요? | 중간. 사용자 지정 포함. 발생 빈도·순서는 보호자 보고로 맞추며 감정을 자동 해석하지 않음 |
| 기지개 | 몸 일부 또는 전체를 늘이는 행동을 정의 [R9] | 자세·유지시간·발생 상황과 앞뒤 전환 | 기지개는 어떤 모습이고 주로 언제 하나요? | 중간. 사용자 지정 포함. 놀이 자세와 앞뒤 맥락을 구분. 수면 후 반드시 하는 동작으로 고정하지 않음 |

R1에서 37마리의 가정 영상 242개를 분석해 19가지 지시적 몸짓을 구분했고, 35마리에서 고개를 돌려 번갈아 보기가 관찰됐습니다. 이는 해당 표본과 수집 상황의 결과로, 모든 반려견의 사용률이 아닙니다. 행동이 관찰되지 않았다고 그 개에게 없는 행동이라고 단정할 수도 없습니다. [원문](https://link.springer.com/article/10.1007/s10071-018-1181-3) · [동작 정의 표](https://link.springer.com/article/10.1007/s10071-018-1181-3/tables/2)

R2는 분석 대상 27마리·22명의 보호자가 참여한 상황 비교입니다. 특히 근접성과 꼬리 흔들기의 실내 상황 간 일관성이 fitting에 유용한 근거입니다. 꼬리 흔들기는 실외 상황과 유의한 상관이 없었으므로, 이를 모든 맥락에 통하는 고유 특성으로 확대하지 않습니다. 접근 지연과 근접 시간도 같은 하나의 성격값으로 합치지 않습니다. [저자 원고](https://real.mtak.hu/9758/1/Farago%20et%20al_IS_Final_forcomments.pdf)

## 앉기와 눕기의 자세 개인화

2026-10-17 사용자가 앉거나 누워 있는 자세도 개체마다 다를 수 있다고 제안해, 동작 빈도뿐 아니라 기본 자세의 형태를 맞추는 항목으로 반영합니다. 아래 세부 변형은 사진과 보호자 응답으로 확인할 제작 후보이며, 각 형태가 안정적인 개체 특성이라는 문헌 결론은 아닙니다.

| 구분 | 선택할 자세 후보 | fitting 입력 |
| --- | --- | --- |
| 앉은 자세 | 정면으로 곧게 앉기, 엉덩이를 한쪽으로 둔 앉기, 앞발의 간격·좌우 배치 | 평소 앉은 사진 또는 자세 예시 선택 |
| 누운 자세 | 엎드리기, 옆으로 눕기, 몸을 둥글게 말기 | 자주 보이는 자세를 복수 선택 |
| 앞발과 머리 | 앞발을 나란히/교차해 두기, 턱을 바닥이나 앞발에 받치기, 머리를 들기 | 사진에서 보이는 조합을 선택하고 미리보기 수정 |
| 자세 유지와 전환 | 자주 취하는 자세, 자세를 바꾸는 정도, 일어난 뒤 몸 털기·기지개 여부 | 보호자 응답. 한 장의 사진으로 빈도·순서를 추정하지 않음 |

한 가지 자세로 고정하지 않고 대표 자세와 보조 자세를 지정할 수 있게 검토합니다. 몸통·다리·머리를 임의로 조합하기보다 자연스러운 완성 자세 몇 개를 먼저 제작하고, 그 안에서 차이를 조정하는 방식을 제안합니다. A/B에서 자세의 효과와 타이밍의 효과를 따로 확인하려면 자세만 바꾸는 비교를 별도로 둡니다.

고개 갸웃은 시각적으로 매력적인 후보지만, R6의 실험 1에서 장난감 이름 학습에 뛰어난 집단은 시행의 43%, 일반 집단은 2%에서 관찰됐습니다. 이는 일반 반려견의 일상 빈도가 아니라 해당 과제의 결과입니다. 해당 행동을 하지 않는 개에게 귀여움을 위해 일괄 추가하면 개인화의 목적과 어긋날 수 있습니다. [원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9107419/)

## 이번 단계에서 미루는 요소

- 눕기 전 특정 방향으로 돌기·이불 파기: 보호자가 지목한 후보로는 받을 수 있지만, 이번 선별 논문에서 장기 개체차와 화면 식별력을 뒷받침할 충분한 근거를 확인하지 못했습니다. 불가능하다는 뜻은 아니며 후속 조사 대상으로 둡니다.
- 귀·입술·눈의 미세 움직임: 작은 픽셀 화면에서 판독하기 어렵다는 구현상 판단으로 후순위에 둡니다. 부위의 형태 차이가 커서 동일 자산을 모든 개에게 적용하기도 어렵습니다.
- 빠른 전력 질주·큰 점프·복잡한 구르기: 신규 전환·방향·접지 자산이 많이 필요하므로 초기 fitting보다 후속 특화 동작에 적합합니다.
- 불안·행복·집착 등의 감정·성격 점수: 이 조사에서 정리한 것은 관찰 동작입니다. 꼬리·자세·단일 사진을 곧바로 내적 상태로 변환하는 규칙은 만들지 않습니다.

## 입력 부담을 줄이는 fitting 설계안

보호자 응답은 상황마다 달라지는 행동을 고르는 데 사용하고, 사진은 외형과 직접 보이는 자세를 선택하는 데 사용합니다. 보호자 보고로 만든 값은 관찰 영상으로 측정한 값과 구분합니다. R10은 보상 반응 설문과 관찰 행동의 연관성을 보여주지만, Nana의 새 질문이나 정확한 동작 타이밍 추정까지 타당화한 것은 아닙니다.

첫 등록에는 다음 네 상황을 제안합니다. 각 질문은 움직이는 예시 선택과 '해당 없음·잘 모르겠음'으로 답하게 하고, 세부 조절은 결과를 본 뒤 선택적으로 엽니다. 네 문항이라는 수는 편의상 제안한 설계값입니다.

갸웃·놀이 자세·장난감은 '이 아이가 자주 하는 행동 추가'에서 선택하게 합니다. 현재 자산으로 표현할 수 없는 선택은 비슷한 동작으로 몰래 바꾸지 않고 미지원으로 남깁니다. 사진의 견종이나 외모로 빈 응답을 채우지 않습니다.

행동 프로필은 **상황 → 반응 여부 → 동작 → 지속·반복 → 다음 행동**으로 구성합니다. '활발함 80점'처럼 하나의 점수로 모든 행동을 결정하지 않습니다. 초기 속도·대기시간은 느림/보통/빠름 등의 제작용 값으로 시작하고 보호자가 미리보기에서 수정합니다. 연구의 평균값을 모든 개의 기본 습관으로 복사하지 않습니다.

예를 들어 보호자가 직접 고른 경우에만 '관심 표시 → 고개 돌림 → 잠깐 기다림 → 천천히 접근 → 머리를 든 채 엎드림'으로 연결합니다. 이 순서 자체가 문헌에서 보편적으로 확인된 반려견 행동 규칙이라는 뜻은 아닙니다.

## 제작과 중간점검에 연결할 제안

1. G0의 걷기·쉬기·잠든 자세 범위는 유지합니다. 행동 개인화 후보 목록이 G0 범위 추가 승인을 뜻하지 않습니다.
2. G1 첫 비교는 기존 기본 8종 초안에서 고개 돌리기·앞발 들기·꼬리·휴식 전환을 활용하고, 접근·머무르기는 행동 연결 규칙으로 맞춥니다. 사용자 지정 동작인 몸 털기·기지개를 별도로 추가합니다. 냄새 맡기·갸웃·놀이 자세도 구현 시 자산 추가가 필요합니다.
3. 다리가 땅에 닿는 순간과 이동량을 맞춥니다. 빠른 걸음을 만들기 위해 위치만 빨리 움직이면 미끄러지는 인상을 줄 수 있으므로 실제 크기에서 확인합니다. 모든 동작에 8장을 만들거나 모든 움직임 속도를 8fps에 종속시키지 않습니다.
4. 중간점검에서는 같은 외형·동작 자산·표시 크기·제시 시간을 사용한 기본 프로필 A와 응답 fitting B를 비교합니다. 단순히 B에 동작을 더 많이 넣는 방식은 피하고, 동작 수와 자산 품질을 가능한 한 맞춥니다.
5. 개인화 여부를 미리 밝히지 않고 순서를 교차해 보여줍니다. 자기 강아지다움·차이 없음·판단 이유·자연스러움과 입력 부담을 기록합니다. 특정 요소의 효과를 알고 싶다면 다음 비교에서 그 요소만 바꿉니다.
6. 같은 응답을 고른 보호자가 결과를 좋아하는 것은 선택 일관성일 수도 있습니다. 가능하다면 강아지를 잘 아는 가족의 독립 평가와, 선택 문구를 그대로 반복하지 않는 자유 설명으로 보완합니다. 이는 신규 평가 제안입니다.
