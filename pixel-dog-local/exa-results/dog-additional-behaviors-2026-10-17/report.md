# 추가 행동 후보 전체 포함 조사

기준일: 2026-10-17. 사용자 지시: **“모두 포함”**.

직전 답변의 후보를 28개 세부 항목으로 나누어 모두 행동 DB에 연결했다. 새 문헌 근거 기록 18건, 기존 수면 자세의 보호자 보고 재사용 1건, 근거 확인 대기 사용자 요구 9건이다. 신규 기록은 27건이며, 누적 기록은 280건에서 307건으로 늘었다. 기록 수는 행동 종류·개체 수·실제 발생 횟수와 다르다.

## 포함 범위와 근거 수준

## 근거 문헌과 확인 범위

### 물체 조작과 놀이 이동 — 기존 L32 재확인

Davis 등의 새끼 강아지 물체 놀이 연구에서 Table 1의 행동 정의를 추가로 확인했다. 코로 밀기, 앞발로 당기기, 물고 끌기, 집었다 놓기, 뜯기, 물체 위에 눕거나 구르기, 접근과 후퇴, 통통 튀는 접근, 물건을 문 채 피하기, 상대 쫓기를 11개 기록으로 세분화했다. 표본은 3품종의 생후 3–7주 새끼 42마리다. 세부형별 발생 빈도와 성견의 안정된 습관은 새로 추정하지 않았다. [원문과 Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC10135149/)

기존 L32와 관련 기록을 중복 생성하지 않았다. L32의 확인 범위·근거 위치·확인 이력만 이번 원표 확인 내용으로 갱신하고 이전 기록은 그대로 두었다.

### 얼굴 움직임 — 새 L63

Kaminski 등(2017)의 DogFACS 정의표에서 눈썹 안쪽 올리기(AU101), 귀를 아래·바깥으로 내리기(EAD105), 입꼬리 당기기(AU12)를 추출했다. 이 정의를 각각 행복·슬픔·신뢰와 대응시키지 않는다. 24마리 가정 반려견의 사람 주의·먹이 조건 연구이며, 여기서 추가한 세 항목 모두에 동일한 조건 효과가 확인됐다고 해석하지 않았다. [논문 본문·Table 3](https://www.nature.com/articles/s41598-017-12781-x)

### 얼굴 긁기와 재채기 — 새 L65

Pfaller-Sadovsky 등(2023)은 먹이 강화 일정과 소거 조건에서 6마리를 관찰했다. 앞발로 얼굴 긁기는 self-scratching의 정의에 포함되지만 세부형만의 발생량은 확인하지 못했다. 재채기는 6마리 모두에서 보고됐으며 조건별 발생 양상은 달랐다. 두 행동을 평상시의 특정 감정이나 보편적인 습관 빈도로 일반화하지 않는다. [관련 본문·정의표·결과](https://doi.org/10.1016/j.jveb.2023.07.002)

### 한숨 — 새 L64

Taylor와 Madden(2016)은 한숨을 깊은 들숨 뒤 소리 나는 날숨으로 코딩하고 집단 발생량을 보고했다. 보호자가 낯선 환경에서 불안을 보인다고 보고한 성견 28마리의 30분 격리 조건이므로, 한숨을 곧바로 편안함·만족의 신호로 해석하지 않았다. 디퓨저 제품의 효과도 이 행동 정의의 근거와 별개다. [본문·Table 1·3](https://pmc.ncbi.nlm.nih.gov/articles/PMC5126766/)

### 앉는 전환 — 새 L66

Yoshikawa 등(2023)의 비글 8마리 운동 분석 연구에서 서 있다가 앉는 전환을 확인했다. 이번 접근 범위는 출판사 초록과 highlights다. 뒷다리 관절 가동범위 변화만으로 전환을 여러 단계로 나누지는 못했다는 결과를 보존했다. 모든 개의 앞발·뒷발 순서나 눕는 전환을 이 연구에서 추정하지 않았다. [출판사 초록](https://www.sciencedirect.com/science/article/abs/pii/S0034528823001893)

## 근거 확인 대기 항목

이불 당기기, 잠자리 바닥 긁기, 돌다가 자리 잡기, 먹이를 옮겨 먹기, 먹이 숨기기, 먹이 덮기, 앞발 교차, 지지 방향 바꾸기, 누운 자세로의 전환은 사용자 요구 출처 U02에 연결했다.

먹이 숨기기 검색에서 나온 **사람이 숨긴 먹이를 개가 찾는 실험**을 개가 스스로 먹이를 숨기는 근거로 사용하지 않았다. 늑대·코요테 등 다른 종의 저장 행동 순서도 반려견의 고정 연쇄로 옮기지 않았다. 형태·상황·반복 여부는 추가 문헌 또는 보호자 확인으로 보완한다.

돌다가 눕기와 먹이를 옮긴 뒤 먹기는 후보의 의미를 보존하기 위해 후속 관계 2행을 만들었다. 두 관계 모두 `design_proposal`이며 관찰된 연쇄가 아니다. 숨기기·덮기·먹기를 하나의 필수 순서로 묶지 않았다.

## DB와 개인화 설계에 반영한 내용

- 신규 기록: E178–E195 18건, U009–U017 9건. 기존 E171 재사용.
- 행동 위계: 23개 노드 추가. 분류 묶음 2개, 기록 가능한 행동·변형 21개.
- 새 상황: 새끼 물체 놀이, 사람 주의, 강화 일정, 격리·디퓨저, 잠자리 준비, 먹이 이동, 자세 전환의 7개.
- 새 문헌 출처 4개와 사용자 요구 출처 1개, 종합 근거 3건, 일상 맥락 평가 18건 추가.
- 누적: 307개 기록, 187개 분류 노드, 기록 가능한 행동·변형 147개, 상황 53개, 출처 91개, 관계 83행.
- 개별 지속시간·지연·반복 수·개체 식별값은 확인되지 않아 빈값을 유지했다.

행동 위계에는 관찰할 수 있는 동작을 넣고, 물건·먹이·이불 같은 대상과 발생 상황은 별도 필드로 남겼다. 예를 들어 이불 당기기는 기존의 물고 끌기 형태와 같은 코드를 사용하되 잠자리 맥락의 사용자 후보로 구분한다. 사진과 짧은 응답으로 형태·상황을 확인하는 개인화 후보이며, 실제 자산 제작·동작 선택 규칙·A/B 테스트 완료를 뜻하지 않는다.

## 검색 기록과 한계

이번 후속 검색은 8회이며 Exa 요청 결과 수 합계(`sources_reviewed`)는 36이다. 실제 반환 36건, URL 기준 중복 제거 33개다. 이 수치는 읽은 논문 수가 아니다. 새로 채택한 문헌은 4편이고 기존 L32를 재확인했다. 새 4편 중 3편은 관련 본문·표를, 1편은 출판사 초록·highlights를 확인했다.

이전 답변을 준비하며 읽은 L32 표를 재사용했고, L63은 이번에 다시 조회했다. 메타데이터만 반환된 DOI 한 건은 근거로 채택하지 않았다. 검색어·반환 URL·확인 범위는 [검색 기록](search-log.json)에 남겼다. 네이버 등 비공개 커뮤니티나 추가 개인 영상을 조사한 작업은 아니다.
