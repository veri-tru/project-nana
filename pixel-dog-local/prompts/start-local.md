# 로컬 개발 시작 프롬프트

아래 내용을 프로젝트 루트를 연 코딩 에이전트에 전달하세요.

> 이 폴더는 반려견 픽셀 캐릭터 모바일 앱의 기획 인수인계 패키지입니다. AGENTS.md, README.md, docs/decisions.md, docs/handoff.md를 읽고 docs/backlog.md의 Android G0부터 진행하세요. 먼저 로컬 JDK·Android SDK·IDE·실기기 또는 에뮬레이터 상태를 확인하고, 사용할 도구 버전을 기록하세요. 환경이 갖춰져 있으면 apps/android에 Kotlin 기반 G0 프로젝트를 생성하세요. 걷기·쉬기·잠든 자세의 임시 자산을 기본 8fps로 재생하고, 입력·상태 시간·위치 이동은 프레임 교체와 분리하세요. 작은 플로팅 창의 탭·드래그·표시 시작·중지·권한·화면 꺼짐·종료 처리를 구현하세요. 설정의 64×64px 정본 격자를 사용하고 기존 96×96 시안을 최종 승인 자산으로 취급하지 마세요. G0에는 AI나 서버를 연결하지 않습니다. OS 정책과 의존성은 현재 공식 자료로 확인하고, 실제 수행한 빌드·검증만 보고하세요. 완료한 항목과 남은 문제를 docs/backlog.md와 docs/handoff.md에 반영하세요.

앱 구현 전 문서 검토만 원할 때는 마지막 요청을 “구현하지 말고 로컬 환경 점검과 첫 작업 계획까지만 정리하세요”로 바꿀 수 있습니다.
