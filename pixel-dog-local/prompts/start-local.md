# 로컬 개발 시작 프롬프트

아래 내용을 프로젝트 루트를 연 코딩 에이전트에 전달하세요.

> 이 폴더는 반려견 개인화 픽셀 캐릭터 엔진과 모바일 앱의 개발 프로젝트입니다. AGENTS.md, README.md, docs/current-spec.md, docs/decisions.md, docs/handoff.md를 읽고 사용자의 현재 작업 범위를 확인하세요. 프로젝트 전용 환경은 ./engine.ps1 -Setup으로 준비하며 status, doctor, verify로 선택 기록·지원 범위·재현성을 확인합니다. 전역 Python 환경을 바꾸지 마세요. B2 화풍과 두 개체 C의 선택을 유지하고, 고해상도 시안 선택을 실제 64×64 실행 자산 승인으로 확대하지 마세요. 머리 투영과 전신 2D 작화는 별도이고, 털 지원 범위는 등록 모델과 현재 사양을 따릅니다. 현재 미완료 항목에 맞춰 작업하고 날짜별 과거 계획을 자동 재개하지 마세요. Android G0가 작업 범위일 때는 JDK·Android SDK·기기부터 점검하고 Kotlin 네이티브 표시·걷기/쉬기/잠든 자세·탭/드래그·표시/종료를 검증하세요. 기본 8fps를 지키고 입력·이동·상태 시간은 프레임 교체와 분리합니다. G0에는 AI나 서버를 연결하지 않습니다. 실제 수행한 검증만 보고하고 docs/backlog.md와 docs/handoff.md에 반영하세요.

앱 구현 전 문서 검토만 원할 때는 마지막 요청을 “구현하지 말고 로컬 환경 점검과 첫 작업 계획까지만 정리하세요”로 바꿀 수 있습니다.
