# 식별단서 지침 유무와 짧은 요청 비교

2026-11-01. 같은 실제 사진 2장(P02·P07)과 같은 크레용풍 디자인 참고 1장을 사용했습니다. 이전 B 중간 털 길이 그림을 기준으로 재사용하고, 지침을 줄인 두 조건을 각각 새로 생성했습니다. 내장 image_gen을 사용했으며 생성 그림은 다음 생성의 참조로 넣지 않았습니다. 실제 원본 이미지는 프로젝트에 복사하지 않았습니다.

| 조건 | 입력 문구 | 그림 |
|---|---|---|
| P1 | 개체 식별단서·부위별 털·화풍·구도 상세 설명 | [기존 B 재사용](P1-with-guidance.png) |
| P2 | P1에서 개체 식별단서 문단과 부위별 털 설명 제거. 화풍·구도 설명과 중간 길이 요청 유지 | [식별단서 제거](P2-without-identity-guidance.png) |
| P3 | 이미지 역할, 참고 디자인으로 그려 달라는 요청, 중간 길이·앉은 앞사선·배경/글자 제외만 짧게 지정 | [짧은 요청](P3-minimal.png) |

[비교판](comparison.png)은 왼쪽부터 P1/P2/P3입니다. 동일 캔버스를 같은 배율로 줄였으며 개체만 따로 크기 정규화하지 않았습니다. 따라서 화면에서 보이는 개체 크기 차이도 원래 생성 결과의 차이입니다. 원본 3개는 각 1254×1254px, 비교판은 1536×556px입니다.

## 이번 결과에서 보이는 차이

| 비교 항목 | P1 상세 지침 | P2 식별단서 제거 | P3 짧은 요청 |
|---|---|---|---|
| 큰 색 배치 | 회색 귀·몸통과 흰 이마·주둥이·가슴·발 | 대체로 유지 | 대체로 유지 |
| 귀 | 얼굴 옆의 둥근 처진 귀 | 비슷한 처진 귀 | 비슷한 처진 귀 |
| 꼬리 배치 | 낮게 옆으로 놓인 긴 털 | 위로 올라간 털 윤곽 | 위로 올라가 구부러진 털 윤곽 |
| 눈 | 작은 점 형태 | 점 형태이나 크기·위치 차이 | 더 크고 하이라이트가 들어감 |
| 몸·얼굴·프레이밍 | 기준안 | 얼굴 윤곽과 몸 비율·배치 변화 | 얼굴·다리·털과 개체 크기 변화 |
| 참고 화풍 | 크레용 질감, 참고보다 묘사 많음 | 크레용 질감 유지 | 크레용 질감 유지, 눈·표정 묘사 증가 |

사진과 레퍼런스만으로 큰 색 배치와 처진 귀가 대체로 표현됐다는 점은 관찰할 수 있습니다. 상세 지침은 이번 표본에서 낮은 꼬리 배치와 작은 점눈 같은 요구를 제시하는 역할을 했습니다. 다만 낮은 꼬리 배치는 그림을 위한 포즈 선택이며 실제 개체의 고정된 꼬리 형태가 맞았다는 판정은 아닙니다. 생성 결과를 새로운 관찰 사실로 사용하지 않습니다.

P1과 P2 사이에도 결과 차이가 있지만 조건당 1장이므로 지침 삭제 때문인지 생성 편차인지 분리할 수 없습니다. P3는 식별단서뿐 아니라 화풍·구도 설명의 양과 문구 언어도 다르므로 식별단서만의 효과로 설명할 수 없습니다. seed 고정·반복 생성·보호자 닮음 평가는 하지 않았으며 우열이나 성공률을 확정하지 않습니다. 이번 비교는 고객 대상 행동 개인화 A/B와 별개의 내부 외형 생성 탐색입니다.

## 다음 생성 방식에 대한 작업 가설

이미지와 레퍼런스를 기본 입력으로 쓰고, 얼굴·눈 등 공통 화풍 규칙을 짧게 고정한 다음 보호자가 중요하게 고른 특징 또는 반복해서 틀리는 부위만 명시하는 방식을 검토할 수 있습니다. 14개 축 전체를 매번 길게 나열해야 한다는 근거는 이번 결과만으로 확보되지 않았습니다. 이 제안은 새 확정 정책이 아닙니다.

전체 프롬프트·참조 파일·조건별 차이·한계는 [prompts.json](prompts.json), 크기·해시는 [validation.json](validation.json)에 남겼습니다. 원본을 바꾸지 않은 비교판 조립 스크립트는 build-comparison.cjs입니다.
