# 검은 코 복구 · 얼굴 연결 · 품종별 귀

현재 A/B/C 세 파일은 독립 외형 PASS · 기술 PASS · 전달 검사 READY다. 상태의 권위는 `review-status.json`이며 사용자 선택은 PENDING이다. 네 품종 × 다섯 시점 × 세 안의 60셀을 직접 검토했고 12개 모델·메타데이터·세 PNG의 재생성이 일치했다. 실제 저장 메시에서 뼈 표본 1,353,486개가 모두 내부였고, 피부–뼈 교차와 검사 범위의 자기 교차는 없었다. 최소 실제 여유는 0.309843 모델 단위다. 경미한 잔여 항목은 골든·닥스훈트 귀뿌리의 캡 형태다.

## 사용자 범위

“검은 코만 복구, 얼굴 연결은 계속 수정.” 이전 B의 검은 코만 복구 기준으로 사용한다. 기존 v1의 코밑 별도 덩어리와 뒤로 젖혀진 귀에 대한 거절은 유지한다. 골격, 둥근 눈, 짧은 목을 바탕으로 기본 표정만 다룬다. 픽셀 변환·학습·여섯 표정 제작은 이번 결과가 아니다.

## 제작 방식

검토된 `head-skeleton-volume-v2/geometry.pkl`의 실제 뼈 정점을 입력으로 쓴다. v1 B 외피를 초기 메시로 구성한 뒤, 검은 코 정점과 그 경계 삼각형을 고정하고 코 주변 피부부터 볼까지 위치를 다듬는다. 최근접 골격 표면을 제약으로 쓰는 완화 단계, 국소 표면 정리 단계, 최대 0.65 모델 단위의 완만한 외향 보정을 적용한다. 코 경계에서 보정량은 0이 된다. 최종 법선은 수정된 실제 메시에서 다시 계산한다. 음영만 바꾼 수정이 아니다.

`make_fields`는 초기 구성용 필드다. 최종 뼈 포함·접촉 검사는 **후처리된 `geometry.pkl`**의 실제 삼각형을 대상으로 해야 한다. `parameters.json`의 `sections`와 `muzzle_support`는 초기 외피 자료이며, 실제 변화는 `surface_relaxation`에 기록한다. 0.70 장애물 제약과 0.65 외향 보정은 제작 설정이지 최종 최소 여유를 보증하는 수치가 아니다.

귀는 골든의 넓은 늘어진 귓판, 닥스훈트의 긴 귓판, 휘핏의 짧게 접힌 귓판, 말티푸의 도톰한 타원형 귓판으로 나눈다. 말티푸는 사용자가 고른 첫 번째 사진을 기본형 참고로 사용하며, 두 번째 사진의 입·혀는 후속 범위다.

## 비교 조건

| 안 | 골격 제약 표면 완화 | 후속 표면 정리 | 코·눈·목·귀 |
|---|---:|---:|---|
| A | 320회 | 160회 | 공통 설정 |
| B | 400회 | 160회 | 공통 설정 |
| C | 480회 | 160회 | 공통 설정 |

차이는 같은 공간 마스크 안에서 표면을 정리하는 반복 횟수다. 이 마스크는 볼·윗입술과 일부 귀 앞면에도 닿는다. 귀 생성 설정은 같지만 최종 귀 정점까지 동일한 것은 아니다. 독립 검사에서 B 대비 A/C의 귀 영역 최대 이동은 골든 0.113, 닥스훈트 0.275, 말티푸 0.096 모델 단위였고 휘핏은 0이었다. 코 정점과 눈 메시는 정확히 보존된다. 같은 개체의 다섯 시점은 동일 저장 메시를 투영한다. 판은 각각 2400×1500px이며, 네 품종 × 측면·사선·정면·후면·윗면을 포함한다. 실제 개의 실측 비율이나 CT 복제물로 주장하지 않는다.

실행: `python outputs/skull-based-heads-v2/build.py A B C`

## 실패 이력

`iterations`는 개발 중 동결본이다. `development-visual-review.md`와 `review-dev*.json/md`의 실패를 지우지 않는다. 특히 개발12는 외형 PASS이나 실제 골격 관통으로 기술 FAIL이었으므로 전달 불가다. 개발10의 코 복구·기술 검사와 개발12의 외형 판정을 새 파일에 승계하지 않는다. 최종 전달 여부는 새 이미지 전체에 대한 보고서와 `review-status.json`을 함께 확인한다.
