## 제작 기준

프로젝트의 개체 식별·좌우 무늬 보존·출처 기록 기준을 적용했다. 이번 요청에 따라 체형 비율을 의도적으로 바꾼 정적 스타일 비교이며, 실제 체형 측정·품종 판정이나 행동 개인화 A/B 자료가 아니다. 보호자 닮음 확인과 동작·부위 호환 검수는 남아 있다. 기존 48픽셀 시안은 보존했다.
