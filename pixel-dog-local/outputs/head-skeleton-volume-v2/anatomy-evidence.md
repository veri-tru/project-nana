# 실제 자료와 모델의 대응

세 자료는 IMAIOS 개 머리 CT 해부 모듈의 공개 3D 이미지다. 실제 원본을 직접 열어 확인했고, `references.json`에 URL·로컬 연구용 경로·해시를 연결했다. 원본 픽셀은 결과판이나 배포용 모델에 포함하지 않는다. CT 데이터의 분할·등록, 품종별 실측, 개체의 질환 판단은 수행하지 않았다.

| 관찰한 관계 | 실제 자료에서 확인한 점 | 현재 구현/검토 대상 |
|---|---|---|
| 두개부–이마–비부 | 측면에서 이마가 앞쪽 비부 지붕으로 이어지고, 그 아래 상악의 깊이가 존재 | 기존 여섯 기준점의 위치를 유지한 두개부 loft와 비부 지붕, 상악 측벽·바닥의 결합 |
| 비강 입구·절치부 | 정면에서 위쪽 비강 입구와 아래 절치부가 구분됨 | 관통 가능한 앞쪽 입구, 지붕/측벽/경구개 두께, 앞쪽 U자 절치부. 실제 형상 가림 계산으로 내부의 깊이를 표현 |
| 광대활과 관자부 | 윗면에서 두개부와 바깥으로 휜 광대활 사이 공간이 있음 | 앞뒤 뿌리에서 넓어지는 곡선 광대활, 안쪽 빈 공간. 얇은 선이나 완전한 눈 안경테로 대체하지 않음 |
| 상악–안와 앞벽 | 측면에서 상악 뒤쪽이 안와 앞·안쪽 지지로 올라감 | 상악 후방의 깊이/폭이 두개부로 이어지고 급한 수직 절단벽이 남지 않는지 확인 |
| 하악체–상행지 | 측면에서 아래턱 몸통이 넓은 상행지로 연결됨 | 앞뒤에 따라 깊이가 변하는 좌우 하악체, 두께 있는 상행지, 가운데를 메우지 않은 구강 공간 |
| 근돌기와 관절돌기 | 높은 근돌기 뒤에 별도의 낮은 관절부가 있음 | 높은 근돌기·뒤쪽 오목한 절흔·관절돌기와 목. 아래턱 단독 측면/후사선/윗면에서 확인 |
| 개방 동작 | 좌우 턱관절 위치와 하악 관계 | 같은 하악 전체를 0°/10°/20° 강체 회전. 두개부/위턱 고정, 관절 외 침범 수치와 이미지 별도 확인 |

실제 골격의 연결과 빈 공간은 자료를 따른다. 네 개체의 머리 비율은 사용자가 조정한 제작값이며 이 자료의 견종별 복제가 아니다. 말티푸의 미용된 털 윤곽을 뼈 실측으로 사용하지 않는다.

## 후속 학습·픽셀화에 남길 데이터

`geometry.pkl`과 품종별 `*-regions.npz`에는 정점·삼각형·법선·정점별 영역 ID를 저장한다. `regions.json`은 두개부, 전두부, 비골 지붕, 상악 측벽, 경구개, 절치부, 광대활, 관절 받침, 하악체, 상행지, 근돌기, 관절돌기, 코연골의 제작 영역을 구분한다. 매끄럽게 결합한 경계의 태그는 제작 규칙으로 분류한 영역이며 실제 뼈 봉합선의 실측 분할 정답이 아니다.

이 단계는 구조 기준 모델과 부위 정보를 준비하는 단계다. 사용자 최종 선택과 독립 검토 전에는 학습 정본으로 승격하지 않는다. 실제 학습 실행이나 픽셀 단순화는 아직 하지 않았다.
