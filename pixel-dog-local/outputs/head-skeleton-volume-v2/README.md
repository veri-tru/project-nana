# 머리 골격 입체 구조 v2 — 검토 통과 후보 06

2026-11-06 현재 상태: 독립 외형 PASS, 독립 기술 PASS, 전달 검사 READY. 다섯 비교판과 네 개체의 형상·영역 데이터는 독립 전체 재생성과 일치한다. 사용자 최종 선택은 PENDING이다. 턱 몸통/상행지의 이음새와 일부 거친 표면은 MINOR로 남는다. 판정 근거는 `visual-review.md`, `technical-review.md`, `review-status.json`이다.

2026-11-06 사용자는 기존 주둥이 단축을 유지한 채 작업을 계속하고, 이 구조를 학습 기준으로 삼은 뒤 픽셀 단계에서 간략화하라고 지시했다. 따라서 현재는 두개부·전두부·비골 지붕·상악 벽·경구개·절치부·광대활·하악체·상행지·근돌기·관절돌기의 연결과 공간을 확보한다. 털과 외피, 픽셀 단순화, 실제 모델 학습은 아직 실행하지 않았다.

`head-skeleton-v1`의 실패 기록은 유지한다. 이 폴더는 선 도해에 음영을 더한 출력이 아니라, 음함수로 생성한 닫힌 3D 표면을 같은 좌표에서 여러 방향으로 렌더한다. 위쪽 구조와 아래턱은 별도 강체이고, 아래턱은 기존 좌우 TMJ 축으로 회전한다.

실제 자료는 `references.json`에 연결한 IMAIOS 개 머리 CT 모듈의 공개 측면·윗면·정면 이미지다. 세 원본을 직접 열어 상대 연결을 대조했다. 네 품종 각각의 CT를 등록하거나 치수를 측정한 것이 아니다. 품종의 주둥이 길이는 사용자 피드백으로 단축한 제작값을 사용한다. 해부학 구조의 연결과 데포르메 치수를 혼동하지 않는다.

`profiles.json`은 이전 단축안과 동일하다. 골성 부피, 광대활 돌출, 관자부의 안쪽 들어감, 뼈 두께는 새 제작 변수다. 동일한 폭 입력이 있다고 새 표면의 모든 가로 단면이 이전 도해와 같다고 주장하지 않는다. 말티푸의 주둥이 길이는 유지한다.

현재 출력과 학습 기준 데이터의 적합성은 독립 외형·기술 리뷰를 거쳐야 한다. 검토되지 않은 모델을 정본 학습자료로 승격하지 않는다. 생성기는 `review-status.json`을 변경하지 않는다. 실행: `python outputs/head-skeleton-volume-v2/build.py`.

전체 비교는 `structure.png`의 네 개체 측면·사선·정면·윗면이다. `jaw-motion.png`은 같은 아래턱의 0°/10°/20° 회전, `jaw-detail.png`은 아래턱 단독 세 방향, `joint-detail.png`은 원래 표면을 부분 노출한 왼쪽 관절 진단이다. `structure-detail.png`은 골든의 연결부 확대이며 다른 개체의 검토를 대신하지 않는다.

형상과 정점별 제작 영역은 `geometry.pkl`, 네 개체의 `*-regions.npz`, `regions.json`에 저장한다. 이 자료의 영역은 실제 뼈 봉합선의 실측 분할 정답이 아니다. 머리 골격 검토이며 기존 목·몸통 또는 피부·표정에 적용한 결과가 아니다.

개발 중 3차 하악 지지/관절 가림, 4차 턱 회전 충돌, 5차 말티푸 앞쪽 광대활 뿌리 단절을 발견했다. 이미지상 연결돼 보인 5차 외형 판단은 3D 연결 검사 뒤 정정했다. 해당 결과와 보고서는 `iterations/03`, `iterations/04`, `iterations/05`, `review-pass04`, `review-pass05`에 보존한다. 현재 판정은 별도 `review-status.json`을 따른다.
