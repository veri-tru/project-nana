## 이전 조사와 자세 지침의 연결

[시각적 습관 요소 조사](../../exa-results/dog-behavior-2026-10-17/report.md)와 [행동·클립 연결 설계](../../docs/personalization-spec.md)를 참고했습니다. 아래 5종은 이번 시각화에 필요한 대표 후보로 선정했으며 개 행동의 빈도 상위 5개라는 의미는 아닙니다.

| 동작 | 기존 자료의 구분 | 이번 제작 지침 |
|---|---|---|
| 걷기 | 접근·따라가기에서 걷기 자산 재사용 | 몸통을 수평으로 지지하고 한 앞발을 앞으로 들어 내미는 중간 자세. 달리기·점프와 구분 |
| 엎드려 쉬기 | LIE/E015, 머리 높이와 다리 배치 분리 | 가슴·복부를 낮추고 앞발 둘을 나란히 뻗으며 뒷다리는 접음. 머리는 든 상태 |
| 앞발 하나 들기 | PAW_HOVER/E002, 공중 들기와 접촉 구분 | 앉은 지지 상태에서 한 앞발만 아래 가슴 높이로 접어 띄우고 다른 앞발은 접지 |
| 기지개 | STRETCH/E024, 놀이 자세와 맥락 구분 | 앞발 둘을 앞으로 뻗어 접지하고 앞가슴을 낮추며 뒷다리로 엉덩이를 높임 |
| 몸 털기 | SHAKE/E023, 잔떨림과 구분 | 서 있는 몸의 작은 비틀림과 귀·털의 흔들림을 한 자세로 표현. 일부 보조선 사용 |

발 위치·시선·구도 등 세부사항은 문헌의 직접 인용이 아니라 시안을 위한 제작 지침입니다. 실제 개체의 자주 하는 자세·상황·빈도·좌우 선호는 이번 생성으로 확정하지 않습니다. 기지개와 놀이 자세는 한 장의 모양만으로 구분할 수 없고, 열린 입과 혀도 헥헥거림을 증명하지 않습니다.

## 생성 방식과 검토 결과

내장 image_gen으로 각 PNG를 별도로 생성했습니다. 편집 참조는 [P1 수정본](../dog-crayon-round-eyes-20261101/P1-round-eyes.png) 또는 [P2 수정본](../dog-crayon-round-eyes-20261101/P2-round-eyes.png) 하나입니다. 새로운 원본 사진 분석이나 P3 이미지 참조는 하지 않았습니다. 두 안에 공통 화풍·작은 원형 점눈·같은 동작 자세 지침을 주었으며 서로 다른 것은 기준 그림입니다. 전체 요청은 [prompts.json](prompts.json)에 남겼습니다.

- 10장 모두 작고 둥근 점눈과 회색·흰색 중심의 개체 표현이 이어지는지 확인했습니다. 눈의 픽셀 크기·머리 비율·무늬 경계를 프레임 사이에서 고정한 결과는 아닙니다.
- 걷기는 들어 올린 앞발, 엎드림은 낮은 몸통, 앞발 들기는 한 앞발의 접힘, 기지개는 높은 엉덩이와 뻗은 앞다리로 차이를 볼 수 있습니다. 몸 털기는 귀·털과 보조선에 의존합니다.
- 꼬리 배치는 자세에 따라 달라졌습니다. 특히 P1도 걷기·기지개에서 꼬리가 올라가므로 기준 그림의 낮은 꼬리 배치를 모든 자세에서 유지했다고 볼 수 없습니다. 고정된 꼬리뼈 형태를 재현했다는 판정도 하지 않습니다.
- 다리의 원근·가림과 발 지지, 걷는 주기, 몸 털기의 머리→몸통 전파, 시작/종료 전환은 연속 프레임과 실제 재생에서 추가 검수가 필요합니다. 몸 털기 보조선은 설명용이며 앱 애니메이션의 필수 요소로 정하지 않았습니다.
- 이번에는 모든 조건에 동작 지침을 주었으므로 지침 유무의 우열을 검증한 실험은 아닙니다. 동작별 지침이 유용할 수 있다는 사용자 가설을 제작에 적용한 탐색입니다. 보호자 닮음·동작 선호·의미 판독 평가는 남아 있습니다.

원본 10개는 모두 1254×1254px 종이 배경 PNG입니다. 원본 그림은 생성 후 수정하지 않았고 비교판에서만 같은 배율로 축소·배치했습니다. 개체의 실제 사진은 이 폴더에 복사하지 않았습니다. 파일 수·크기·해시는 [validation.json](validation.json)에 기록했습니다. 해상도별 스프라이트·8fps 동작·접지선·부품 호환은 아직 구현·검증하지 않았습니다.
