## 구조와 용어

- `cranium`은 하나의 고정 그룹이다. 정수리(crown), 이마(forehead), 이마–주둥이 전이(stop), 콧등(nasal_bridge), 위턱의 앞/뒤 방향점(maxilla_front/back)을 포함한다. 정수리와 이마는 **털을 제외한 두개부 형태를 제어하는 제작 기준점**이며, 특정 뼈의 정밀 해부 landmark를 실측했다고 하지 않는다.
- `nasal_base`는 **코연골이 시작되는 후방 부착 방향점**이다. 코 가죽의 시작 경계나 비강 바닥과 같다고 정의하지 않는다. `nose_tip`은 연부조직의 앞끝 부착점이다. 둘을 뼈나 독립 회전 관절로 취급하지 않는다.
- 파란 순서는 머리의 등쪽 형태를 연결하는 가이드다. 정수리에서 코끝까지 6개의 관절을 직렬로 만든 것이 아니다. 각 기준점은 고정 두개부 좌표계에 속한다.
- `mandible`은 별도 강체다. 두개부에 놓인 좌우 TMJ를 잇는 축에서만 회전한다. 0°는 중립 제작 자세이며 치열·교합 접촉은 아직 모델링하지 않았다. 그림의 턱 선 전체를 동일 행렬로 돌리며, 회전 후 보간선을 다시 계산해서 변형하지 않는다.
- 회색 단면은 머리 폭과 위턱 깊이를 제어하는 입체 제작 틀이다. 눈 위치 원과 귀뿌리는 부착 가이드이며 실제 뼈 구멍·연골 외피를 복제한 것이 아니다. 초록 선은 후두부–C1–C2 방향 가이드다.
- 좌표는 머리의 공통 중립 공간이다. x는 뒤쪽, y는 위쪽, z는 개체의 왼쪽이다. `parent`는 동작 소유 그룹이고 `point`는 부모 상대 오프셋이 아닌 머리 중립 좌표다. 기존 몸통 리그로 변환하는 어댑터와 외피 연결은 아직 적용하지 않았다.

## 자료와 적용 범위

연결 관계는 [IMAIOS 개 머리 CT 해부](https://www.imaios.com/en/vet-anatomy/dog/dog-head), [전두골의 두개부·비골 쪽 관계](https://www.imaios.com/en/vet-anatomy/anatomical-structures/frontal-bone-11073890488), [BSAVA 머리 방사선 해부](https://www.bsavalibrary.com/content/chapter/10.22233/9781910443187.chap8)를 참고한다. BSAVA는 공개 검색 초록에 나온 구조 목록까지만 확인했고 본문 접근은 제한됐다. 골성 비부와 앞쪽 연골의 구분은 Elsevier *Textbook of Veterinary Anatomy*의 [공개 검색 발췌](https://elsevier-elibrary.com/contents/fullcontent/58986/epubcontent_v2/OEBPS/B9781416066071000116.htm)를 보조로 사용했으며 전문 열람으로 표시하지 않는다.

품종의 외형 방향은 [골든 표준](https://grca.org/find-a-golden/more-topics-before-you-buy/akc-breed-standard/), [휘핏 표준](https://www.ukcdogs.com/whippet), [닥스훈트 표준](https://www.ukcdogs.com/dachshund)을 참고한다. 말티푸는 사용자가 선택한 `1-55765.jpg`의 짧은 주둥이와 둥근 두개부 방향만 참고한다. 미용된 털 윤곽으로 가려진 뼈 치수를 측정했다고 하지 않는다. 둘째 사진은 이전 입·혀 참고 용도로 보존하며 이번 골격 수치의 측정 근거로 쓰지 않는다.

`profiles.json`의 길이·높이·폭은 모두 **제작자가 정한 비교용 수치**다. 품종 표준에 있는 치수이거나 CT에서 추출한 값이 아니다. 같은 배율로 네 개체를 비교하지만 실제 개체의 신체 크기 비교는 아니다.
