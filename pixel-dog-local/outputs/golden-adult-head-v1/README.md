# 골든 리트리버 성견 머리 비율 후보

2026-11-06 사용자: “골드리트리버는 대형견이라 얼굴스켈레톤 좀 손봐야할듯”. 골든만 별도 분기에서 수정하며 현재 스켈레톤과 v2/13 외피 원본은 보존한다.

## 수정 근거

기존 골든은 머리 윤곽이 둥글고, 주둥이 외피의 폭 제어값이 13.0으로 말티푸의 13.4와 비슷했다. 같은 숫자가 실제 생물학적 크기를 뜻하지는 않으나 품종 특징을 분리하는 표현 제어가 부족할 수 있다. 골든 사진과 [GRCA의 AKC 품종 기준](https://grca.org/about-the-breed/akc-breed-standard/)의 넓고 완만한 두개부, 깊고 넓으며 두개부로 매끄럽게 이어지는 주둥이를 방향 근거로 삼았다. 수치는 사진 실측·CT·체중 기반 계산이 아닌 데포르메 제작 가설이다. 대형견이라는 이유만으로 모든 머리를 일률적으로 확대하지 않는다.

## 같은 기준에서 세 강도 비교

기존 B 외피와 연결된 `head-skeleton-volume-v2` 06 골격을 출발점으로 한다. A/B/C는 하나의 비율 조정 벡터에 각각 0.75/1.00/1.25를 곱한다. 골격 두개부 폭, 상악·하악 지지 폭, 정수리 높이, 주둥이 앞뒤 길이와 깊이를 함께 조정한다. 이전의 주둥이 단축을 전부 취소하지 않고, 끝을 3/4/5 설계 단위 앞으로 조정한다.

| 항목 | 기존 | A | B | C |
|---|---:|---:|---:|---:|
| 두개부 폭 제어값 | 21 | 23.25 | 24 | 24.75 |
| 주둥이 전방 폭 제어값 | 8.5 | 10 | 10.5 | 11 |
| 외피 주둥이 반폭 제어값 | 13 | 15.25 | 16 | 16.75 |
| 외피 주둥이 높이 제어값 | 10.8 | 11.7 | 12 | 12.3 |
| 주둥이 끝 전방 이동 | 0 | 3 | 4 | 5 |
| 정수리 제어점 낮춤 | 0 | 1.5 | 2 | 2.5 |

눈의 반경과 코의 공통 템플릿·개체 배율은 유지하지만, 새 골격에 맞춰 눈·코·귀 부착 위치와 외피를 다시 계산한다. 기존 검은 코 정점의 절대 위치까지 동일하다고 주장하지 않는다. 짧은 목의 생성 규칙은 유지하고 폭 입력의 영향을 받는다. 귀는 넓어진 두개부에 뿌리 틈이 생기지 않도록 배치용 폭을 21+(새 두개부 폭-21)×0.55로 별도 조절한다. 따라서 귀·목 전체 정점 불변도 주장하지 않는다.

## 결과와 재생성

- `exterior-comparison.png`: 기존/A/B/C의 실제 외피, 측면·사선·정면·후면·윗면. 행마다 같은 3D 형상을 같은 배율로 투영한다.
- `skeleton-comparison.png`: 같은 골격의 다섯 방향.
- `jaw-check.png`: 기존/A/B/C의 0/10/20° 아래턱 회전. 외피 표정 애니메이션을 제작한 것은 아니다.
- `model-A.pkl` 등: 새 골격과 외피의 실제 정점·면·영역·제작 설정.
- `parameters.json`: 제어값. `build.py`와 `exterior_seed.py`: 재생성 코드.

실행: `python outputs/golden-adult-head-v1/build.py A`, `B`, `C`를 각각 실행한 뒤 `python outputs/golden-adult-head-v1/build.py render`. 이 폴더 안에만 새 모델과 보드를 저장한다. 세 개별 생성은 독립 프로세스로 병렬 실행할 수 있다.

기존 스켈레톤 제작기와 외피 v2 제작기를 재사용한다. `exterior_seed.py`는 v1의 외피 초기화 코드를 보존한 사본에 골든 주둥이 폭/높이 제어만 추가했다. 후처리는 v2의 B(400회)를 세 후보에 동일 적용한다. 사본의 기존 독립 실행 함수는 이번 경로에서 사용하지 않는다.

픽셀 그림을 이미지 모델로 다시 생성한 결과가 아니다. 골격 파라미터와 실제 메시를 수정한 중립 머리 후보이며, 최종 선택 전이고 픽셀 재작화·전신 체격·표정 세트·실제 모델 학습은 이번 범위에 포함되지 않는다. 최종 전달 상태는 `review-status.json`을 따른다.

## 개발 중 수정

1차 B/C의 귀뿌리 틈을 구현자와 기술 리뷰어가 확인했다. 기술 검사에서 외피의 실제 두 통로가 확인되어 전달 FAIL로 보존했다. `iterations/01`에 당시 코드·모델·이미지·검사 기록을 남기고, 귀 배치 폭을 보정해 다시 생성한다. 최종 통과 여부는 새 파일의 검토로 결정한다.

## 최종 검토

2차 A/B/C 후보는 독립 외형·기술 PASS. 모든 최종 이미지 52셀과 실제 저장 메시를 검토했다. B/C 귀뿌리 틈은 해결됐으며 작은 귀뿌리 능선만 MINOR로 남는다. A 전체 골격/외피 재생성은 배열 일치, 세 보드는 재렌더 바이트 일치다. B/C는 전체 모델 생성 반복 대신 실제 저장 메시를 직접 검증했다. 모든 후보의 뼈-외피 포함/교차와 0/10/20도 턱 간섭 검사를 통과했다. 사용자 선택은 PENDING이다.
