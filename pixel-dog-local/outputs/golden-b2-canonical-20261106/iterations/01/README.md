# 정본 B2 화풍의 골든 재작화

사용자 지시: “기존 시안으로 정본화하고 다시만들어”. 기존 `B2 / SOFT PIXEL` 네 품종 보드를 `references/styles/breed-head-b2/v1`에 원바이트로 보존하고 현재 머리 화풍 정본으로 고정했다. 골든 수정 adult-B의 실제 엔진 참조를 형상 입력으로 사용했다. 모델/체급 계층 코드는 변경하지 않았다.

`comparison.png`는 3행(A/B/C) × 5시점(측면·사선·정면·후면·윗면)의 고해상도 이미지 모델 시안이다. A는 정본 기준 음영, B는 조금 옅은/작은 그늘, C는 조금 깊은/큰 그늘을 목표로 한다. 모두 같은 B2 화풍이며 형상 변경을 의도하지 않았다. 이미지 모델 출력은 정확한 메시 재투영이나 바이트 단위 통제 실험이 아니므로 실제 차이는 독립 검토로 확인한다.

`generation.json`은 실제 도구 입력과 원본 저장 위치, `evidence.json`은 입력/출력 해시를 기록한다. 정본과 실제 3D를 참조했지만 실제64×64·5색 팔레트·이진알파·정수격자·애니메이션 자산을 검증한 결과는 아니다. 원본 기하와 사용자 화풍 선택은 구분하며 새 그림 자체의 사용자 선택은 대기 중이다.

최종 독립 외형/기술 검토와 전달 상태는 `review-status.json`을 따른다. 다른 개체들과의 화풍 일치와 수정 골든 비율을 함께 검토한다.
