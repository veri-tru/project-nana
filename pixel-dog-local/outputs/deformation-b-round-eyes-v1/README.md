# B 머리의 눈만 원에 가깝게

사용자는 비교판을 본 뒤 ‘괜찮은데’라고 긍정적으로 답했다. 현재 둥근 눈 형태를 유지하며 추가 변형하지 않는다. 이는 눈 수정에 대한 피드백이며 전체 캐릭터나 모든 시점의 원형 투영 승인으로 확대하지 않는다.

세 품종의 눈을 원에 가깝게 만들라는 요청이다. 기존 B 1.70배 머리의 눈 중심은 그대로 두고, 가로·세로 반경을 기존 두 반경의 기하평균으로 통일했다. 기존 타원의 면적을 기준으로 크기를 최대한 보존하는 작화값이며 실제 색 영역 면적이 완전히 같다는 뜻은 아니다. 눈의 기울기는 0, 외곽식 지수는 2로 설정한다. 눈동자·반사광의 색과 상대 배치는 기존식을 사용한다.

머리·귀·코의 모든 3D 정점은 그대로이며 눈 주변 재질만 바뀐다. 눈은 같은 두개 곡면에 붙어 있어 시점에 따른 타원 투영은 남는다. 카메라마다 눈을 따로 늘리거나 얼굴을 변형하지 않았다. 몸통 작업은 없다.

공유 v3 렌더러에는 `eye_tilt`와 `eye_power` 선택값만 추가했다. 기본값 .12와 1.7은 그대로여서 기존 입력의 출력은 유지된다. 새 분기에서만 원형 설정을 넘긴다. 이전 B 머리 이미지·NPZ와 골격·사진 프로필 파일은 수정하지 않았다.
