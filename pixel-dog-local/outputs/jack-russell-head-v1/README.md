# 잭 러셀 테리어 머리 골격 후보

사용자 “잭테리어도 골격 만들어봐”에 따라 현재 머리 엔진 범위에서 Jack Russell Terrier를 추가한다. 골든 A는 화풍 선택으로 유지한다. 이 결과는 픽셀 재작화가 아니라 실제 골격과 중립 외피 메시다.

## 형태와 근거

[FCI 345](https://www.fci.be/Nomenclature/Standards/345g03-en.pdf) 3쪽과 [Royal Kennel Club 품종 기준](https://www.royalkennelclub.com/breed-standards/terrier/jack-russell-terrier)의 평평하고 적당한 폭의 두개부, 과하지 않은 이마 꺾임, 두개부보다 조금 짧고 튼튼한 주둥이/턱, 작게 접힌 귀를 방향 근거로 사용한다. FCI 표지의 실제 개 사진은 외형 참고, 기존 IMAIOS 일반 개 두개골 자료는 위턱·광대활·하악의 연결 참고다. 잭 러셀 개체의 CT나 실측 치수는 없다.

모든 좌표·벽 두께·턱관절 크기·외피 여유·귀 부피는 제작값이다. 소형 분류는 모델을 작게 렌더하는 배율과 구분하고 얼굴형의 자동 결정 근거로 쓰지 않는다. 털무늬를 넣지 않은 중립 외피는 부착부 확인용이며 실제 개체의 털색이나 선택된 B2 픽셀 화풍을 대체하지 않는다.

## 세 후보

- A: 기준 주둥이 앞뒤 길이의 94%.
- B: 기준 길이.
- C: 기준 길이의 106%.

이마 꺾임(stop) 앞쪽 제어점의 x만 바꾸고 두개부 폭/높이·주둥이 폭/높이·코 크기·눈·귀·외피 후처리 설정은 공유한다. 이에 맞춰 위턱과 아래턱 앞쪽도 재구성한다. 모델 단위는 cm가 아니며 숫자는 품종의 실측 통계가 아니다.

## 파일

- `skeleton-comparison.png`: 각 A/B/C를 측면·사선·정면·후면·윗면에서 실제 투영.
- `exterior-comparison.png`: 같은 골격을 감싼 중립 외피와 짧은 목, 접힌 귀.
- `jaw-check.png`: 같은 아래턱 전체의 0/10/20도 회전.
- `model-A/B/C.pkl`: 실제 골격/외피 배열과 설정.
- `parameters-A/B/C.json`: 숫자와 추정 범위.
- `references.json`, `source-guards.json`: 참고자료와 보존할 기존 파일 해시.

`build.py`는 기존 골격/외피 구성기를 읽기 전용으로 불러온다. `exterior_seed.py`는 이전 seed 사본에 잭 러셀용 키·주둥이·조직 여유·코 크기를 분리한 전용 입력이다. 이 seed의 과거 독립 실행부는 사용하지 않고 `build.py` 경로만 사용한다. 귀는 새 button_ears 필드가 대체한다.

전신·경추·치열·교합·외피 개폐 애니메이션은 이번 범위가 아니다. 최종 전달 상태는 `review-status.json`을 따르며 사용자 선택은 대기 중이다.

## 최종 검토와 엔진 등록

독립 외형·기술 검토 PASS, 전달 게이트 READY다. 39개 이미지 셀, 18개 메시, 턱 0/10/20도 9개 상태를 확인했다. B 모델 전체 재생성 데이터와 비교판 3장의 PNG 재출력이 일치한다. 귀 뒤쪽의 얕은 사선 주름은 외형 MINOR로 남아 있다. 사용자 선택은 PENDING이다. 등록 후 `python -m unittest discover -s tools/head_engine/tests -v`의 21개 테스트가 모두 통과했다(132.677초). 새 품종 3안의 실제 검토 모델 로딩과 기존 엔진/픽셀 회귀를 포함한다.

머리 엔진 catalog에 `jack_russell`과 `jack-russell-A/B/C`를 등록했다. B는 작업 기본값이다. 독립 등록 검토에서 기존 4개 품종·6개 preset·체급·렌더 입력과 엔진 코드가 그대로임을 확인했다. [기술 검토](technical-review.md), [외형 검토](visual-review.md), [등록 검토](technical-catalog-review.json)를 함께 보존한다.

## 개발 중 수정

1차 외피의 둥근 후두부가 잭 러셀의 평평한 정수리를 가려 외형 MAJOR로 차단됐다. 코 안쪽 지지 부품의 외피 관통도 기술 MAJOR였으며, 귀 아래에는 작은 관통 통로가 있었다. 원본은 `iterations/01`과 initial 보고서에 보존했다.

수정3은 위턱·아래턱 배열을 그대로 두고, 후두부를 국소 골격 단면과 상하부 여유가 다른 단면으로 감싸도록 바꿨다. 귀끝을 전하방으로 뻗게 하고 귀 아래 국소 지지를 추가했다. 코 지지 부피는 실제 외피의 코 템플릿 안쪽에 맞췄다. 개발2에서 하악 하단 여유가 부족했던 검사 기록은 `development`와 technical-preflight 기록에 남긴다. `revision-03.json`은 위턱·아래턱 배열 불변을 기록한다.
