# 머리·턱·짧은 목 재구성 v2

현재 수정 후보 09는 **VISUAL=PASS / TECHNICAL=PASS / DELIVERY=READY / 사용자 결정=PENDING**이다. [외형 검토](visual-review.md)는 네 개체의 76개 정적 시점·표정을 직접 확인했고, [기술 검토](technical-review.md)는 실제 표면·관절·혀 접촉·간접 입력을 검사하고 네 PNG의 바이트 단위 재현 일치를 확인했다. 미해결 BLOCKER/MAJOR는 없으며 말티푸 콧등의 희미한 음영층(VV09, MINOR)은 남아 있다.

정확한 파일 해시와 전달 상태는 `review-status.json`을 따른다. 이전 `cranio-cervical-v1`의 사용자 거절과 개발 과정의 외형 FAIL은 그대로 보존한다. 내부 후보 통과는 최종 사용자 승인이나 연속 동작 검증을 뜻하지 않는다.

## 범위

골든 리트리버·휘핏·닥스훈트·크림색 말티푸의 머리와 짧은 목, 기본·반쯤 감기·눈 감기·입 벌림·혀 내밀기·코 핥기 및 추가 중간 벌림 상태다. 전신, 연속 애니메이션, 실제 반려견 닮음 승인, 실측 해부학 치수는 이 작업의 결과가 아니다.

## 구현

- 머리의 닫힌 외피를 입체 거리장으로 변환하고, 후두부–C1–C2–하부 목 제어점을 따르는 목 볼륨과 합친다. 최종 머리·목은 하나의 닫힌 삼각형 표면이다. 기존 방사형 표면을 아래로 늘리는 방식은 사용하지 않는다.
- 아래턱은 두개골 하위의 좌우 턱관절에 연결된 별도 닫힌 표면이며, 모든 벌림 상태에서 같은 축을 중심으로 강체 회전한다. 입꼬리와 관절의 위치는 서로 다르다. 뺨으로 덮이는 후방 턱가지와 노출된 입 앞부분을 구분한다.
- 휘핏은 고정 윗주둥이의 부푼 밑면부터 줄인다. 말티푸는 둥근 두개·짧고 넓은 주둥이와 두께 있는 귀를 별도로 구성한다. 목 지지점을 앞으로 조정하면서 머리·얼굴 기준점의 월드 좌표는 보상해 유지한다.
- 기존 세 개체의 귀 표면·뿌리 입력과 둥근 눈의 기준점/반경을 유지한다. 말티푸 귀는 얇은 연결 탭이 없는 닫힌 단면으로 교체한다. 눈은 표면의 국소 범위에 표시해 정면에서 띠가 되지 않도록 한다.
- 공통 코의 원형상과 개체별 배율(0.78 / 0.62 / 0.72 / 0.58)을 사용한다. 말티푸의 두개·주둥이 재구성은 코 피부 전체 길이 뒤에서 시작한다. 볼륨 격자와 삼각형 표면으로 변환하므로 원본 정점의 비트 단위 일치를 주장하지 않는다.
- 혀는 두께 있는 닫힌 단면이다. 실제 아래턱/머리의 거리장과 대조해 위치를 보정하며, 코 핥기 끝점은 현재 코 표면에서 찾는다. 수치 접촉 검토와 시각 검토를 각각 기록한다.

말티푸 참고는 [Maruone의 특정 크림색 강아지 사진](https://maruone.com/blog/entry/35932)이며 `private-data/volume-refs/maltipoo.jpg`에 보관했다. 개체 사진을 고정된 품종 표준이나 실측 골격으로 해석하지 않는다. 원본 사진은 Git에 넣지 않는다.

모든 경추·턱관절 위치, 목 두께, 벌림 각도와 비율은 데포르메를 위한 제작값이다. 7개 경추의 실제 뼈 형상이나 의학적 정확도를 구현했다고 주장하지 않는다.

## 실행과 검토 파일

프로젝트 루트에서 `python outputs/head-neck-volume-v2/preview.py`를 실행한다. `geometry.pkl`은 이 로컬 생성기가 만든 검토 데이터이며 외부에서 받은 pickle은 로드하지 않는다.

검토 환경의 패키지 버전은 이 폴더의 `requirements.txt`에 기록했다. 글꼴은 기존 렌더러가 사용하는 Windows 글꼴이며 독립 재현 기록에 파일 해시를 포함한다. 기존 정적 픽셀 제작기의 별도 요구사항 파일은 변경하지 않았다.

| 파일 | 검토 범위 |
|---|---|
| `views.png` | 네 개체 측면·정면·사선 |
| `attachments.png` | 후면·윗면·귀 숨김 측면·귀 숨김 사선 |
| `expressions.png` | 요청한 여섯 표정 + 중간 벌림, 사선 |
| `mouth-side.png` | 닫힘·중간·열림·혀 내밀기·코 핥기, 귀 숨김 측면 |

`visual-review-development-*.md`와 `iterations/`는 실패와 수정 과정이다. 통과하지 않은 개발 이미지를 최종 후보로 전달하지 않는다. 독립 기술 리뷰의 `review_audit.py --reproduce`는 별도 폴더에서 재생성하고 간접 Python/JSON 입력 및 글꼴 해시를 수집한다. 최종 전달 전 `python tools/review/check_delivery.py outputs/head-neck-volume-v2/review-status.json`으로 보고서·입력·출력 해시와 판정을 대조한다.
