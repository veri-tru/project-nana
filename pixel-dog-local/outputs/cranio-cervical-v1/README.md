## 실제 구현

- 네 개체에 같은 `neck.lower → neck.C2 → neck.C1 → head.occipital_joint → body.head` 계층을 적용했다. 머리 아래 `face.skull → face.jaw_axis → 좌우 jaw_hinge`는 별도 분기다. 말티푸에도 같은 목 계층이 있다.
- C1/C2와 하부 경추 기준점 사이를 보간한 타원체 외피로 목을 생성한다. 연결 시작 범위는 후두부와 목 반경에서 결정하며 턱 축에서 정하지 않는다. 두개골 뒤아래 표면과 합쳐 하나의 연속 격자로 만든다. 단순한 골격선 덧그리기가 아니다.
- 입 때문에 잘린 머리 단면과 목 단면의 서로 다른 정점 배열이 옆면 접힘을 만들 수 있어, 접합부의 외곽을 구한 뒤 공통 중심에서 방사 방향으로 재표본화한다. 최초 검토에서 발견한 골든/휘핏의 단면 자기교차를 이 방식으로 수정했다. 이는 근육의 세부 굴곡을 단순화한 외피다.
- 모든 품종에 아래턱 뒤쪽부터 좌우 턱관절까지 올라가는 표면을 적용했다. 기존 골든/닥스/말티푸의 후방 88% 압축·매립 분기를 대체했다. 아래턱은 좌우 관절을 잇는 축을 중심으로 강체 회전한다.
- 기본·반쯤 감기·눈 감기 상태도 같은 관절 아래턱의 0도 상태를 사용한다. 눈과 귀, 개체별 축소한 공통 코를 유지한다. 두개골 뒤아래·턱·목은 이번 구조 수정 범위다.
- 비교판의 청록 선은 목을 생성하는 후두부/C1/C2/하부 경추 제어점이다. 갈색 선은 실제 아래턱 표면의 단면 중심에서 턱관절까지의 경로다. 사진의 옛 턱 가이드 점을 새 표면의 뼈처럼 표시하지 않는다.

## 출력

- `structure.png`: 네 개체의 측면 기본, 측면 입 벌림과 연결선, 사선 기본.
- `expressions.png`: 입 벌림·혀 내밀기·코 핥기.
- `rigs.json`: 부모–자식 계층과 제작 좌표.
- `recipe.json`: 제작 파라미터, 표정별 관절·목·혀 정보, 주요 입력 및 출력 해시.

## 참고와 제한

사용자 첨부 골격도의 연결 관계 및 [개 턱관절 CT 연구](https://www.frontiersin.org/journals/veterinary-science/articles/10.3389/fvets.2024.1407761/full), [후두부–환추 해부 연구](https://pubmed.ncbi.nlm.nih.gov/24712312/)를 구조 참고로 사용했다. 아래턱의 관절과 후두부–경추 연결을 구분한다.

관절 좌표·경추 방향·목 반경·턱 두께는 현재 데포르메를 위한 제작값이다. 하부 경추는 하나의 제어점으로 단순화했고, 7개 경추의 뼈 형상·각 분절 운동·근육·피부 변형을 재현한 모델은 아니다. 짧은 목 아래는 절단면으로 끝난다. 전신·어깨 연결과 머리 회전 애니메이션은 이번 출력 범위가 아니다.

말티푸는 제공된 개체 사진이 없는 작화 후보이며, 이전 주둥이 단축 작업을 입력으로 사용했다. 외형 적합성과 자연스러움은 사용자 판단을 기다린다. 독립 검토는 제작 방법과 재현성 검증이며 미감 승인이 아니다.
