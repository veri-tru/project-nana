# P1·P2 작은 원형 점눈 비교

2026-11-01. 사용자가 기존 비교의 눈을 작고 둥근 점눈으로 통일하고 P3는 AI slop 느낌이라 제외하도록 지시했습니다. 내장 image_gen으로 P1·P2의 눈을 수정한 뒤 생성된 눈 주변만 원본에 반영했습니다. 점의 최대 지름은 약 32px로 맞췄으며, 눈 주변 64×64 영역 두 곳 밖의 변경 픽셀은 각 0개입니다. 눈 주변 털은 제한된 편집 영역에 포함됩니다.
