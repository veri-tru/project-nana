# 말티푸 · 사용자 사진 기준 수정

**외피 작업 중단 · 전달 BLOCKED.** 사용자가 정수리→이마→위턱→코끝의 머리 골격부터 다시 잡도록 지시했다. 후속 작업은 `../head-skeleton-v1`이다. 개발 중 실패 결과와 단일 상세판 진단 이력은 보존하며 완료 후보로 전달하지 않는다. 최종 전달 판정은 `review-status.json`과 독립 외형/기술 보고서의 동일 해시 판정을 따른다. 이전 `head-neck-volume-v2`의 PASS는 이 수정본에 승계하지 않는다.

사용자는 **첫 사진을 기본 외형, 둘째 사진을 입·혀 참고**로 선택했다. 원본 경로·SHA-256·용도는 `references.json`에 기록했으며 사진은 출력 폴더에 복제하지 않았다. 두 사진이 같은 개체라는 가정은 하지 않는다.

- 첫 사진: 짧게 다듬은 둥근 정수리, 볼과 수염 털의 둥근 덩어리, 코 아래의 턱털, 아래·뒤로 넓어지는 귀를 참고한다.
- 둘째 사진: 아래턱이 열리며 생기는 입안 공간과 바닥에 지지되는 짧고 넓은 혀를 참고한다. 긴 털과 큰 수염의 외곽을 기본형에 섞지 않는다.
- 털 외피와 실제 턱·경추 제어점은 구분한다. 사진에서 보이지 않는 뼈 위치나 정밀 3D 비율은 실측값이 아니며 제작자가 설정한 데포르메 값이다.
- 기존 B 머리 표현, 둥근 눈, 공통 코 형태와 개체별 크기 원칙을 유지한다. 말티푸의 눈 위치·반경과 털 외피는 사진 방향에 맞춰 조정한다.
- 골든·휘핏·닥스훈트는 수정 범위 밖이며 이전 v2의 실제 저장 형상·재질·리그와 동일함을 검사한다.

실행: 프로젝트 루트에서 `python outputs/maltipoo-photo-v1/preview.py`. 패키지 버전은 `requirements.txt`에 기록한다. 머리와 짧은 목의 정적 검토이며 전신·연속 애니메이션·픽셀 정본 적용은 포함하지 않는다.
