# 잭 러셀 개체 귀 형태 적용 시안

사용자 “이번 개체에 적용해봐”에 따라 선택된 잭 러셀 A의 얼굴·배색·음영을 기준으로 귀 형태를 비교한다. 1 접힌 귀, 2 반쯤 선 귀, 3 선 귀이며 각 행은 측면·사선·정면·후면·윗면 5시점이다. 귀 이외의 특징 유지가 편집 목표다. 이미지 모델 출력이므로 픽셀 단위 불변이나 정확한 3D 투영은 보증하지 않는다.

실제 개체 사진은 제공되지 않아 관찰된 귀 형태가 아닌 선택용 제작 후보다. 좌우 비대칭은 이번 후보에 도입하지 않았다. 기존 잭 러셀 A의 선택 기록과 골격 B는 보존한다. 이 결과는 built-in image_gen 고해상도 시안으로, 엔진 귀 변형 코드·3D 메시·native64 실행 자산은 변경하지 않았다.

generation-06.json이 최종 프롬프트·이미지 입력 순서를 기록한다. generation.json 및 generation-02~05.json은 이전 시도 이력이다. 최종 검토 범위는 마지막 저장 comparison.png의 15셀 전체이며 전달 판정은 review-status.json을 따른다.

검토 보조자료: 기존 FCI 345 실제 개 사진과 승인된 잭 러셀 A, [FCI 88](https://www.fci.be/Nomenclature/Standards/088g01-en.pdf)의 앞쪽으로 접힌 귀끝 구조, [FCI 166](https://www.fci.be/Nomenclature/Standards/166g01-en.pdf)의 선 귀와 앞쪽 귓바퀴 구조를 참고한다. 뒤의 두 자료는 생성 입력이 아닌 수정 후 구조 검토용이며, 다른 품종의 얼굴형·귀 크기를 이식하거나 잭 러셀의 품종 기준·개체 사실로 해석하지 않는다.

## 수정 이력

1차의 반직립 구분 부족을 고친 2차는 TOP 아래 귀가 기존 접힌 형태로 남아 독립 검토 FAIL이었다. 3차의 잘린 기둥 형태, 4차의 접힘 누락도 제외했다. 5차는 직선 분할과 직립 귀로 번진 접힘 표시 때문에 독립 검토 FAIL이었다. 각 그림과 보고서는 iterations에 보존한다. 최종 6차는 실패 이미지를 입력에서 제외하고 승인 A와 B2 정본 두 장에서 새로 생성했다. 실제 최종 프롬프트는 generation-06.json이다.

## 최종 검토

6차는 독립 외형·기술 PASS와 전달 READY다. 15셀 전체와 최종 파일/입력 11개 해시를 확인했다. 비귀 영역의 작은 음영 차이(JET02 MINOR)는 남아 있으므로 픽셀 단위 귀만 교체된 결과로 주장하지 않는다. 사용자 귀 형태 선택은 PENDING이다.
