## 내부 기준과 이번 적용 범위

근거 문서는 [개발 지침](../../AGENTS.md), [자산 규격 초안](../../docs/asset-spec.md), [개체 개인화 설계](../../docs/personalization-spec.md)입니다. 픽셀 격자·해상도 제한은 이번 크레용풍 예외 범위이며 개체의 근거·일관성 기준은 유지했습니다.

| 기준 | 적용한 내용 | 확인 상태 |
|---|---|---|

| 귀·꼬리·털 일관성 | 짧은 처진 귀와 긴 꼬리털, 일정한 미용 상태를 요청. 기준 그림처럼 꼬리를 낮게 배치하도록 보강 | 5종에서 낮은 꼬리 배치 확인. 흔들리는 귀·털의 시간 변화는 미검증 |
| 비대칭·방향 | 원본 측면을 유지하고 좌우 반전·미확인 반대쪽 무늬 추가 금지 | 제작 과정에서 반전하지 않음. 실제 개체의 양측 무늬 전체가 확인된 것은 아님 |

## 제작과 보존 검증

내장 image_gen에 이전 P1 동작 그림을 편집 대상으로, 수정된 점눈의 P1을 개체 기준으로 전달했습니다. 각 동작에 동일한 내부 일관성 규칙과 기존 행동 자세 지침을 붙였습니다. P2의 추가 생성·수정은 하지 않았습니다.

생성기의 좌표 지시만으로 접지가 고정됐다고 간주하지 않고, 생성 후 발 아래의 어두운 윤곽을 정렬 기준으로 잡아 위아래로만 이동했습니다. 5장의 이동량은 걷기 +21px, 엎드림 +65px, 앞발 들기 -36px, 기지개 +13px, 몸 털기 -35px입니다. 확대·축소·왜곡·좌우 반전 없이 이동했으며 이동 대응 위치의 그림 픽셀 불일치는 0개입니다. 최하단 윤곽은 접지의 시각적 대리값이며 골격·발 접촉의 실측값은 아닙니다.

P2 사본 5개는 이전 원본과 파일 해시가 같습니다. 비교판에서만 동일 배율로 축소·배치했습니다. 기존 P1·P2 그림과 원본 자료는 덮어쓰지 않았습니다.
