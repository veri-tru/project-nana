# 개체 외형을 유지한 낙서 선화 재검토안

2026-11-01. 사용자가 이전의 과도하게 길고 비대칭인 안을 거부하고, 개체별 개인화 원칙은 원본 정책대로 유지하도록 지시했다. 이번 A/B/C는 실제 사진의 서 있는 외형을 다시 기준으로 잡고, 선과 묘사량을 비교하는 고해상도 정적 시안이다. 픽셀 규칙은 이번 낙서 시안에만 적용하지 않는다.

comparison.png는 왼쪽부터 A/B/C다. 같은 개체와 비슷한 서 있는 자세를 요청했으나 독립 생성 결과의 형태·무늬 경계가 픽셀 단위로 일치하는 비교물은 아니다. 행동 개인화 A/B 자료로 사용하지 않는다. 최종 화풍이나 닮음 승인은 아직 받지 않았다.

## 원본 개성화 원칙의 적용

기준 문서는 docs/personalization-spec.md와 docs/asset-spec.md다. 사용자 지시는 기존 원칙의 유지이며, 이번 작업에서 새로운 개체 분류 정책을 만들지 않았다.

- 품종 이름을 추정해 외형을 정하지 않는다. 사진에서 관찰되는 개체 특징을 참고한다.
- 이번 시안에 요청한 외형 단서는 짧고 둥근 회색 접힌 귀, 흰 이마 중앙과 주둥이, 회색 등·상부 다리, 흰 가슴·아래쪽 발, 뒤쪽 다리 곁으로 내려온 꼬리다.
- 보이지 않는 반대쪽 무늬와 정확한 실측비는 미확인이다. 좌우 반전이나 새로운 반점을 개인화 사실로 등록하지 않는다.
- 사진 관찰·보호자 보고·제작 기본값·미확인·충돌과 보호자 확인을 구분하는 원본 구조를 유지한다. 생성 결과를 새 관찰 근거로 사용하지 않는다.
- 특징 최대 3개의 우선순위는 보호자가 정한다. 위 제작 단서는 이번 그림의 관찰 목록이며 보호자가 확정한 특징 3개로 취급하지 않는다.
- 행동의 발생·빈도·상황은 이번 정적 이미지에서 추정하지 않는다. 기존 응답·관찰 근거로 개인화한다.
- 자산 호환·다른 방향·동작·소유자 닮음 검수는 미확인 상태다.

## 제작과 검토

내장 image_gen으로 사진 기반 기준안을 만들고, 그 기준안에 대해 내부 털선·명암을 줄이는 편집을 각각 요청했다. 길어진 귀와 올라간 꼬리가 포함된 중간 결과는 최종안에서 제외했다. 사진과의 대조에서는 귀가 짧고 볼 곁에 놓이는지, 몸통이 과장되어 늘어나지 않았는지, 흰 얼굴·가슴·발과 아래로 향한 꼬리가 유지되는지 확인했다. 정확한 닮음은 보호자 확인이 필요하다.

원본 생성 이미지를 각 PNG로 복사했으며 비교판만 표시 크기에 맞게 배치했다. 원본 사진은 이 폴더에 복사하지 않았다. 전체 생성·편집 요청문은 prompts.json, 실제 파일 크기와 미확인 항목은 review.json에 기록했다.
