# 골격 기반 개체별 머리 — 수정 후보

현재 후보는 11 구조의 [A](heads-A.png)·[B](heads-B.png)·[C](heads-C.png)다. 네 개체 × 다섯 시점 × 세 안의 외형 검토와 실제 저장 표면·전체 재생성 기술 검토를 통과했다. 사용자 선택은 대기 중이며, 최종 전달 판정은 [review-status.json](review-status.json)을 따른다. [외형 보고서](visual-review.md) · [기술 보고서](technical-review.md).

2026-11-06 사용자 요청으로 `head-skeleton-volume-v2`의 검토된 골격에서 골든 리트리버·휘핏·닥스훈트·말티푸의 외피 시안을 다시 만든다. 해당 골격을 이번 작업의 기준으로 사용한다는 지시이며 이전 실패 외피의 승인이 아니다.

실제 상부 골격과 아래턱 정점을 입력으로 사용한다. 앞뒤 위치별 단면의 볼록 껍질에서 각도별 외피 반경을 계산하며, 두개 뒤쪽은 뼈 단면을 포함하는 하나의 연속 타원 곡면으로 감싼다. 뼈의 구멍이나 후두 돌출을 피부 외곽에 그대로 복사하지 않는다. 원본 골격과 사용자가 조정한 주둥이 길이는 변경하지 않는다. 수치는 모델 제작 단위이며 실제 개의 실측 치수가 아니다.

주둥이는 폭과 높이가 남는 둥근 앞면을 갖는다. 그 뒤에서 단면이 다시 잘록해지지 않도록 개체별 최소 지지 폭과 높이를 유지한다. 코는 이 앞면의 위쪽에 국소적으로 연결하며, 전체 주둥이·입술·턱을 코끝 하나로 수렴시키지 않는다. 공통 코 템플릿에 개체별 균등 배율을 적용한다. 실제 코 표면의 노출 경계는 주둥이와의 매립 관계도 받는다. 코 연골은 위치 참고로만 사용하며, 골격 내부 포함 검사의 대상은 상부 뼈와 하악이다.

귀는 좌우 대칭의 두께 있는 연속 곡면이다. 골든·닥스훈트·말티푸는 세로 단면으로, 휘핏은 접힌 경로를 따라 만든다. 눈은 안와 부근에서 실제 외피와의 교점을 구해 부착하며, 둥근 눈이 피부 안쪽에 일부 들어가도록 배치한다. 머리·귀·코·목은 하나의 닫힌 피부 메시이며 눈은 별도 닫힌 메시다. 짧은 목은 뒤통수 아래의 단면 곡면으로 경추 실측 복제가 아니다.

기존 B 데포르메와 둥근 눈을 참고한다. 말티푸는 사용자가 선택한 첫 사진의 짧게 다듬은 기본형을 참고하며 둘째 사진의 긴 털을 혼합하지 않는다. 사진은 외형 참고이며 가려진 뼈 치수의 실측 근거로 취급하지 않는다.

A/B/C는 같은 골격·코 템플릿·귀 경로·목·색을 쓰고 외피 여유 3.2/4.6/6.0의 제작값을 비교한다. 품종별 여유 배율을 적용하며 눈 중심과 뼈 단면에서 유도한 앞면·뒤통수 외피도 이에 따라 달라진다. 각 비교판은 한 메시의 측면·사선·정면·후면·윗면이며 네 개체에 동일 배율을 적용한다. A/B/C는 이번 볼륨 비교안의 이름이고 기존 B 데포르메 선택을 변경하는 새 화풍 선택이 아니다.

현재 기본 표정의 머리와 짧은 목만 구현한다. 입 벌림/혀/여섯 표정, 전신, 실제 모델 학습과 픽셀 간략화는 이번 결과에 포함하지 않는다. 내부 검토 통과는 사용자 닮음·취향 승인이나 실측 해부학 정확도 보증을 뜻하지 않는다.

전체 생성: `python outputs/skull-based-heads-v1/build.py`. 한 볼륨안만 생성하려면 마지막에 A/B/C를 지정한다. 최종 검토는 전체 재생성으로 부분 생성 캐시도 검증한다. 생성기는 리뷰 판정이나 사용자 결정을 기록하지 않는다.

실패 이력: 02의 일괄 팽창한 얼굴과 07의 원뿔형 주둥이는 사용자 거절이다. 09의 병목·말티푸 귀, 10의 단면 연결부, 12의 코 과매립도 보존한다. 11의 코 아래 둥근 볼륨은 실제 사진·다각도 재검토와 별도 독립 대조에서 구조 분리와 구분했으며, 최초 FAIL과 정정 근거를 함께 보존했다. 현재 남은 외형 MINOR는 코 아래의 둥근 명암과 골든 귀 뿌리의 작은 돌기다. `iterations`의 개발 진단 파일을 새 후보나 사용자 승인 결과로 표시하지 않는다.
