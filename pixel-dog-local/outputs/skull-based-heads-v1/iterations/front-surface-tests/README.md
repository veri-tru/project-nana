# 개발 진단 자료 — 전달 후보 아님

11의 둥근 주둥이 앞면을 검토하면서 시험한 반경 지수·아랫면 후퇴·법선 계산 비교다. 실제 생성 위치는 `skull-based-heads-v1` 루트였으며 시험 후 이곳에 보존했다. 보존된 스크립트의 상대경로는 원래 실행 위치 기준이다.

이 시험 이미지들은 최종 후보가 아니다. 이어진 12의 평평한 앞면은 코 과매립으로 실패했다. 최종 후보는 11 구조를 실제 사진·다각도와 다시 대조한 뒤 유지한 A/B/C이며, 별도의 최종 외형·기술 보고서와 `review-status.json`을 따른다.
