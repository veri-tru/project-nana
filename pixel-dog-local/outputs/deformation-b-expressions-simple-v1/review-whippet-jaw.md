# 휘핏 아래턱 수정 독립 검토

> 이전 직선 입선 버전의 검토 이력이다. 사용자가 우거지상 인상을 거절하고 곡선을 요청했으므로 현재 후보에는 `review-whippet-neutral.md`의 후속 검토를 적용한다.

2026-11-05. 현재 세션과 같은 모델의 새 리뷰어 `whippet_jaw_review`가 최종 저장 PNG 네 개를 각각 열고, 이전 코드와 현재 코드의 좌표·재질·재현성을 비교했다. 구현 코드는 수정하지 않았다.

**METHOD_REVIEW_PASS / USER_REVIEW_PENDING**

사용자의 ‘턱이 그릇 같다’는 지적과 후속 측면 사진에 맞춰 휘핏 입 절단부와 아래턱의 길이·깊이·폭을 조정한 범위의 방법론 검토다. 실제 개체 닮음, 최종 미감 또는 사진 해부학 실측 검증을 뜻하지 않는다. 이전 `review.md`의 해시·통과 결과를 이번 변경에 전용하지 않는다.

## 실제 이미지 확인

`whippet-jaw-before-after.png`, `expressions.png`, `expressions-side.png`, `mouth-options.png`를 최종 렌더 완료 후 각각 열었다. 전후판은 같은 배율과 같은 벌림에서 측면·사선을 비교한다. 측면에서 아래턱 앞끝이 코 가까이 전진하고, 짧고 깊게 처진 하부보다 길고 얕은 형태가 됐다. 실제 열린 틈은 유지된다. 사선에서는 입 경계가 비스듬히 내려오는 형태로 보인다. 이 관찰을 미감 승인으로 해석하지 않는다.

제공된 측면 사진도 실제로 열었다. 사진은 길게 뻗은 주둥이·아래턱 관계를 참조한 자료이고, 코드의 깊이·폭·각도를 실측한 자료가 아니다. 정확한 품종·개체 식별이나 전체 체형 변경으로 범위를 넓히지 않았다.

## 변경 격리와 형상

- 골든 리트리버와 닥스훈트는 여섯 표정의 모든 정점·재질 배열이 이전 코드와 정확히 같다.
- 휘핏의 기본·반쯤 감기·눈 감기 역시 이전과 정확히 같다. 모든 입 상태에서 귀는 원본과 같다.
- 휘핏 코·눈의 어두운 재질 영역은 재질 오차 0, 해당 정점 좌표 오차 최대 `2.34e-11`로 부동소수점 수준이다. 분할 후 좌표가 유지된 외피 면의 재질 변경은 0이다.
- 아래 수치는 1.70배 확대 전 모델 로컬 단위이며, 사진 실측값이 아니다. 동일한 노출부 범위 기준으로 계산했다.

| 항목 | 이전 | 수정 |
| --- | ---: | ---: |
| 턱 앞끝 x | -21.8200 | -25.2175 |
| 앞끝~기존 입꼬리 길이 | 9.6662 | 13.0637 |
| 노출부 최대 깊이 | 1.6499 | 1.1000 |
| 노출부 최대 폭 | 6.4202 | 5.9642 |

입선 변경 때문에 단순히 폭 배율만으로 전후 폭을 추정하지 않고 실제 단면을 비교했다. 중간 0.86 배율에서 폭이 오히려 늘어나는 점을 지적했고, 최종 0.76 배율에서는 위 표처럼 실제 폭도 줄었다.

## 관절과 혀

- 세 품종 각 벌림에서 아래턱의 역회전 및 표본 정점 쌍 거리 오차는 최대 `7.11e-15`, 관절축 이동은 0이다. 같은 품종에서 벌림 각도에 따라 아래턱 자체가 휘지 않는다.
- 휘핏 혀는 새 입선·바닥에 맞춰 다시 배치됐다. 내부 바닥 접촉 오차는 `6.67e-16` 이내, 아랫입술 지지점 오차는 `1.29e-16` 이내다.
- 휘핏 내부 혀의 최소 윗구개 여유는 0.2914이며, 바닥 폭에 대한 최소 옆 여유는 혀 내밀기 0.8007·코 핥기 0.9507로 모두 양수다.
- 혀의 코 접촉점 오차는 0이다. 외부 최대 두께는 혀 내밀기 1.275·코 핥기 0.975로 기존 두께를 유지한다.
