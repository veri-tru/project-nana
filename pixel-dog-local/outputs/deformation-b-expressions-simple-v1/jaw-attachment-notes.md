# 휘핏 턱 뒤쪽 연결 구조 수정

사용자 지적은 ‘턱이 목 중간에 달려 있다’였다. 이전에 보존하던 고정 머리 표면의 하부 윤곽이 주원인이었다. 원본 head generator도 사진 프로필이 뒤통수에서 인접 목까지 이어진다고 명시한다. 기존 cheek 전이는 입 뒤에서 이 낮은 원본 외피를 복원했고, 턱 축은 로컬 y=-1.424에 놓여 있었다. 회전 거리 보존 검사만으로는 이 부착 위치 오류를 검출할 수 없었다.

## 현재 구조

- 휘핏의 실행 시 턱 축 y를 기존 temple.y−1.2인 **5.365**로 옮겼다. x=-3.914와 좌우 간격 z=±5.925는 유지한다. 원본 B.json은 수정하지 않고 새 실행 좌표를 recipe에 기록한다.
- 머리 아래 경계는 입꼬리에서 볼 안쪽으로 올라간다. 관절 근처의 두개 하부는 hinge.y−1.2인 **4.165**이며 그 뒤는 등록된 후두점까지 둥글게 닫는다. 목으로 내려가는 원본 하부를 다시 복원하지 않는다.
- 아래턱 뒤쪽은 중앙의 가는 점으로 축소하지 않는다. 앞 턱 단면에서 좌우 관절 끝점으로 이어지는 가지를 만들고, 마지막 단면을 실제 좌우 관절축에 맞춘다. 관절 뒤까지 늘어진 아래턱 면은 제외한다.
- 기본·반쯤 감기·눈 감기에도 같은 얕은 아래턱과 정리한 두개 하부를 덮는 연속 외피를 적용했다. 닫힌 입에는 구강색 판이나 새 입술 외곽선을 칠하지 않는다. 따라서 **휘핏 기본형 전체 정점이 이전과 동일하다는 과거 조건은 이번 변경에 적용하지 않는다.** 보존 대상은 코·눈·귀와 전면 윗주둥이이며 바뀐 부위는 아래턱·뒤쪽 머리 하부다.
- 골든 리트리버·닥스훈트는 여섯 표정 모두 이전과 동일하게 유지한다. 몸통이나 실제 목은 새로 만들지 않는다.

좌표는 모두 B 1.70배 확대 이전의 로컬 제작 단위다. 위 위치와 여유는 현재 캐릭터용 작화값이며 실측 해부학 좌표가 아니다. [BSAVA 턱관절 자료](https://www.bsavalibrary.com/content/chapter/10.22233/9781910443286.chap25)와 [개의 턱관절 형태 연구](https://www.frontiersin.org/journals/veterinary-science/articles/10.3389/fvets.2024.1407761/full)는 하악과 측두골의 연결 관계를 확인하는 데만 사용했다. 사용자 제공 그레이하운드류 사진 역시 형태 참고이며 치수를 측정한 자료가 아니다.

`python preview.py`와 `python whippet_attachment_comparison.py`를 순서대로 실행한다. 직전 실패 버전은 `preview-before-jaw-attachment.py`에 보존했다. `recipe.json`과 `whippet-attachment-recipe.json`은 입력·출력 해시와 실행 턱 축을 기록한다. 이전 검토는 현 파일의 검증으로 사용하지 않는다.

사선에서 뒤쪽 아래에 가늘게 보이는 부분은 이번에 만든 턱이나 귀 뿌리가 아니라, 가림이 해제된 반대편 귀 끝이다. 부위별 진단 렌더로 확인했으며 귀 모양을 바꾸거나 삭제하지 않았다. 현재 결과는 머리만의 정적 후보로 사용자 검토 대기다.
