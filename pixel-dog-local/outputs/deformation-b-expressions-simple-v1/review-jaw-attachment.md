# 휘핏 턱 뒤쪽 연결 구조 독립 검토

2026-11-05. 새 동일 모델 리뷰어 `jaw_attachment_review`가 원인 분석부터 최종 저장 PNG 네 개의 실제 열람, 형상·변경 범위·재현 검증을 수행했다. **METHOD_REVIEW_PASS / USER_REVIEW_PENDING**. 이번 통과는 아래 명시한 구조와 제작 방법 검증이며 닮음·미감·사용자 인상을 승인한 것이 아니다.

## 이전 실패의 원인과 이번 검증 범위

이전에는 입 뒤에서 고정 머리의 원본 하부 윤곽을 복원했다. 원본 head generator는 사진 윤곽이 인접 목까지 포함됨을 명시한다. 실제로 x=-10의 원본 아래 경계는 y=-2.955, x=-4는 y=-2.355였다. 낮은 원본 외피가 그대로 남은 상태에서 별도 턱만 회전하므로 턱이 목 덩어리 중간에 붙은 것처럼 보였다. 기존 y=-1.424의 축과, 뒤로 갈수록 중앙으로 축소되는 턱도 부착 구조를 충분히 표현하지 못했다. 강체 회전 오차가 작다는 사실만으로 이 문제가 해결된 것은 아니었다.

현재는 다음을 별도로 검증했다.

- 실행 관절축은 `(-3.913687, 5.364588, 0)`이며 좌우 끝은 z=±5.925다. 원본 B 파일을 변경하지 않은 실행 시 제작값이다. 코·눈·귀의 실제 해부학으로 측정한 좌표가 아니다.
- 뒤쪽 아래턱의 마지막 좌우 정점은 두 관절 끝점과 **오차 0**으로 일치한다. 아래턱의 최대 x는 관절 x와 같아 관절 뒤로 늘어나는 턱 면이 없다. 중앙의 가는 끝으로 축소하는 이전 구조와 다르다.
- 고정 머리 하부는 입 뒤에서 위로 올라간다. x=-10/-8/-6/-4/0/3의 현재 열린 머리 아래 경계는 각각 약 0.008/0.913/2.575/4.127/4.850/6.339다. 원본의 낮은 목 하부로 되돌아가지 않는다. 관절 뒤도 후두점으로 올라가며 닫는다.
- 기본·반쯤 감기·눈 감기의 연속 외피 역시 이 하부 구조를 따른다. x=-10 이후 위 표본들에서 닫힌 머리와 열린 머리의 고정 두개 하부가 정확히 같다. 앞쪽 닫힌 아래턱은 얕은 피부로 덮으며 구강색 선을 새로 칠하지 않는다. 따라서 이번에는 휘핏 기본형 전체 좌표가 이전과 동일하다고 주장하지 않는다.
- 골든 리트리버와 닥스훈트는 여섯 상태 모두 정점·재질 배열이 이전과 정확히 같다. 휘핏의 귀도 여섯 상태 모두 정점·재질이 정확히 같다. 코·눈 보호 정점의 최대 차이는 3.98e-11 렌더 단위로 보간 수치 오차 수준이다. 닫힌 세 상태의 재질 배열은 이전과 정확히 같다.

## 저장 이미지 확인

`expressions.png`, `expressions-side.png`, `mouth-options.png`, `whippet-attachment-before-after.png`를 각각 직접 열었다. 측면에서 이전의 낮은 뒤쪽 덩어리가 제거되고 아래턱 뒤쪽이 볼 안쪽으로 올라가는 것이 보인다. 사선에서도 턱 끝이 낮은 외피 중간에 붙는 이전 외곽과 달라졌다. 기본·눈 상태의 뒤쪽 하부도 함께 정리됐다. 이미지의 잘림이나 칸 겹침은 없다. 이 관찰을 자연스러움·개체 닮음의 최종 승인으로 해석하지 않는다.

사선 뒤쪽의 가는 갈색 부분은 부위별 색 분리와 귀 제외 렌더로 확인했다. 턱의 잔여 면이나 귀 뿌리가 아니라 **반대쪽 귀의 자유 끝부분**이다. 두개 하부를 줄이면서 가림이 해제된 것이며 귀 좌표는 바꾸지 않았다. `review-attachment-components.png`와 `review-attachment-ear-tip.png`는 이 원인 확인용 내부 진단 그림이지 새 선택 시안이 아니다.

## 회전·혀 지지

2.32°/3.48°/4.64°에서 아래턱 rest 좌표가 같고 고정 머리는 움직이지 않는다. 역회전 복원 오차 최대 7.11e-15, 관절축 이동 0이다. 이 검사 외에 위의 실제 관절 끝점 연결과 두개 하부 위치를 따로 확인했다.

혀 내밀기·코 핥기 모두 입안 바닥 접촉 오차는 -2.22e-16 이내, 아랫입술 지지점 오차는 0이다. 구개 여유 최솟값은 각각 0.3833/0.2564, 측면 여유는 0.6224/0.7724 로컬 단위로 양수다. 코 핥기의 지정된 코 표면 접촉 오차는 0이다. 정적인 두 표면 상태에 대한 확인이며 모든 연속 애니메이션이나 생체 연부조직까지 검증한 것은 아니다.
