현재 결과는 [턱 뒤쪽 연결 구조 수정](jaw-attachment-notes.md)이다. 머리에 포함돼 있던 목 쪽 하부를 분리하고, 휘핏 아래턱의 양쪽 뒤끝을 올라간 관절 위치에 연결했다. 기본·눈 표정도 같은 하부 구조로 맞췄다. [현재 전후](whippet-attachment-before-after.png).

## 이전 수정 이력

[현재 곡선 수정 독립 검토](review-whippet-neutral.md): 최종 4개 PNG 재현·변경 범위·턱 회전·혀 지지를 확인했다. 사용자 시각 승인은 별개다.

최신 휘핏 수정: 이전 직선 입선이 ‘우거지상’처럼 보인다는 지적과 ‘입이 곡선으로 빠져야 할 듯’ 요청을 반영했다. 앞쪽 높이를 2.0 로컬 단위 낮추고, 얕게 내려갔다 입꼬리 쪽으로 완만하게 이어지는 곡선으로 교체했다. 곡선의 양끝 접선은 수평이며 입꼬리가 볼로 이어지는 전이를 5.0 단위로 넓혔다. 턱 깊이 상한 1.10은 유지하고 반폭은 2.98로 제한한다. [직전 결과와 곡선 수정 비교](whippet-neutral-before-after.png). 다른 품종·눈·귀·기본형은 유지한다. 아래 직선 턱 수정은 이전 이력이다.

후속 휘핏 수정: ‘턱이 그릇 같다’는 지적과 사용자가 제공한 그레이하운드류 측면 사진을 참고했다. 아래턱을 단순히 얇게 누르는 대신 입선을 코 가까운 앞 입점부터 뒤 입꼬리까지 곧게 연결해 턱 앞끝을 연장했다. 턱 깊이는 같은 단면의 55% 이하·최대 1.10 로컬 단위, 폭은 새 절단면의 76%로 제한한다. [휘핏 측면·사선 전후](whippet-jaw-before-after.png). 이 수치는 사진 실측이 아닌 제작값이다. 골든·닥스훈트와 기본·눈 표정은 그대로다.

사용자가 이전 턱 구조 시안을 ‘괴물 같다’고 거절하고 입도 단순화할 것을 요청했다. 이어 휘핏처럼 주둥이가 얇은 품종의 표현 문제를 지적했다. 기존 `deformation-b-expressions-v1`는 거절된 구조 실험 이력으로 남기고, 새 후보를 이 폴더에 분리했다.

## 변경 범위

복잡한 사진 입선과 앞쪽의 인위적인 절단 폭 전이를 제거했다. 한 개의 낮은 입술 평면과 기존 둥근 주둥이의 교차로 입을 나누며, 들쭉날쭉한 앞 입술을 만들지 않는다. 옆에서 입선은 단순한 직선에 가깝고 아래턱의 바깥은 기존 머리의 둥근 표면을 따른다. 관절 근처의 아래턱은 볼 안에 들어가도록 rest 형상을 좁혔다. 뒤쪽 볼은 고정해 관절 둘레의 노출된 고리 모양을 줄였다. 열린 앞부분을 막는 측면 면은 만들지 않는다.

아래턱 전체는 기존 관절축을 중심으로 강체 회전한다. 이전 14°보다 작은 벌림을 사용하고, 얇은 주둥이에 같은 아래턱 두께·벌림을 강제하지 않는다. 아래 값은 **실측 품종 해부학이 아닌 현재 캐릭터용 제작값**이다.

| 품종 | 입선·아래턱 설정 | A / B / C 벌림 | 코 핥기 벌림 |
| --- | --- | --- | --- |
| 골든 리트리버 | 22% | 4° / 6° / 8° | 4° |
| 휘핏 | 얕은 입 곡선·넓은 입꼬리 전이, 깊이 최대 1.10 | 2.32° / 3.48° / 4.64° | 2.32° |
| 닥스훈트 | 20% | 3.4° / 5.1° / 6.8° | 3.4° |

여섯 표정판의 입 벌림·혀 내밀기는 B 열의 중간값을 임시로 사용한다. 사용자가 B를 선택했다는 뜻은 아니다. 입안의 작은 면만 어두운 재질을 사용하고 새로운 입술 외곽선은 그리지 않는다.

후속 지적 ‘혀가 공중에 떠 있고 두께감도 없음’을 반영했다. 혀 아랫면은 입안 바닥과 아랫입술을 넘는 지점에 실제로 접촉한다. 내부 단면의 반두께는 틈의 28% 이하이며 중심을 그 반두께만큼만 올려 바닥에 놓는다. 입 밖은 작은 입 틈에 맞추던 두께 제한을 해제해 반두께를 품종 주둥이 반폭의 8.5%(코 핥기 6.5%)까지 늘리고 끝을 둥글게 닫았다. 혀 내밀기는 앞으로 나온 뒤 아래로 내려가며, 코 핥기는 코 표면 정점에 혀끝이 닿는다. 이는 색만 덧칠한 두께 표현이 아니라 표면 단면 좌표의 변경이다. recipe에 아랫입술 지지점·중심·반두께와 외부 최대 두께를 기록한다.

기본·반쯤 감기·눈 감기, B 머리 배율 1.70, 귀와 코·눈 입력은 유지했다. 머리 자체나 몸통의 비율을 다시 설계하지 않았다. 각 판 안에서는 같은 배율·카메라와 품종별 고정 원점을 사용한다. 정적인 표현 후보이며 사용자 검토 대기다.

## 재현

현재 곡선 전후 비교는 `python whippet_neutral_comparison.py`로 생성한다. `preview-before-whippet-neutral.py`가 직전의 아래로 기운 입선이다. 과거 `whippet-jaw-before-after.png`는 앞선 수정 이력으로 보존하며 현재 상태의 비교판으로 사용하지 않는다. 곡선 깊이·높이 이동·전이 길이는 모두 제작값이다. 중립적인 인상은 표현 목표이지 실제 동물의 감정 추론이 아니다.

`python preview.py`로 세 PNG와 `recipe.json`을 생성한다. recipe는 제작값·카메라·입력 및 출력 해시를 기록한다. 기존 검토 결과를 새 이미지의 승인으로 전용하지 않는다.

`python whippet_comparison.py`는 보존된 `preview-before-whippet-jaw.py`와 현재 구현을 같은 배율·벌림으로 비교한다. 참고 사진 `55757.jpg`는 사용자 첨부이며 개체의 정확한 품종을 확정한 자료가 아니다. SHA-256은 `9c439bdd4b2811a2a9f0eb578dda06909ec080a544e33071bd950b26504c3fb2`. 관찰한 것은 코 가까이 뻗는 아래턱과 비교적 곧고 얕은 턱 윤곽이며, 사진에서 3D 치수나 관절 각도를 측정했다고 주장하지 않는다.
