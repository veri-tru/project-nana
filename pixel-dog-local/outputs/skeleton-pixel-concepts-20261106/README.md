# 현재 머리 스켈레톤 기반 픽셀 시안

2026-11-06 사용자 요청: “현재 스켈레톤 기준으로 각 개체들 품종 픽셀화 해서 시안만들어줘”.

현재 머리 엔진 `skull-based-heads-v2` 개발13의 B를 외형 참고로 삼아 골든 리트리버·휘핏·닥스훈트·말티푸의 머리와 짧은 목을 픽셀 표현으로 비교했다. 네 행은 품종, 다섯 열은 측면·사선·정면·후면·윗면이다. B는 작업 기준이며 사용자가 최종 선택한 외형으로 표시하지 않는다.

- `B2-soft.png`: 털색과 가까운 부드러운 유색 윤곽.
- `C2-clear.png`: 짙고 선명한 대비 윤곽.
- `prompts.json`: built-in image_gen에 전달한 전체 프롬프트, 실제 참조 경로·역할·화풍 영역, 생성 원본 위치.
- `evidence.json`: 결과와 입력의 SHA-256.
- `review-status.json`: 독립 외형·기술 검토와 전달 판정의 권위. 사용자 최종 선택과 별개다.

화풍은 B2/C2 정본 파일의 각 절반을 실제 입력으로 전달했다. 원본 외피 그림은 구조·비율, 사진은 품종·털색 참고다. 골든은 현재 외피의 금색과 귀를 따른다. 도구의 최대 참조 5개 제한 때문에 골든 사진을 별도 생성 입력으로 넣지는 않았으며 구현자가 로컬 사진 자료를 확인했다. 휘핏의 무늬는 작은 화면을 위한 큰 회갈색/밝은 색면으로 단순화했고, 가려진 면의 무늬는 작화상 추정이다.

두 보드는 각각 1536×1024px RGB다. 이는 고해상도 이미지 모델의 픽셀 표현 시안이다. 실제 64×64 격자·5색 팔레트·이진 알파를 검증한 실행 PNG가 아니며 원본 메시를 직접 투영한 결과도 아니다. 시점들은 이미지 모델이 그린 비교용 표현이고 동일 3D 형상의 정확한 재투영을 보장하지 않는다. B2와 C2를 별도로 생성했으므로 색뿐 아니라 작은 실루엣·배치 차이도 있다. 윤곽색만 바꾼 통제 실험으로 해석하지 않는다. 정확한 바이트 재생성, 새 엔진 구현, 모델 학습, 애니메이션, 실기기 검증은 이번 결과에 포함되지 않는다.

기존 스켈레톤·외피·제작기·앱 자산은 수정하지 않았다. 최종 화풍 선택과 실제 64×64 재작화는 후속 작업이다.
