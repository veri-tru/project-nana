RGB 이미지이므로 투명 알파가 없다. 원본 모티프는 64×64 파일이 아니며, 격자 정렬·정수 배율·최근접 확대·실기기 가독성을 검증한 실행 자산으로 사용할 수 없다. 프롬프트의 약 64셀·최대 5색은 생성 지시이고 검증 결과가 아니다. 실제 출력은 프롬프트의 2400×1600-style 요청과 같은 3:2 화면비이며 1536×1024로 저장됐다.

## 입력 출처와 저장 무결성

`evidence.json`에 기록된 출력 2개와 입력 8개의 SHA-256을 현재 파일에서 재계산했고 모두 일치했다. 아래 정형 표식은 그 전체 집합을 그대로 담는다. 결과 두 파일은 `prompts.json`에 기록된 `.codex/generated_images` 원본과 바이트 해시가 일치한다. 복사 과정의 재압축·리샘플링은 없다.

직접 생성 참조는 현재 `skull-based-heads-v2/heads-B.png`, B2/C2 원본 시트, 닥스훈트·휘핏·말티푸 사진 3개다. `prompts.json`의 절대 경로가 증거 파일의 상대 경로와 같은 파일을 가리킨다. B2는 원본 x=[0,887), C2는 x=[887,1774), y=[0,887)이며 1774×887 실제 원본과 정본 manifest의 style ID/영역이 일치한다. `prompts.json`의 region 배열은 끝 좌표 방식이며 manifest의 xywh와 표기 방식만 다르다. 반대 패널의 개체 특징을 옮기도록 지시하지 않았다.

현재 외피 B의 해시는 이전 `skull-based-heads-v2/review-status.json`의 B와 일치하며 그 기록은 READY / 사용자 PENDING이다. 현재 B를 사용자 최종 승인 외형으로 표시하지 않은 README 설명이 맞다. B 입력 자체가 골격 기반 외피의 실제 5시점 렌더이며 이번 생성의 구조 참고다. `parameters.json`에 네 품종 B 항목이 있고 `references.json`의 골격·골격 프로필·눈 참고·네 품종 사진·이전 코 참고·이전 코 geometry 총 9개 간접 참조의 존재와 해시를 추가 대조했다. 전부 일치했다. 이는 출처 연결 확인이며 이전 3D 생성기 전체를 이번에 다시 실행한 검사는 아니다. 이 간접 참조들은 이미지 모델에 별도 전달한 입력으로 기록하지 않았다.

닥스훈트·휘핏·말티푸 원본 사진과 간접 골든 사진 자료도 실제 열람했다. 골든 사진은 이번 5개 생성 입력에 포함되지 않았으며 README가 이를 명시한다. 휘핏의 큰 회갈색/밝은 무늬는 원본 브린들의 작화상 단순화이고, 보이지 않는 뒷면 무늬는 관찰값이 아니다. 이 구분은 prompts와 README에 기록되어 있다.

## 실행 경로, 변경 범위와 재현성

실행 경로는 built-in image_gen이며 새 결정적 생성 코드가 없다. prompts에는 두 전체 프롬프트, 실제 참조 경로, 참조 역할과 영역, 원 생성 파일 위치를 보존했다. 따라서 입력과 요청을 추적할 수 있지만 모델 내부 버전·seed를 고정한 정확한 재생성은 불가능하다. 보고서·README는 바이트 재생성 성공이나 모델 학습을 주장하지 않는다.

출력은 새 `skeleton-pixel-concepts-20261106` 폴더에 격리되어 있다. 현재 골격·외피 참조 해시는 이전 provenance와 일치한다. 저장소에는 기존 수정/미추적 파일이 다수 있으므로 git status만으로 전체 작업 트리 불변을 보장하지 않는다. 이번 검토자는 기술 보고서만 작성했고 이미지나 기존 제작기 파일을 수정하지 않았다.

B2/C2는 독립 생성되었으므로 외곽선 색 외에도 머리 윤곽, 배치, 계단 크기 차이가 보인다. 이는 윤곽색만 바꾼 통제 비교가 아니며 README와 prompts의 제한 설명에 반영되어 있다. 두 정본 화풍의 독립 표현 후보라는 범위에서 비교한다. 같은 매개변수를 달리한 3개 형상 반복 실험이나 새 엔진 변경 라운드로 표시하지 않는다.

## 표면·관절 및 정책 적용

이번 요청은 기존 골격을 참고한 2D 픽셀 표현 시안 제작이다. 기존 머리–턱–목 메시를 수정하거나 새 동일 형상의 실제 렌더를 제공하는 작업이 아니다. 따라서 정책의 머리–턱–목 형상 수정에 필요한 동일 메시 렌더 검사를 이 2D 결과가 통과했다고 판정하지 않았다. 원본 구조의 실제 5시점 렌더와 새 시안의 5시점 표현을 구분했다. 새 보드의 시점들은 이미지 모델의 작화이므로 정확한 3D 재투영·관절 축·표면 포함·접촉·가려진 귀뿌리 연결을 증명하지 않는다. 기본 닫힌 입만 있으며 입 벌림·혀 접촉·연속 동작 검증도 없다.

README는 이 제한을 명확히 표시하고 있으며, 출력에는 native 64×64·validated·exact mesh conversion 같은 주장이 없다. 따라서 현재 요청의 고해상도 표현 후보 전달에 필요한 기술 근거는 갖췄다. 이 PASS를 새 3D 형상 또는 실행 자산 승인으로 승계할 수 없다.

미해결 BLOCKER/MAJOR/MINOR는 없다. 위의 색 수·알파·재현성·동일 형상 투영 제한은 숨겨진 결함을 승인한 것이 아니라 현재 파일의 검증 가능한 실제 성격을 명시한 것이다. 최종 전달은 동일 해시에 대한 독립 외형 PASS, review-status 기록, check_delivery 통과를 모두 요구한다.
