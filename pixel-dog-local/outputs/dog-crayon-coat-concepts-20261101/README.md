# 크레용풍 개체 외형 시안 3종

2026-11-01. 사용자가 제공한 작은 크레용풍 앉은 강아지 디자인을 화풍·단순화의 기준으로 사용했습니다. 실제 개체의 재관찰 기록을 반영하고, 털 길이 선택을 비교하기 위해 얼굴·몸통의 길이를 달리한 3종입니다. 모두 정적 검토용이며 사용자 선택과 닮음 승인은 아직 받지 않았습니다.

| 안 | 원본 PNG | 비교 내용 |
|---|---|---|
| A | [A-short.png](A-short.png) | 얼굴·몸통 털이 짧고 정돈된 표현 |
| B | [B-medium.png](B-medium.png) | 중간 길이, 둥근 수염과 약간의 털 윤곽 |
| C | [C-long.png](C-long.png) | 얼굴·몸통에 더 긴 털 윤곽과 수염 |

모두 1254×1254px의 종이 배경 PNG입니다. 픽셀 격자·48px 규칙을 적용한 자산이 아닙니다. [comparison.png](comparison.png)는 A/B/C를 왼쪽부터 배치한 1536×556px 비교판입니다. 그림 원본은 생성 후 수정하지 않았고, 비교판에서만 축소·배치와 A/B/C 표기를 했습니다.

## 개체 단서와 제작 선택의 구분

- 실제 사진의 회색 처진 귀·얼굴 바깥쪽, 흰 이마 중앙~콧등·주둥이·수염, 회색 몸통과 흰 가슴·아래쪽 발을 단서로 사용했습니다. 참고 그림의 주황색 털은 복제하지 않았습니다.
- 추가 사진 P07에서 관찰한 몸통보다 긴 꼬리털을 세 안에 공통으로 남겼습니다. 이번 길이 비교는 얼굴·몸통 중심이며 전체 부위의 털을 일괄 잘랐다는 뜻이 아닙니다.
- 앉은 자세, 열린 입·작은 혀, 작은 발과 단순화 비율, 낮게 놓인 꼬리는 이번 그림을 위한 표현입니다. 해당 개체의 고정된 습관·감정·꼬리뼈 형태로 저장하지 않습니다.
- 주둥이 길이·흉곽·배선·실측 비율·보이지 않는 쪽 무늬는 여전히 미확인입니다. 그림 속 해석을 관찰 자료로 역등록하지 않습니다.
- 보호자가 고르는 우선 식별 특징 최대 3개와 실제 선호 털 길이는 아직 미선택입니다.

## 생성과 확인 범위

내장 image_gen으로 B를 먼저 생성하고, 같은 B를 바탕으로 A와 C의 얼굴·몸통 털 길이 편집을 각각 요청했습니다. 실물 근거는 원본 P02와 추가 후측면 P07이며, 재관찰 기준은 [개체 관찰](../../reviews/individual-dog-appearance-20261101/report.md)입니다. 원본 사진과 스타일 참고 이미지는 이 폴더에 복사하지 않았습니다.

세 안의 흰 얼굴 중심부·회색 귀·흰 수염·가슴·발, 낮은 긴 꼬리털과 짧음/중간/긺의 외곽 차이를 비교판에서 확인했습니다. 편집 결과 사이에 선·무늬 경계·프레이밍의 미세 차이는 있으며 픽셀 단위로 일치하는 통제 실험은 아닙니다. 원본 레퍼런스보다 내부 털결과 채색 묘사가 더 많아 화풍 단순화의 정도도 사용자 확인이 필요합니다. 동작·다른 방향·실제 표시 기기 호환은 미검증입니다.

전체 요청문은 [prompts.json](prompts.json), 크기·해시·미검증 항목은 [review.json](review.json)에 기록했습니다. build-comparison.cjs는 원본 그림을 바꾸지 않고 비교판을 재작성하는 로컬 스크립트입니다.
