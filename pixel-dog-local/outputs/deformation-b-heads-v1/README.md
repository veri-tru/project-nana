# 머리만 기존 B 데포르메 적용

사용자가 현재 세 머리에 기존 데포르메를 적용하되 ‘머리만 일단’ 보도록 범위를 한정했다. 기존 선택 B의 `head_scale=1.70`을 완성된 머리·귀 전체에 적용한다. 기준은 `deformation-b-face-v3`의 모서리 수정본이다.

머리 연결점(body.head)을 중심으로 완성된 세 표면(머리·양귀)의 모든 xyz에 같은 배율을 곱한다. 코·눈·귀뿌리 및 귀끝도 같은 변환을 받으므로 상대 위치·크기·곡률 비율은 보존된다. 색과 조명은 유지한다. 이는 기존 머리 단위 확대 설정이며 주둥이를 줄이거나 눈을 별도로 키우는 새로운 얼굴형 변형이 아니다. 몸통은 수정하거나 렌더하지 않았다. 원본 v3 파일도 변경하지 않았다.

[전후 비교](heads-before-after.png)는 세 품종·측면·정면·뒷면에 같은 카메라와 픽셀/모델단위 배율을 사용한다. 전후 각 쌍은 같은 머리 연결점 투영을 공유하며, 칸별 자동맞춤으로 확대 차이를 없애지 않는다. 따라서 화면에서 실제로 1.70배 차이가 난다.

`python preview.py`로 재생성한다. `heads-B.npz`에는 적용된 실제 3D 표면과 재질 배열이 있고, `recipe.json`에는 변환 행렬·입력 해시·카메라·배율이 있다. 배율은 기존 작화값이며 실측 해부학 치수가 아니다. 전신 머리높이 48% 충족 여부나 64×64 최종 픽셀 정본을 검증한 결과는 아니다. 사용자 시각 승인은 대기 중이다.
