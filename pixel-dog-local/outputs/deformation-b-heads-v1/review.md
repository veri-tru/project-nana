# 머리 B 데포르메 적용 독립 검토 — 2026-11-05

검토자 `head_deformation_review`. **머리만 기존 B 배율을 적용한 범위의 방법론 검토 통과.** 사용자 미감·닮음 승인을 대신하지 않는다.

## 범위와 근거

기존 `deformation-rig-b-v1/B.json`의 `deformation.head_scale=1.70`을 직접 읽는다. 기존 문서와 생성기는 얼굴 내부 비례를 보존하면서 머리·귀를 하나의 단위로 확대하는 설정이다. 이번 결과는 사진으로 등록한 현재 v3 완성 머리에 이 작화 배율을 적용한 것이다. 새로운 눈 크기나 주둥이 압축률을 추가하지 않았다.

사용자의 후속 범위인 ‘머리만 일단’에 맞춰 몸통을 수정하거나 렌더하지 않았다. 약 48%라는 과거 전신 참고 비율을 충족했다고 주장하지 않는다. 원본 v3는 변경하지 않고 별도 폴더에 결과를 만들었다.

## 실제 파일 검토

`heads-before-after.png`를 직접 열었다. 1800×1010 RGB 이미지이며, 골든 리트리버·휘핏·닥스훈트 각각 측면·정면·뒷면의 전후를 보여준다. 머리와 귀가 화면에서 잘리거나 다른 칸과 겹치지 않는다. 귀 뿌리·코·눈은 기존 머리와 함께 확대되며 별도 재배치가 없다. 이 고해상도 형상 비교는 64×64 픽셀 정본 검수가 아니다.

18칸 모두 픽셀/모델 단위 배율 `3.9291737695769395`를 공유한다. 전후 각 쌍은 동일한 머리 연결점의 투영 위치를 쓰며 개별 자동맞춤이 없다. 실제 투영의 가로·세로 크기 비율을 계산해 9쌍 모두 1.70임을 확인했다. 모델 투영은 모든 패널 내부에 있고, 가장 좁은 수평 여백도 1px 이상이다.

## 좌표와 자료 보존

- 세 품종의 머리 1개·귀 2개 표면 모두 `applied_xyz == source_xyz * 1.70`이 비트 단위로 일치한다. 원점은 기존 머리 연결점이다.
- 재질 배열은 원본과 비트 단위로 같다. 코·눈의 색과 표면상 위치, 귀 연결과 모서리 곡률은 동일한 균등 변환을 받는다.
- 모든 좌표가 유한하며 `heads-B.npz`의 각 표면·재질 배열이 실제 렌더 입력과 완전히 일치한다.
- 입력 해시를 현재 파일과 다시 대조했다. v3 `preview.py`, `B.json`, `profiles.json` 및 기존 B 배율 파일이 기록된 값과 동일하다. 원본과 몸통 입력은 보존됐다.

## 재현성

독립 프로세스에서 `build_heads()`와 `render()`를 다시 호출해 메모리 PNG를 만들고 저장된 비교판과 비교했다. PNG 전체 바이트가 일치했다. 저장된 이미지나 코드에 검토자가 변경을 가하지 않았다.
