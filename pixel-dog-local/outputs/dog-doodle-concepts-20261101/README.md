# 레퍼런스 기반 낙서형 시안 3종

상태: 사용자 반려. 2026-11-01 비율이 기괴하다는 지적을 받아 채택하지 않았다. 개체 외형을 유지한 후속안은 ../dog-doodle-identity-20261101/README.md를 확인한다. 아래 내용과 파일은 제작 이력으로 보존한다.

2026-11-01 사용자 요청에 따라 픽셀 규칙과 48픽셀 제한을 적용하지 않고 제작했다. 첨부된 낙서 레퍼런스의 선과 머리·몸통·다리 비율을 함께 참고했다.

| 시안 | 파일 | 형태 |
| --- | --- | --- |
| A 길쭉형 | A-tall.png | 작은 머리, 늘어진 귀, 길고 가느다란 몸과 앞다리 |
| B 통통형 | B-pudgy.png | 넓고 기울어진 머리, 작은 몸, 아주 짧은 발 |
| C 비대칭형 | C-wonky.png | 긴 물결형 몸통, 서로 다른 귀 길이, 불규칙한 다리 |

세 파일은 흰 배경의 고해상도 PNG다. comparison.png는 비교용 배치이며 원본의 비율을 유지했다. 픽셀화·48픽셀 축소·팔레트 제한을 하지 않았다.

내장 image_gen으로 생성했다. 첫 결과는 선과 털·명암이 지나치게 정돈되어 최종안에서 제외하고, 가장 단순한 낙서 레퍼런스 두 장을 중심으로 다시 생성했다. 최종안은 점눈·작은 코·적은 선, 넓은 빈 면과 과장된 비율을 기준으로 확인했다. 회색 귀·등과 흰 얼굴·가슴·발은 기존 반려견의 식별 단서로 요청문에 반영했다.

레퍼런스의 특정 캐릭터를 그대로 옮기지 않고 새 형태를 생성했다. 출처 로고·워터마크·문구는 결과물에 포함하지 않았다. 최초·최종 요청문과 참고 경로는 prompts.json, 실제 파일 크기와 검수 상태는 validation.json에 있다. 아직 보호자의 닮음 확인과 애니메이션 검수는 하지 않은 정적 콘셉트다.
