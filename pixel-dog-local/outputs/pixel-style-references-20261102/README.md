디자인 방향은 픽셀과 크레용풍을 계속 비교 중이다. 크레용풍 점눈·외곽선 선택은 전체 화풍 확정이 아니다.

사용자 제공 픽셀 레퍼런스 2장과 기존 개체 사진 P02로 내장 image_gen을 사용했다. 털 표현을 더 단순화하라는 피드백을 반영한 최신 후보:

- A-soft-simple.png: 얇은 윤곽과 부드러운 명암. 얼굴·꼬리에 일부 세부 묘사가 남는다.
- B-bold-simple.png: 굵은 외곽선과 큰 색면, 제한된 그림자.
- C-minimal-simple.png: 큰 도트와 점눈, 거의 단색으로 채운 형태.

이전안과 중간 후보도 보존했다. 전체 요청과 참조 경로는 prompts.json, 파일 해시는 hashes.json에 기록했다. 생성 편집이므로 외형·자세의 픽셀 단위 보존을 보장하지 않는다.

정적 육안 검토에서 잔털·내부 명암 조각 감소와 세 안의 차이를 확인했다. 전체 닮음·화풍 승인, 정확한 저해상도 격자·팔레트, 투명 배경, 작은 표시 크기, 애니메이션은 미검증이다. 1254×1254 생성 원본이며 32px/48px 실행 스프라이트가 아니다.
