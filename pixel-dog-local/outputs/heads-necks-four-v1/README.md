## 구현 범위

기존 머리 표면의 뒤쪽 하부를 연속 확장해 짧은 목을 만들었다. 접합부는 좌표 자체를 완만하게 보간하고, 뒤끝 단면을 닫았다. 별도 원통을 겹치거나 음영만으로 이음새를 숨기는 방식이 아니다. 목과 접합부의 정점은 기본 상태에서 계산한 표면으로 여섯 표정 모두 고정하며, 아래턱은 기존 관절축을 따라 독립 회전한다. 목 아래는 짧은 흉상 절단면으로 끝난다.

기존 세 품종의 눈·귀 입력과 구현은 유지했다. 원형에 가까운 눈과 머리 1.70배 설정을 사용한다. 목 형상은 이번 요청에 따라 새로 만든 제작값이며, 전신이나 목 움직임을 구현한 것은 아니다. 기존 출력 폴더는 수정하지 않고 새 분기에서 표정 구현을 가져온다.

말티푸는 별도 제공 사진이 없는 크림색 곱슬 털의 작화 후보다. 둥근 머리, 짧은 주둥이, 처진 귀와 작은 털 굴곡을 새 프로필에 기록했다. 털 굴곡은 머리 상부와 귀의 자유 부분에만 적용한다. 귀 뿌리와 눈 주변에는 적용하지 않는다.

사용자의 후속 지시 ‘다들 코가 남산만한데 개체에 따라 크기 조절’에 따라, 이전 동일 크기 규칙을 공통 형태 + 개체별 균등 배율로 변경했다. 기존 공통 코 대비 골든 0.78, 휘핏 0.62, 닥스훈트 0.72, 말티푸 0.58을 적용한다. 이는 실측 비율이 아닌 이번 작화 후보의 설정이다. 코 전체는 같은 비율로 축소하고 주둥이 접합부는 기존 표면까지 부드럽게 복귀한다. 별도 코 물체를 얹지 않는다. 귀와 두개 뒤쪽, 목 설정은 코 배율에 포함하지 않는다.

## 관찰 근거와 제작값

[AKC 말티즈 표준](https://images.akc.org/pdf/breeds/standards/Maltese.pdf)의 처진 귀와 [Poodle Club of America의 푸들 표준](https://poodleclubofamerica.org/akc-breed-standard/)의 곱슬 털·처진 귀를 부모 품종의 참고 요소로 사용했다. 말티푸 전체의 고정 표준이나 실측 비율로 해석하지 않는다. 크림색, 짧은 주둥이 비율, 귀 길이, 털 굴곡, 목 길이는 이 후보의 제작값이다. `maltipoo-authored.json`에 출처 성격을 명시했다.

## 재생성 및 검증

프로젝트 루트에서 `python outputs/heads-necks-four-v1/preview.py`를 실행한다. `recipe.json`에는 주요 입력 파일과 결과 이미지의 SHA-256, 배율, 품종별 목 설정, 여섯 상태의 턱·혀·목 수치를 기록한다. 실행 환경은 기존 표정 제작기의 Python/NumPy/SciPy/Pillow 및 Windows 글꼴을 사용한다. 전체 간접 의존성을 독립 패키지로 복제한 결과물은 아니다.

최종 저장 이미지 두 장에 대한 독립 방법론 검토는 `review.md`에 기록한다. 기술 검토 통과와 사용자의 외형·자연스러움 판단은 별개다.
