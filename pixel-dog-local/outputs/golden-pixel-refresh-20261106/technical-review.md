## Layering, source integrity and output isolation

- Size class supplies only authored `relative_scale` (0.85/1.00/1.15). For every supported breed, changing among the three classes leaves its selected source model and selector identical. There is no roundness, muzzle or skull-shape rule derived from size class.
- Breed selects a catalogued geometry preset. Individual overrides win for scale and a same-breed preset, with exact per-field evidence metadata. Unsupported keys, cross-breed presets, absent evidence, duplicate JSON keys, invalid numeric types, NaN, infinities and out-of-range scale are rejected. Evidence labels record a claim; they do not authenticate the claim.
- Both rendering consumers read the saved resolved JSON. Re-resolving its original request must equal the complete stored result; modified resolved selections fail. Model/status/renderer hashes are checked before loading the catalogued pickle. A deliberately mismatched model hash was independently tested and rejected. No arbitrary request path is deserialized.
- Golden uses reviewed adult B as a working default with explicit PENDING selection. The other three breeds retain the original saved B arrays. Individual A/C selection is supported within the golden breed without changing source geometry.
- `normalized` uses one common scale across all five projected views; `relative` applies authored scale without silently fitting an oversized result. Pixel-native scene scale is separately documented in pixels/model-unit. Neither mode asserts cm, body mass or measured anatomical dimensions.
- Existing artifacts and review-bearing directories are protected. Independent export rejection checks covered the reviewed source directory, its nested child and a path outside outputs. No existing source geometry, review record or final output was overwritten by this review.

## Native raster and saved-output checks

The pixel adapter calls the pinned depth-buffer `raster` function directly with 64×64 buffers. It does not call the supersampled `paint` wrapper and does not downsample a larger image. The projected triangle coordinates equal the reviewed 3D renderer's coordinates exactly in every view. The model's vertices, faces, normals and colors remain unchanged after projection and styling.

The three styles use the same native masks and eye/nose ink placements. The external one-cell contour adds silhouette pixels; it does not erode source skin pixels. The ear seam is a declared material-boundary outline inside that mask. P1/P2 change lighting thresholds only. P2/P3 differ in exactly 819 atlas pixels, all recolored from the soft outline RGB to the dark outline RGB; no fill, feature or alpha pixel changes.

All 15 saved frames have binary alpha 0/255, clear border margins and at most five opaque colors. Rear views use four colors because no eye/nose ink is visible. Other views use five. Each style's opaque-pixel counts, in frame order, are 1286, 1263, 1234, 1234 and 1638.
