- `pixel-comparison.png`: 세 시안 × 다섯 시점, 6배 최근접 보기와 실제 1배를 함께 표시.

- `P3-contrast-atlas.png`: P2의 윤곽색만 C2 계열의 짙은 색으로 변경.

각 atlas는 320×64 RGBA이고 프레임은 왼쪽부터 측면·사선·정면·후면·윗면의 64×64다. 불투명 색은 외곽 1색+내부 최대 4색, 알파는 0/255만 사용한다. 세 안의 실루엣·눈/코 픽셀은 동일하며 골격 강도 A/B/C 비교와 다르다.

화풍 참고는 `references/styles/b2-c2/v1/reference-sheet.png`의 왼쪽 B2와 오른쪽 C2다. 해당 개의 무늬·표정은 복사하지 않고 윤곽색 대비와 넓은 색면 표현만 따른다. 기준 3D 모델의 짧은 목·중립 표정, 골든의 넓은 주둥이를 유지한다. 64격자에서 눈 반짝임과 미세 털은 생략한다.

## 실행과 검토

코드·명령은 [엔진 README](../../tools/head_engine/README.md), 입력은 `resolved-profile.json`, 실제 생성 설정은 `pixel-recipe.json`, 출력 규격은 `pixel-validation.json`, 출처는 `engine-inputs.json`과 `evidence.json`에 저장한다. `review-status.json`은 새 출력의 독립 외형·기술 판정을 기록한다.

체급의 small/medium/large 배율은 제작 기본값이며 실측 크기나 체중 분류가 아니다. 같은 크기로 비율을 비교하는 normalized와 공통 제작 단위의 relative를 분리했다. 현재 픽셀은 normalized이다. 사용자 취향 선택·전신 조립·표정 애니메이션·실기기 표시 검증은 남아 있다.

## 수정 이력

1차 출력은 측면 코 식별이 약해 외형 검토에서 V01 MAJOR, 눈의 갈고리 형태는 V02 MINOR였다. 당시 그림·코드·보고서는 `iterations/01`에 보존했다. 2차는 코/눈 의미 마스크를 분리하고 얇은 코를 원래 실루엣 안쪽 한 칸만 확장했으며 눈을 투영 중심에 맞춘 작은 클러스터로 정리했다. 원본 3D 모델과 세 안의 실루엣은 바꾸지 않았다. 최종 상태와 대상 해시는 `review-status.json`을 따른다.
