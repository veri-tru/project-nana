# 코의 측면과 윗면 관찰 — 2026-11-05

사용자는 앞면에만 붙인 코 표현을 거절하고 실제 개의 측면과 윗모습을 확인하라고 지시했다. 아래 사진을 실제로 열어 관찰했으며, 문헌의 해부 구조와 렌더러 작화값을 구별한다.

- [IMAIOS — Nostril](https://www.imaios.cn/en/vet-anatomy/anatomical-structures/nostril-11073761376). 콧구멍의 가쪽 모서리는 좁아지고 가쪽·위쪽으로 이어진다. 렌더에는 작은 음영으로만 단순화했다.

## 이번 구현

1. 주둥이 mesh의 앞부분에 공통 낮은 코 단면을 통합한다. 별도의 타원체나 앞면 스티커는 사용하지 않는다.
2. 검은 코의 윗면과 양옆에 앞뒤 길이를 주고, 뒤쪽은 콧등·뺨 표면으로 연결한다.
3. 코 아래 주둥이의 사진 기반 윤곽은 유지해 검정 코가 지지 없이 떠 있지 않게 한다.
4. 윗면 폭·높이·깊이·피부 경계·콧구멍 음영 함수는 전 품종 공통이다. 개체별 코 설정은 색상만 받는다. 등록 위치와 주변 및 하부 주둥이는 품종별 입력을 사용한다. 최종 코의 모든 표면 좌표가 품종별로 완전히 동일하다고 주장하지 않는다.
5. 수직 윗면을 검토판에 추가한다. 기존 귀는 얇은 면 모델이므로 윗면에서 귀의 부피 검증을 완료했다고 주장하지 않는다.
6. 사용자가 윗모습에서 각진 주둥이를 추가 지적했다. 코 뒤 짧은 구간에서 폭이 갑자기 커지던 보간을 제거하고, 공통 코에서 각 품종의 두개 폭까지 완만한 곡선으로 연결했다. 주둥이 단면은 원형으로 완화하고 뺨에서 기존 품종별 단면으로 돌아간다. 눈의 등록점과 귀·골격 입력은 유지하며, 바뀐 주둥이 표면 때문에 투영된 얼굴 폭과 눈의 가림은 달라질 수 있다.

이 수치들은 B 데포르메 작화값이다. 해부학 실측값이나 새 사용자의 승인으로 기록하지 않는다.
