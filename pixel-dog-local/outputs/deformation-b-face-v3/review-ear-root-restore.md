# 귀 뿌리 위치 복구 독립 검토 — 2026-11-05

검토자 `ear_geometry_review`. **이전 귀 부착 위치 복구라는 제한된 범위의 기술 검토를 통과했다. 뿌리 각짐 개선은 미완료다.** 사용자 미감·닮음 승인을 대신하지 않는다. 앞선 거절 후보는 `review-ear-geometry.md`에 별도 이력으로 남아 있다.

## 범위와 실제 형상

기준은 `preview-before-ear-round.py`다. 최종 `preview.py`와 비교하면 귀 색 그라데이션 제거, 부착부 바깥 귀 몸체 좌표 평활화만 남았다. 부착부를 매립하거나 품종별로 x/y를 이동하던 처리는 제거했다. 골격 입력만 같다는 검사가 아니라 실제 출력된 양쪽 귀의 xyz 배열을 비교했다.

`distance <= 0.65 * ew`인 부착부 전체가 기준과 비트 단위로 같았다. 휘핏 46행, 닥스훈트 32행, 골든 리트리버 47행이며 양쪽 귀 모두 최대 좌표 차이가 0이다. 얼굴·코의 좌표와 색 배열도 세 품종 모두 기준과 완전히 같다.

귀 몸체는 가우시안 평활화 결과를 점진적으로 반영하고 끝의 0.20w 구간에서 가중치를 다시 0으로 감쇠한다. 최대 정점 이동은 휘핏 0.522484, 닥스훈트 0.480378, 골든 0.228234 모델 단위다. 세 품종 양쪽 귀 모두 좌표가 유한하며, 주기 단면 seam 및 양 끝 cap의 좌표 벌어짐은 0이다. 귀 색은 단일 RGB 재질로 돌아왔다.

## 저장된 이미지 직접 검토

아래 다섯 파일을 각각 실제로 열었다. `ear-geometry-flat.png`는 실제 mesh를 동일 카메라·배율, 머리/귀 각 단색으로 그려 음영 영향을 제거한다. 기존 위치와 복구 결과의 부착부가 대응하고 몸체만 작게 변한다. 측면에서 골든·닥스의 수평 부착 경계, 휘핏의 직각 부착 경계와 정면·뒷면 모서리가 여전히 보인다. 따라서 이를 각짐 해결 완료로 표시하면 안 된다.

컬러 다각도판, 측면·윗면·¾판, 전신판, 코 윗면 확대도 현재 같은 모델 출력이다. 사진에서 직접 관찰되지 않은 깊이·두께·곡률은 작화값이라는 기존 구분을 유지한다. 이 고해상도 형상 검토는 64×64 픽셀 정본 검수나 품종 닮음 승인을 뜻하지 않는다.
