# 48픽셀 얼굴과 발 수정본

2026-11-01 사용자 요청에 따라 기존 A/B/C의 얼굴과 발을 다듬은 v2다. 각 48-v2.png는 실제 48×48px 투명 PNG이고, 384-v2.png는 최근접 이웃 방식의 8배 확대본이다. comparison-8x.png는 왼쪽부터 A/B/C 수정본이며 before-after-8x.png는 위에 기존본, 아래에 수정본을 배치했다.

내장 image_gen으로 각 시안의 얼굴·발 수정을 요청했다. 눈과 코의 어두운 픽셀 덩어리, 흰 이마·주둥이의 구분, 다리 하단과 발의 명암을 정리했다. 생성 원본은 각 generated-edit-original.png로 보존했고 전체 요청문은 prompts.json에 있다.

생성 결과를 48픽셀에 정렬한 뒤 얼굴·턱 경계와 다리 하단·발 영역에만 반영했다. 몸통 등 수정 영역 밖의 픽셀, 전체 실루엣과 투명도는 기존본과 동일하게 유지했다. 투명 샘플이 검은 발 픽셀로 들어오는 오류를 시각 검수에서 제거하고 다시 확인했다. 영역 좌표와 변경 픽셀 수는 validation.json에 있다.

기존본은 ../48px 폴더에 보존했다. 아직 보호자의 닮음 확인, 동작별 호환과 다른 방향의 외형 검수는 하지 않았다. 이번 결과를 완성된 애니메이션 자산으로 등록하지 않는다.
