# 48×48 픽셀 시안

2026-11-01 사용자 요청에 따라 기존 A·B·C 64×64 PNG를 최근접 이웃 방식으로 48×48px로 축소했습니다. 새로운 그림을 생성하거나 다시 그리지 않았습니다.

각 48 PNG는 실제 48×48px 투명 배경이며, 384 PNG는 8배 확대본입니다. comparison-8x.png는 왼쪽부터 A·B·C를 표시한 비교판입니다.

사진의 얼굴 무늬·귀·흰 발을 비교하는 정적 시안입니다. 보호자 닮음 승인·동작 호환·최종 프로젝트 해상도는 확정하지 않았습니다. 작은 크기에서 픽셀 배치를 다시 다듬는 작업은 아직 하지 않았습니다. 검증 결과는 validation.json을 봅니다.
