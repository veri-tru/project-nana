# 사진 기반 64픽셀 외형 시안 3종

2026-11-01 사용자 제공 사진 5장을 참고해 제작했다. 이번 시안의 실제 파일 규격은 사용자 지시에 따라 64×64px이며, 프로젝트 전체의 최종 해상도 결정을 대신하지 않는다.

| 구분 | 실제 파일 | 특징 |
| --- | --- | --- |
| A | A-game-64.png | 색을 간결하게 정리한 균형형 |
| B | B-rounded-64.png | 생성 결과에서 몸통이 비교적 길고 날렵하게 표현된 형 |
| C | C-natural-64.png | 얼굴과 몸통의 털결을 더 남긴 형 |

B의 파일명 rounded는 최초 생성 의도를 보존한 이름이다. 실제 결과의 비율은 위 설명으로 평가한다. 세 시안은 같은 서 있는 자세와 방향을 요청했으나 결과의 머리·몸통 비율은 서로 다르다. 행동 개인화 A/B 비교물로 사용하지 않는다.

각 64 PNG는 투명 배경이다. 512 PNG와 comparison-8x.png는 가장 가까운 픽셀을 복제한 8배 확대본이며 비교판에는 밝은 배경을 사용했다. 공통 캔버스와 바닥 기준 y=57로 배치했다.

## 적용한 프로젝트 규범

- AGENTS.md, docs/asset-spec.md, docs/current-spec.md, docs/personalization-spec.md와 외형 자료 검토 보고서를 확인했다.
- 사진에서 보이는 회색 귀·몸통, 흰 이마 중앙·주둥이·가슴·발을 반영했다. 품종 이름은 추정하지 않았다.
- 몸통은 균형 장방형 참고 후보로 보되 품종이나 실측 비율로 확정하지 않았다.
- 사진 방향을 유지하고 반대쪽 외형을 복제하지 않았다. 원사진은 작업 폴더에 복사하지 않았다.
- 이번 결과는 생성 보조로 제작한 정적 시안이다. 보호자의 닮음 확인, 부위 분리, 다른 방향·포즈, 동작 호환과 8fps 애니메이션 검수는 남아 있다.

## 제작과 검증

내장 image_gen으로 각각 생성하고 생성 원본을 A/B/C-generated-original.png로 보존했다. 생성 원본의 실제 해상도는 64×64가 아니므로, 투명 영역을 기준으로 내용 범위를 확인한 뒤 Sharp의 최근접 이웃 방식으로 축소·배치해 실제 64×64 PNG를 만들었다. Python 이미지 편집이나 외부 API 대체 생성은 사용하지 않았다.

최종 프롬프트 전체는 prompts.json, 실제 크기·투명도·색 수·기준선 확인 결과는 validation.json에 있다. 색 수는 실제 파일의 측정값을 사용하며 프롬프트의 요청 수와 같다고 가정하지 않는다. 투명도는 0·255로 확인했다.

사진과 달리 보이는 부분은 보호자 검토 후 수정한다. 특히 눈 위치, 귀 길이, 몸통 길이와 다리 비율을 확인한다. 최종 캐릭터·몸통 자산의 승인 상태로 등록하지 않는다.
