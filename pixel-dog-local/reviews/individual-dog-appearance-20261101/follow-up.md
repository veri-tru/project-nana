# 첫 개체의 미확인 외형 보완 안내

2026-11-01. 사용자의 추가 이미지·설명 수집 방향을 구체화한 안내 초안입니다. 이후 추가 스크린샷 3장(P06~P08)을 받아 검토했습니다. 아래 요청과 연결한 결과는 하단에 기록하며 보호자 검수는 아직 진행하지 않았습니다.

사진 또는 설명 중 편한 방식으로 보완합니다. 사진이 있어도 가림이 남으면 분류를 보류하며, 설명으로 받은 값은 보호자 보고로 기록합니다. 모름·나중에 응답을 허용합니다.

| 요청 ID | 보완 항목 | 사진으로 보완할 때 | 설명으로 보완할 때 |
|---|---|---|---|
| F01 | 꼬리 형태·길이 | 평소 모습에서 꼬리의 뿌리부터 끝까지 보이는 옆·뒤 사진 | 평소 꼬리가 펴지는지, 부드럽게 굽는지, 말리는지와 대략 어디까지 내려오는지 설명. 자세에 따라 달라지면 함께 기재 |
| F02 | 주둥이 길이 | 코끝과 눈·이마가 함께 보이는 옆얼굴 사진 | 털을 제외한 코 주변이 얼굴에서 얼마나 앞으로 나오는지 설명. 판단이 어려우면 모름 |
| F03 | 가슴 형태·배선 | 자연스럽게 서 있을 때 앞가슴이 보이는 사진과, 가슴부터 배·뒷다리까지 보이는 옆사진 중 가능한 자료 | 앞가슴이 몸통보다 넓어 보이는지, 옆에서 배가 뒷다리 쪽으로 올라가는지 설명. 털 때문에 모르겠다면 모름 |
| F04 | 귀의 실제 길이·끝 | 양쪽 귀의 끝이 보이는 정면·옆얼굴 사진 | 귀끝이 눈·코·턱 중 어디 높이까지 오는지, 좌우 차이가 있는지 설명 |
| F05 | 현재 털 길이·결, 미용 영향 | 현재 모습이 잘 보이는 사진. 미용 전 모습도 반영하고 싶은 경우에만 이전 사진 추가 | 현재 미용한 상태인지, 표현하고 싶은 시점이 언제인지, 털이 자랐을 때 펴지는지·물결치는지·말리는지 설명 |
| F06 | 몸통·다리 비율·등선의 잠정 분류 | 몸 전체와 발이 보이는 몸 높이에서 찍은 옆사진 | 현재 후보인 약간 긴 몸통·중간 다리·수평에 가까운 등 윤곽에서 다르게 느끼는 부분을 설명 |
| F07 | 보이지 않는 쪽의 무늬 | 해당 방향의 캐릭터를 제작할 때 반대쪽 얼굴·몸통 사진 | 흰색·회색 영역이 반대쪽에서도 같은지, 다르다면 어느 부위인지 설명. 개체 자신의 좌우 기준 사용 |

F01~F03은 현재 분류가 보류된 부위입니다. F04~F06은 이미 관찰된 후보를 더 정확히 해야 할 때, F07은 해당 방향의 제작이 필요할 때 받습니다. 모든 요청을 한꺼번에 완료할 필요는 없습니다. 기존 옆사진 한 장이 F01·F03·F06을 함께 보완할 수도 있습니다.

입력 후에는 요청 ID → 응답 자료 ID → 연결 외형 항목 → 후보 재검토 → 보호자 확인 순서로 기록합니다. 아직 제공되지 않은 설명을 응답으로 채우지 않습니다. 새 근거로 이전 관찰을 덮어쓰지 않고 변경 이유를 남깁니다.

## 추가 스크린샷 수신 후 상태

| 요청 | 수신 자료와 검토 결과 | 남은 확인 |
|---|---|---|
| F01 꼬리 | P06·P07 재검토 완료. 몸통보다 긴 꼬리털을 관찰 | 실제 꼬리뼈 길이·형태와 평소 말림은 미확인 |
| F02 주둥이 | P06·P08 재검토 완료. 흰 수염과 코 돌출은 유지 | 완전한 옆얼굴이 아니므로 길이 확정 보류 |
| F03 가슴·배선 | P07·P08 재검토 완료. 보이는 무늬·윤곽 보완 | 털·각도 때문에 흉곽 폭·깊이와 배선 분류 보류 |
| F04 귀 | P06~P08 재검토 완료. 처진 회색 귀 후보 유지 | 실제 귀끝·길이와 고정된 좌우 차이 미확인 |
| F05 털·미용 | P06~P08 재검토 완료. 사진별 풍성함과 긴 꼬리털 관찰 | 미용 이력은 미확인. 사용자가 표현할 털 길이를 고르는 절차로 연결 |
| F06 비율 | P07·P08 재검토 완료. 약간 긴 몸통·중간 다리 후보 유지 | 실측은 하지 않음 |
| F07 무늬 | P07에서 뒷목·다리 하단을 보완 | 양쪽 전체 무늬와 정확한 좌우 경계는 미확인 |

추가 이미지를 받았다는 사실은 보호자의 특징 수락이나 털 길이 선택을 뜻하지 않습니다. 현재 제공된 자료로 우선 작업하고, 남은 자료는 해당 부위의 제작·수정에 필요할 때 받습니다. 14개 축 축소는 후속 설계 방향으로 기록했으며 현재 관찰 기록의 항목을 삭제하지 않았습니다.
