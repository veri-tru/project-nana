# 행동 DB 보완 반영 결과

2026-10-17 사용자 지시 ‘보완진행’에 따라 검토안 R01–R14를 반영했다. 현재 버전은 2.0.0이다. 원기록 ID 307개를 유지하면서 대표 행동 121개와 자세·동작 속성 70행으로 연결했다.

## 우선 정정

| 대상 | 적용한 내용 |
| --- | --- |
| 산책 상황 | 산책 제안에 대한 반응 1건과 실제 산책 중 행동 5건을 분리했다. |
| 머리 지지 | 목으로 유지하는지와 외부 지지면에 맡기는지를 구별하고, 받침 위치를 별도 속성으로 기록했다. |
| 앞발·입 조작 합산 | E070은 접촉/비접촉 앞발 동작 종합, E071은 입 조작 종합으로 정정했다. |
| 옆눕기 E019 | 문헌 본문 언급으로 정정하고 직접 정의의 근거 후보에서 제외했다. 별도 출처의 옆눕기 근거는 유지했다. |

이 정정과 이전 추출 범위 보완은 31개 필드 변경으로 기록했다. 원값·새 값·사유를 모두 남겼다. 건강·문제 맥락 제외 상태, 좌우 차이, 행동 전후 관계와 개별 수치의 결측도 유지했다.

## 통합과 재조직화

- 위계의 149개 기록 가능한 코드를 121개 대표 행동에 연결했다. 기존 상위 8개 영역은 유지했다. 대표 행동 수는 검증된 습관 수나 제작 완료 동작 수가 아니다.
- 앞발 교차, 잠자리 회전, 잠자리 표면 다루기의 반복 요구를 묶었다. 부드러운 얼굴 문지름은 관련 긁기 정의와 구별한 확인 대기 요구로 남겼다.
- 파기/긁기, 기다림/대기 과제 지표, 앞발 접촉/물체 조작, 머리 돌림/외면은 경계를 기록하고 별도 코드로 유지했다.
- 설계 연쇄 8개를 공통 틀 7개와 단계 27개로 정리했다. 내용이 같은 3쌍도 서로 다른 반복 단계로 보존했다.
- 관계는 원본 43개로 저장하고, 기존 ID 83개를 통한 양방향 조회를 재구성했다.
- 긍정·부정·일상 평가 146개를 공통 구조로 옮겼다. 기존 분야별 조회와 4건의 중첩 평가는 유지했다.
- 같은 표 항목에서 나온 E183/E184는 공통 근거 단위에 연결했다. 근거 단위 303개는 독립 표본이나 연구 수가 아니다.
- F17·F19는 연구 결과에서 작업 이력으로 옮겼다. 원문 재확인 이력과 미사용 분류의 역할도 기록했다.
