# 품종별 외형 자료 활용 검토

2026-10-17 검토. 첨부 자료는 **외형 템플릿을 선택하고 개체별로 조정하는 참고 사전**으로 활용할 가치가 높다. 기존 행동 DB와 연결하면 사진으로 외형을 맞추고, 보호자 응답으로 행동을 맞추는 기획을 구체화할 수 있다. 9개 몸통 계열의 실제 자산 재사용성은 제작 시험에서 확인해야 한다.

## 자료에서 확인한 범위

| 자료 | 확인한 내용 | 활용 |
| --- | --- | --- |
| 디자인 가이드 | 5쪽, 몸통 9계열, 대표 사진 27장, 논리 파트 45종과 합성 순서 | 제작자가 공유할 형태와 개별 수정할 부분을 판단하는 지침 |
| Excel | 5개 시트, 품종 322행, 독립 외형 태그 14차원, 파트 사전과 근거 | 사람이 외형 후보와 예외를 검토하는 작업표 |
| ZIP | 11개 CSV·JSON·설명 파일, 품종 매핑·태그 어휘·근거·사진 출처 | 별도 외형 사전의 초기 데이터와 출처 연결 |

322개 ID는 중복 없이 001–322로 연결되며, JSON·CSV·원자료·Excel의 ID 집합이 같다. JSON의 14차원 태그와 Excel의 한국어 표시도 일치한다. 그룹별 수는 B01 49, B02 100, B03 36, B04 37, B05 14, B06 10, B07 17, B08 7, B09 52개이며 합계 322개다. 그룹 대표의 배정과 Excel 집계값도 일치한다. 이 수치는 자료 내 분포이며 국내 보급률이나 고객 수요 비중이 아니다.

전체 품종 중 63개는 미확인 태그가 하나 이상 있다. 몸통 길이감 23개, 꼬리 21개, 배선 20개 등이 미확인이다. 체장 절대값은 313개가 미확인으로 남아 있으므로 이 자료만으로 정확한 신체 치수를 산출할 수 없다. 출처별 분류의 생물학적 타당성을 322종 전체에 대해 새로 검증한 결과는 아니다.

## 제품에 연결하는 방식

외형 참고값, 실제 개체의 외형, 개체의 행동, 실행 가능한 자산을 구별한다.

| 구분 | 담을 내용 | 결정 근거 |
| --- | --- | --- |
| 품종별 외형 참고값 | 몸통 후보, 머리·귀·꼬리·털·무늬의 선택지와 예외 | 첨부 자료와 연결된 출처 |
| 개체 외형 프로필 | 선택한 체형, 현재 미용, 색과 무늬 위치, 좌우 차이, 보호자 수정 | 사진에서 보이는 특징과 보호자 확인 |
| 개체 행동 프로필 | 앉고 눕는 자세, 한쪽 앞발 유지, 몸 털기·기지개의 상황과 빈도 | 기존 행동 DB, 보호자 응답, 필요한 경우 관찰 |
| 동작 자산 대응 | 사용할 외형과 동작의 조합, 접지·가림·연결점, 지원 방향 | 실제 제작 파일과 표시 검수 |

품종을 고르면 외형 후보를 제시하되 개체 사진과 보호자 수정이 우선한다. 믹스견이나 품종을 모르는 개도 체형·귀·꼬리·피모를 직접 선택할 수 있어야 한다. 품종 표준의 색과 무늬는 참고값이며, 실제 반려견의 무늬를 거부하는 조건으로 쓰지 않는다. 자료의 자연 귀·꼬리 기준과 실제 개체의 현재 모습을 구별한다.

사진은 외형과 보이는 자세에 사용한다. 사진에 없는 반대쪽 무늬, 털에 가려진 관절, 실제 비율은 미확인으로 남긴다. 품종이나 몸통 코드로 성격, 신뢰, 헥헥거림의 빈도, 앞발 들기 습관을 자동 결정하지 않는다.

### 입력 부담을 줄이는 흐름

1. 기존 사진 한 장으로 얼굴·귀·색·털 등 보이는 외형 후보를 만든다. 몸통 판단이 어려우면 체형 그림 중 선택하거나 전신 사진을 선택적으로 추가한다.
2. 보호자는 다른 부분만 수정한다. 실제 사진을 분석하지 못한 단계에서는 자동 인식을 제공하는 것처럼 표시하지 않는다.
3. 짧은 동작 예시 중 평소 앉고 눕는 자세, 앞발 위치, 몸 털기·기지개가 나타나는 상황을 선택한다. 빈도는 보호자가 답한 범위에서만 저장한다.
4. 지원되는 외형과 행동 조합으로 미리보기를 만들고 보호자가 확인한다. 영상은 첫 입력의 필수 조건으로 두지 않는다.

## 우선 보완할 연결 구조

### 변종과 조합 조건

현재 배열은 가능한 옵션의 목록이며, variant_options 등 일부 조건은 설명문이다. 푸들의 크기·곱슬/코드형 피모·미용이나 차이니스 크레스티드의 본체·피모 조합을 실행 가능한 규칙으로 만들려면 변종 ID, 함께 쓸 수 있는 옵션, 대안 관계, 적용 조건을 명시해야 한다. appearance_query_examples의 조건도 문장 형태여서 검색 기능을 바로 실행하는 코드가 아니다.

품종에서 흔한 조합과 실제 자산이 결합 가능한 조건은 별도다. 사진으로 확인된 개체 특징은 품종 기본값을 바꿀 수 있지만, 부위가 붙지 않거나 포즈에서 겹치는 자산 조합은 제작 수정이 필요하다.

### 형태와 동작의 경계

외형에는 귀의 길이와 붙는 위치, 꼬리의 형태, 다리 비례를 기록하고, 동작에는 그때의 귀 방향·꼬리 자세·앞발 위치를 기록한다. 자료의 등 위 꼬리 같은 태그도 모든 상황에서 고정된 포즈로 처리하지 않는다. 같은 몸통 계열 안에서도 길이·폭·등선이 달라 하나의 애니메이션을 그대로 적용할 수 있다고 보장할 수 없다.

| 기존 행동 후보 | 외형에 따라 확인할 제작 문제 |
| --- | --- |
| 앉기·눕기 | 다리 길이별 접지, 몸통 접힘, 장모에 가려지는 앞발과 머리 받침 |
| 몸 털기 | 몸통의 움직임과 귀·꼬리·장식털의 가림 및 흔들림 |
| 기지개 | 앞발 접지와 가슴 높이, 긴 몸통·짧은 다리에서의 윤곽 |
| 앞발 들고 있기 | 좌우 선택, 지면에서 떨어진 발의 식별, 긴 털 아래의 표시 |
| 입 벌림·헥헥거림 | 주둥이 길이·수염에 따른 입 표시, 입 벌린 정지 자세와 반복 동작의 구분 |

이는 제작 검수 항목이며 새 행동의 발생 확률이나 실제 운동 측정값을 뜻하지 않는다.

### 픽셀 자산 규격

첨부 가이드는 일반 2D 형태와 레이어 구성에 사용할 수 있다. 현재 프로젝트에는 64×64와 96×96 후보를 비교하고 8fps를 기본으로 쓰는 별도 자산 초안이 있으므로, 가이드를 적용한 결과를 작은 실제 표시 크기에서 확인해야 한다.

검수에서는 귀·꼬리·머리 비율과 대표 무늬가 구분되는지, 프레임 사이에 무늬가 이동하지 않는지, 앞발 교차나 입 벌림이 보이는지 확인한다. 부위별 연결점, 클리핑 범위, 포즈별 앞뒤 순서, 기준점·접지선과 좌우 비대칭을 자산 메타데이터에 연결한다. 좌우 반전으로 실제 무늬를 바꾸지 않는다.

45개는 논리적인 파트 유형 수다. 방향·포즈·프레임·표정·품종별 변형을 포함한 완성 그림 수나 개발 공수로 환산하지 않는다. 자동 레이어 합성과 품종별 완성 스프라이트 중 어느 방식이 더 적합한지는 작은 시험에서 비교할 수 있다.

### 데이터 연결과 근거

기존 행동 DB의 대표 행동 121개는 외형 분류 9개와 다른 차원이다. 외형 사전을 별도로 두고 개체 프로필과 실제 자산의 호환 관계로 연결한다. 9×121개 조합을 모두 지원하는 것으로 등록하지 않는다.

| 추가로 필요한 항목 | 이유 |
| --- | --- |
| 자료 묶음 ID와 버전, 3자리 품종 ID | 선행 0을 보존하고 다른 목록과의 ID 충돌을 방지 |
| 변종과 미용 ID, 조합 조건 | 옵션 배열의 대안을 실행 규칙으로 표현 |
| 개체별 수정값과 확인 상태 | 품종 기본값과 보호자가 확인한 특징을 구분 |
| 속성별 근거와 미확인 사유 | unknown을 0이나 특징 없음으로 바꾸지 않음 |
| 외형 자산과 동작 변형의 호환 정보 | 실제 파일이 존재하고 검수한 조합만 사용 |

ZIP에는 원사진·비교판 PNG·캐릭터 스프라이트가 없다. README에 언급된 원사진 322장 해시 보존은 동봉 자료의 주장으로 남아 있으며, 이번 첨부본만으로 원사진 파일과 대조할 수 없다. PDF의 대표 사진 27장과 사진별 출처 메타데이터는 확인할 수 있다. 실제 사진을 다시 사용하려면 해당 원파일과 개별 이용 조건의 연결을 유지해야 하며, 사진 출처 메타데이터만으로 앱 자산이나 학습 데이터가 준비된 것은 아니다.

## 제작 시험과 중간점검 제안

첫 제작 시험은 체형 차이가 큰 4개 계열을 선택한다. 예를 들어 B01 균형정방형, B04 장각균형형, B06 저상장신·보통골격형, B08 단신광폭형을 사용할 수 있다. 이 선택은 구조 차이를 확인하기 위한 것이며 국내 시장의 우선 품종을 뜻하지 않는다. 같은 베이스 안에서도 미용과 귀·꼬리가 다른 개체를 비교해 재사용 범위를 확인한다.

앉기·눕기·몸 털기·기지개의 4개 동작을 적용하면 최초 검수 단위는 16개 체형·동작 조합이다. 각 조합의 방향·프레임·변형은 별도이므로 16장 또는 최종 제작량으로 해석하지 않는다. 성공 여부는 개체 식별, 동작 인지, 가림·접지 오류, 수정 소요시간과 공통 파트를 유지할 수 있는 범위로 판단한다.

중간점검은 기존 계획대로 같은 외형을 고정한 A/B 비교로 진행한다. A는 공통 기본 행동, B는 보호자 응답에 맞춘 행동이며 자산 품질·표시 크기·재생 시간은 맞춘다. 외형까지 함께 바꾸면 행동 개인화의 기여를 구분하기 어려워진다. 외형의 닮음은 그 전에 확인한다.

20대 여성 첫 고객 후보와 30대 여성 유료 개인화 구매 후보라는 가설은 유지한다. 두 집단에 같은 비교 과제를 적용하고 자기 개다움, 선택 이유, 입력 부담, 수정량과 유료 구매 의향을 따로 확인한다. 322종 목록의 수록 빈도를 이 두 집단의 수요로 대체하지 않는다.

현재 검토 판단은 외형 참고 사전과 제작 지침으로 활용하고, 실제 자동 fitting·부위 합성·동작 재사용은 위 시험 이후에 범위를 정하는 것이다. 원본 첨부와 행동 DB는 변경하지 않았다.
